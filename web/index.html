    理论与算法的边界

    左右面身份和异或差分来自本项目的模型。选择规则：候选最少的面优先，其次邻接度最高，再按面编号；直接选最低可用色标。每面至多赋色一次，候选为空就停止，不暗中回溯，也不增加第五色。这是待完善的贪心规则，不保证任意地图成功，不构成新的四色定理证明。

    画框外部也计为一个面。悬空线不分面；岛屿和嵌套区域通过不分面的隐藏桥处理。编辑后重新识别并赋色；面编号和颜色不保证跨编辑保持不变。

    拖动画直线；也可连续点击起点和终点。线相交时自动生成交点，闭合后自动形成新面。按 Escape 取消正在画的线。

    查边模式会显示箭头、左右面及颜色差。撤销可以逐步回到之前的分割。

    导出 JSON 保存线段、分割顺序和验证结果。导入同一文件可复现地图。SVG 用于保存已填色的图。

    当前版本处理有限直线段地图，不从照片或手绘图片自动识别边界。很密集的输入可能达到计算上限；此时不会把超时解释成需要第五色。
