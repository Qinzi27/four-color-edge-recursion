# 从最终线网重新命名：优先级试验

发起思路：Qinzi27。日期：2026-09-18。

本轮实现“加线后清空旧名，从外圈重建推导顺序；同优先级从固定一边补齐”的三个明确候选。
它们在部分地图上只用四名，但均有明确反例。反例针对下述规则，不是否定全部优先级方法，
更不是地图不可四色的证据。没有修改、发布现有网页着色入口。

**随后用户进一步澄清：基本操作应是连接两个已命名结构的接点，而不是按闭合侧选择命名顺序。**
因此本报告保留为已完成的侧优先对照实验，不能声称已实现该点到点规则；
本报告反例也不能直接反驳尚未完整定义的点到点方法。

## 1. 对象、前提与规则

- 输入仅含最终几何，不读原名字或绘制先后。`buildMap` 重建端点、细分线段、接点转角与侧轨道。
- 线名仍是有序左右符号对。赋予一个侧轨道名字，必须同步写入该轨道全部线侧。
- 外侧固定展示名 1。桥和悬枝两侧是同一个侧轨道，不额外造一个待命名侧。
- 从外侧出发，跨真实分界线的最少次数定义层次 `depth`。这不是欧氏距离，也不是画线代数。
- 沿外侧边界从左上角顺时针，随后按队列处理发现的侧边界，预先得到唯一的静态发现序 `rank`。
  每个内部轨道从最小 `(y,x,head_y,head_x)` 的有向线段开始沿其转角轨道扫描。
  逆时针对照反转扫描序，不交换线名左右语义。
- `discovery` 仅是这次遍历的发现关系，不冒充尚未完整定义的几何母线—子线关系。
  所有非树边、闭合接点仍保留，选名时读取完整边界的全部已命名对侧。
- 每步只处理接触已命名侧的待命名轨道。`saturation` 是已知对侧的**不同名字数量**，每步更新。

| 候选 | 优先级键（字典序由小到大） |
| --- | --- |
| P0：纯边界顺序 `boundary` | `(rank)` |
| P1：外圈层次优先 `layer-constraint` | `(depth, -saturation, rank)` |
| P2：限制数量优先 `constraint-layer` | `(-saturation, depth, rank)` |

选中后取不在已知禁名集合中的最小正整数。没有强制四名上限，没有换色、配色枚举或回溯。
因此程序可以如实输出第五、第六名，而不把失败藏成“未找到结果”。
顺、逆时针是六条固定规则的独立比较，没有为每张图挑一个最好结果冒充单一算法。

本质上，这仍是由线侧轨道表达的贪心选名。P2 的首项与既有 DSATUR 饱和度指标相同，
但我们的外圈起点、层次和几何同级规则不同；不能将这个优先级指标宣称为新发明。
参见 [JGraphT 官方算法说明](https://jgrapht.org/javadoc/org.jgrapht.core/org/jgrapht/alg/color/SaturationDegreeColoring.html)，
访问于 2026-09-18。本轮未作穷尽文献查新。

## 3. 六线反例：最后的平局并不是根因

900×600 外框内，画入下列六条线，均无自由端：

```text
(450,0)   → (450,600)
(450,300) → (900,300)
(650,0)   → (650,300)
(450,120) → (650,120)
(650,100) → (900,100)
(450,240) → (650,240)
```

顺时针下，三规则均先得到外围侧 `A=2, B=3, C=2, D=4, E=3`。
内部相邻侧为 `F=[450,120,650,240]` 与 `G=[450,240,650,300]`。
在四名集合 `{1,2,3,4}` 内，两者对已定名边界的候选均为 `{1}`：

```text
F 的已定名对侧：A=2、B=3、D=4
G 的已定名对侧：A=2、D=4、E=3
F 与 G 之间还有一条真实分界线。
```

固定上述外围选择时，无论先补 F 还是 G，另一个必遇四种禁名。程序实际为 `G=1`，随后 `F=5`。
F 的四条禁名边分别是左 A2、上 B3、右 D4、下 G1。
这已经是清空旧名后的失败，不是偷偷保留了上一版命名。

逆时针重新从零计算，三规则都给出 `O=1,A=2,B=4,C=3,D=2,E=3,F=1,G=4`，验证合法。
另一独立四名证书为 `O=1,A=2,B=3,C=4,D=2,E=3,F=1,G=4`。
因此原顺时针优先级需要第五名，绝不意味着这张地图需要五色。

## 4. 两个方向也不构成保证

把上述六线图横向压缩到左半纸 `x→x/2`，再镜像复制到右半纸 `x→900-x/2`，
加中隔线 `x=450`，得到 13 条原始线。三规则、两个方向全部输出五名。

独立诊断搜索（42 个搜索节点，仅为研究 oracle）找到一份四名证书。
这份显式证书已写入 Node 回归测试，每次只验证证书，不再次搜索，也不向新算法提供名字。
不声称 6 线或 13 线在所有图中最小。

## 5. 下一轮真正需要增加的条件

可以单独研究“相邻未命名侧同时只剩同一名字”的提前预警。
若出现 `{a}` 与 `{a}` 的相邻对，仅改变这两个侧的补齐顺序无用，必须：

1. 在更早的选名处避免制造这个状态；或
2. 允许先前已命名侧联动改名，并再次更新所有相关线名。

这是待实现的前瞻/重命名规则，不是本次三策略已有的能力。
候选冲突检测不会自动告诉我们应改哪条母线，更没有完成一般四色证明。
