# 低色优先：危险候选域的可达性检查

本轮保持 `quaternary-low-color-conditional-propagation-v1` 不变，继续检查
“试探没有推出矛盾，是否仍可能落下不可延拓的颜色”。研究起始想法属于
Qinzi27；本轮是可复现诊断与有限核查，不是新算法性能改善或四色证明。

主要结果：**没有发现这轮真实母线运行的错误承诺；但已将原先外部指定
候选域的障碍，提升为只给一个初始颜色、由实际低色决定自行产生的抽象
顺序反例。** 两者的区别明确落在选点顺序上，不能相互替代。

## 3. 裸五点图为什么不足以制造当前障碍

基本图为 `K5−AE`：B、C、D互相接触，A与E各自接触B、C、D，A和E不接触。

已知的初等推理是：三角形B、C、D占用三种不同颜色，A和E只能使用剩下的
第四种，所以所有合法四色赋值都满足 **A=E**。这里的等号表示同名，不合并
两个几何区域，也不添加真实边。

全枚举4^5=1,024个赋值得到24个合法解；枚举5^5=3,125个部分承诺，其中
481个可延拓。在这些状态上检查每个未承诺点的全部四种颜色，共3,796次
试探：1,456次有延拓且传播存活，2,340次无延拓且传播发现冲突，误分类0。
其中经过初始域过滤的候选试探有1,480次，未决域中的候选试探952次；
仍保留在候选域但不安全的24次均被条件试探拒绝。

结构理由：从可延拓的部分承诺出发，不合法的新单色要么直接撞上已定色
邻居，要么使A与E颜色不同。后一种会让B、C、D至多剩两色，路径一致性
足以发现三角形矛盾。该论证只适用于裸图及单色承诺，不能直接移用于有
外部邻居或额外候选域的情形。

## 4. 新进展：仅单锚也能自行产生危险域，但目前是抽象顺序

在上述图上增加K4(P,Q,X,Y)，再加入AX、AY和EZ，得到10顶点、18条真实
NEQ的平面图。仅输入 `Z=1`，没有外部states，没有给定目标配色。规定
抽象输入顺序 `Z,P,Q,X,A,B,C,D,E,Y` 后，冻结guarded实际依次提交：

```text
Z=1（初始化）
P=1 → Q=2 → X=3 → 传播得到Y=4
此时 A={1,2}，E={2,3,4}，B/C/D仍各有四名
试探A=1：传播仍未决 → 实际提交A=1 → 合法完整解由6变0
```

独立枚举全部4^10=1,048,576个赋值，不作颜色对称性缩减，得到：

| 累计承诺 | 合法完整解数 |
|---|---:|
| 无锚 | 864 |
| Z=1 | 216 |
| 再P=1 | 36 |
| 再Q=2 | 12 |
| 再X=3 | 6 |
| 再A=1 | 0 |

前三次主动提交安全，第四次是首次不可延拓承诺。承诺前完整见证之一是
`Z1,P1,Q2,X3,Y4,A2,E2,B1,C3,D4`；承诺后保存并独立验证17节点、6叶的完整
UNSAT树。后续排除候选造成的最终conflict不是首次错误发生的位置。

这是开发中发现的诊断，不能称盲测。它排除了“只能靠人为输入候选集合
才会发生”的解释，但仅否定当前核心在该抽象选点顺序下的普遍安全性，
不能据此断言真实母线顺序失败，更不否定原图可四色。

## 5. 实际母线为什么避开了这一例

同一提升结构已经实现成真实区域图：额外加外面F且仅邻Z，完整输入有
11面、19条真实邻接；Z是标准单锚选中的S1。虚拟连接只服务面识别，
不添加真实共边约束。四种几何表示均通过独立邻接核查。

保存的实际母线轨迹中，四种表示都**先选择E，再选择B/C/D中的一面**。
第二次提交后的传播已经把A固定为与E同名：单锚为A=E=2，旧双锚为
A=E=1。随后才处理X/Y/P/Q；A从未作为主动提交事件出现。因此没有沿着
抽象顺序先把P、Q、X固定，再到A选择1。

| 表示 | 单锚Z1的前三次主动提交 | 双锚F1/Z2的前三次主动提交 |
|---|---|---|
| 原图 | E2 → D1 → B3 | E1 → D2 → B3 |
| 水平镜像 | E2 → B1 → D3 | E1 → B2 → D3 |
| 垂直镜像 | E2 → B1 → C3 | E1 → B2 → C3 |
| 双镜像 | E2 → B1 → D3 | E1 → B2 → D3 |

四种单锚完整图随后均为Y1→X3→P2，传播得到Q4，最后框边备用步骤提交
F2，每图7次主动提交；双锚随后Y2→X3→P1并传播Q4，每图6次主动提交。

这8条完整图运行均没有候选拒绝，说明此例是选点顺序避开危险状态，不能
写成“试探识别并拦截了该危险承诺”。反射后环面及K4内部选点可以变化，
不能把字母角色按面ID排序的结果误认为跨表示保持同一几何位置。

另在五面真几何输入外部域A={1,2}、E={2,3,4}：人工强加A=1仍为6解→0解，
而真实母线实际选择其他侧后完成，未发生首错。该对照与正常单/双锚群体
分开保存；其外部states不属于普通初始化。专用审计核对完整事件链、精确
文档转换、累计锚点、调度、终态及全赋值，避免无解以后空集合比较掩盖错误。

## 6. 下一步的具体问题

本轮把缺口定位到“结构关系与选点顺序的配合”，没有修改算法来提高分数。
建议按以下次序继续：

1. **检验母线顺序的保护条件。** 定向改变提升构造的外层连接、放置位置
   和合法嵌入，检查是否能在固定E或推出A=E之前先固定K4内部颜色；每个
   新实验预声明输入，追踪首个错误承诺。待研究的不变量是：强制同名两端
   是否能在真实可达状态中形成不可比的交叉候选域。当前只有有限支持。
2. **将已证明的同名证书接入四进制分支。** 对共同接触同一三角形的A/E，
   可由证书加入逻辑EQ，使候选域取交集。本例从{1,2}与{2,3,4}直接收紧
   到{2}，仍保留低色优先。可复用已有结构重启支线的可靠关系识别；另立
   版本、冻结后比较修复/退步/成本，不能把旧版不同成功集合拼起来。新EQ
   必须记录真实邻接证书；独立oracle继续只读取原始邻接与实际承诺，避免
   把待核查的学习关系当作oracle前提。

这条EQ是已知初等结构关系，接入不自动构成原创定理或一般完备算法；更大
图仍可能有该局部模板覆盖不到的联合约束。用户暂不需要修复环境或补充
手绘信息，当前可继续通过具体反例和合法构造推进。
