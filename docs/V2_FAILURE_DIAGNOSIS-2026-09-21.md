# 回到原命名主线：v2 唯一失败缺少什么关系

2026-09-21。研究起点与线优先命名思路来自 Qinzi27。本文件诊断已观察到的失败，不改动冻结 v2，不使用 Kempe 修复，也不调用新的整图赋色 oracle。新策略集成及其完整运行成绩由本轮其他报告分别记录。

## 1. 已定位的缺口

历史最强完整归档 v2 在相同的 7069 张图中完成 7068 张，唯一失败为 `guillotine-20261213` 第 17 次切割后的地图，含外侧共 19 个侧身份。这里的 17 是地图历史步骤，**并非命名程序已经选了 17 次**；本图 v2 只做了一次主动名字选择就发生冲突。

几何键：`8070783fd68de9a9dd22c6d4c8831a55c330290f4a30e2e9c8f6edb70af66132`。

| 阶段 | 实际记录 | 已核验结论 |
|---|---|---|
| 规范化 | 外侧 `S0=1`，框首内侧 `S1=2` | 具有完整合法延伸 |
| 原过滤固定点 | `D(S10)={2,3,4}` | 只保留了必要条件，其中 2 实际不能延伸 |
| 原 v2 第一主动决定 | 母线 `L:0,412>900,412`、dart 47 上给 `S10` 取最小名字 2 | 决定后经已记录的 Hall 推导发生矛盾 |
| 本轮精确诊断 | 从真实共边推出 `S1 != S10` | 在既有规范化下排除 2，真正可延伸名字恰为 `{3,4}` |

`S1` 是盒 `[0,544] × [0,72]` 的侧区域，`S10` 是 `[0,900] × [412,600]`。两者没有直接共边。方框坐标沿用原网页坐标；它们只用于定位，证明使用实际非零边段邻接，不依赖图形视觉相近。

这直接对应用户原方法中的问题：**两个不直接相接的线侧能否复用同一个名字，仍可能受跨越多条母线的接点关系约束。** 本例缺少的是一个可提前证明的异名关系，不是需要在已命名图上执行换色。

## 2. 不借整图搜索的手工证明

记 `Si` 的名字为 `c_i`。假设 `c_1=c_10=x`，外侧名字为 `a`；因为 0 与 1 有真实共边，所以 `a != x`。将余下两个可用名字记为 `b,c`。

1. `S11,S12` 相邻，而且各自避开 `a,x`，故占用 `b,c`。`S14` 邻接 `S10,S11,S12`，只能取 `a`。
2. `S15` 邻接 `S14,S10`，故取 `b` 或 `c`；它又与 `S12` 相邻。于是 `S12,S15` 占用 `b,c`。`S13` 邻接 `S1,S12,S15`，只能取 `a`。
3. `S2,S17` 相邻，且各自避开 `a,x`。`S3` 邻接 `S0,S2,S17`，只能取 `x`。
4. `S9,S16` 相邻，且各自避开 `a,x`。`S8` 邻接 `S0,S9,S16`，只能取 `x`。
5. `S7` 邻接 `S0,S8`，故取 `b` 或 `c`；`S16` 也只能取 `b` 或 `c`，并且 `S7,S16` 相邻。最后 `S18` 同时邻接 `S13(a),S3(x),S7,S16`，四个名字全部被排除，矛盾。

因此 `c_1 != c_10`。证明不依赖先固定数字名 1、2：对任何至多四名的合法命名都成立。

### 另一种适合程序独立核验的表达

在至多四名的图中，若两个顶点都邻接一个三角形的三个顶点，它们就必须取同一个剩余名字。先暂时将 `S1,S10` 视为同名类；随后逐条应用这条初等关系：

| 同名收缩 | 三个两两相邻的支撑类 |
|---|---|
| `S0 = S14` | `{S1,S10}`, `S11`, `S12` |
| `{S0,S14} = S13` | `{S1,S10}`, `S12`, `S15` |
| `{S1,S10} = S3` | `{S0,S13,S14}`, `S2`, `S17` |
| `{S1,S3,S10} = S8` | `{S0,S13,S14}`, `S9`, `S16` |

最终五个类 `{S0,S13,S14}`、`{S1,S3,S8,S10}`、`S7`、`S16`、`S18` 两两邻接，要求五个不同名字，故反驳最初的同名假设。

这里的收缩只发生在**逻辑证明的商图**中，不是修改原地图、增加真实线或执行用户的切割操作。报告为每个商图邻接保存一条原侧邻接来源，再追到原始非零共边段、端点坐标及所属母线。固定证书用了 16 个原侧、38 条原邻接；`S4,S5,S6` 不参与这份证明。没有声称这是最小侧数或最少边证书。

## 3. 为什么能断言这是第一处错误

归档 v3 为同一几何保存了完整合法命名：

```text
[1,3,2,4,3,2,4,2,4,3,2,3,4,2,1,3,1,1,3]
```

本轮不将其作为新算法输入，只在事后诊断中进行保持外侧 1 的全局名字置换。两份完整见证同时满足 v2 的初始规范化，并分别令 `S10=3` 和 `S10=4`：

```text
S10=3: [1,2,3,4,2,3,4,3,4,2,3,2,4,3,1,2,1,1,2]
S10=4: [1,2,4,3,2,4,3,4,3,2,4,2,3,4,1,2,1,1,2]
```

每份见证都逐条检查 55 条原始边上的侧名差异、全部有向侧轨道，以及第一传播阶段所有域和二元关系。原 v2 的唯一主动决定及其之后的矛盾，也由原独立验证器重新检查。

由此证据链完整：初始状态有解；取 2 有几何反证；3 和 4 各有完整合法见证。因此第一主动决定确为首个不可延伸决定，且候选真集合恰为 `{3,4}`。这比“未在若干见证中找到取 2 的情况”更强，后者本身不能证明无解。

## 4. 对下一步规则的作用和限制

本例支持在主动承诺一个旧名字之前，先问：“若此侧和已经使用该名字的某侧同名，会不会仅凭真实接点关系就导致矛盾？”若有可重放证明，先保存异名关系，再沿原母线顺序传播、选择。这样推进的是用户的重新排程、重新命名主线。

但单份证书只证明这一对侧不能同名：

- 它不证明这种三角关系闭包能发现所有不可复用名字。
- 找不到反证只能叫“不确定”，不能叫“已经证明可延伸”。
- 它不证明所有必要边界信息都可压成两侧之间的异名关系。
- 它不建立通用四色算法、线性时间界或原创性；共同邻接三角形迫使同名属于初等关系。
- 此文件没有新生产策略成绩，也没有把修复这一个旧失败自动加到 7069 张图完成数上。
