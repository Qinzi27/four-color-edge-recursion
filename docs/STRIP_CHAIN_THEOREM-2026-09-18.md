# 固定双锚条带链：插线与同步改名的受限定理

日期：2026-09-18。发起思路：Qinzi27 的递归线侧命名与插线后重命名。

**结论级别：下面是一个可以直接证明的受限图族结果，不是一般四色定理的新证明，也不声称双色交换操作具有原创性。** 代码实现抽象侧邻接更新，不负责判断任意手绘插线是否满足图族前提。

## 1. 对象和前提

在原平面图中，由端点的旋转次序（rotation system）及线侧延续关系导出侧一致类。一个类上的全部线侧记录必须具有同一个符号。类的标识 `side_id`、当前符号 `symbol`、原图的几何线段及构造历史分别保存，不能混为一谈。

本节在这些类的**侧邻接图**上工作。邻接图的一条边表示两个侧一致类之间的异名约束，不等于某一条特定的原图几何线段；多个原图线段也可能给出同一个邻接约束。

令内部符号集合为 `K={0,1,2,3}`，与网页显示的 `{1,2,3,4}` 相差 1。考虑

\[
H_n=K_2\vee P_n,\qquad n\geq 1.
\]

这里两个锚类为 `O,A`，链类按一个**预先固定的方向**排列为 `S_1,...,S_n`。准确的全部邻接为：

- `O` 与 `A` 邻接；
- 每个 `S_j` 都与 `O,A` 邻接；
- 链内只有 `S_j` 与 `S_(j+1)` 邻接，没有额外弦。

锚符号固定为 `c(O)=0`、`c(A)=a≠0`。把剩余两个符号记为 `p,q`。每个链类只能使用 `p,q`，相邻类异名，因此合法旧命名必然交替。

允许的插线必须把一个 `S_i` 替换为相邻的 `S_i^L,S_i^R`，仍按顺序位于同一链上，二者均与两个锚邻接，其余邻接不变。结果恰为 `H_(n+1)`。这是需要几何层确认的前提；任意一条线或任意侧分裂不自动满足它。

## 2. 确定性规则

首先让两个新类临时继承 `S_i` 的符号。这时只有新相邻对 `S_i^L,S_i^R` 同名；**该状态不作为合法结果提交**。

暂不计新相邻对的异名约束，链的两段为：

\[
L=(S_1,\ldots,S_{i-1},S_i^L),\qquad
R=(S_i^R,S_{i+1},\ldots,S_n).
\]

比较需要改名的未分裂旧类数量：左段为 `i−1`，右段为 `n−i`。选择较少的一段，平局固定选左；同时把该整段上的 `p,q` 互换。两个锚不变，只提交最终合法状态。

例如锚为内部 `0,1`，旧链 `2,3,2`，分裂中间类：

```text
旧命名：       2 | 3 | 2
临时继承：     2 | 3 | 3 | 2   ← 不提交
交换左整段：   3 | 2 | 3 | 2   ← 合法结果
```

这里的“左”是已给定链顺序的前缀，不是算法推断的屏幕左方。外圈锚本身不能消除链方向歧义；几何适配层必须提供一个稳定方向。

## 3. 定理及证明

**定理。** 在以上全部前提下，每次允许插线都可由上述一次同步交换完成合法命名。两个锚保持不变，只使用 `K`。改名的未分裂旧类数量为

\[
m=\min(i-1,n-i),
\]

且在两个锚固定的所有合法新命名中达到最小。算法不枚举命名方案，时间及输出存储均为 `O(n)`。

### 3.1 安全性

1. **锚与链之间。** 链上只交换 `p,q`，两者均不等于锚符号 `0,a`，所以这些邻接保持异名。锚之间没有变化。
2. **所选段内部。** 交换是对 `{p,q}` 的双射；每条原来异名的相邻对仍异名。
3. **未选段内部。** 完全不变，仍异名。
4. **两段之间。** 按图族定义，唯一连接是新相邻对。其两端原来同名，恰好一端交换，故变成异名。

以上穷尽 `H_(n+1)` 的全部邻接，故结果合法。原图中的对应动作必须同步更新被交换类边界上的全部线侧名。不能只改新线的一对数字而留下同一侧的其他记录不一致。

### 3.2 最小改动界

固定两个锚后，新链只能用 `p,q`。给定新链第一个类的符号，其余符号逐项被强制确定。因此合法新命名恰有两种：交换左段得到一种，交换右段得到另一种。

左段方案恰改变未分裂的旧类 `S_1,...,S_(i−1)`，数量为 `i−1`；右段方案恰改变 `S_(i+1),...,S_n`，数量为 `n−i`。取较小者，已在全部合法新命名中最优。

该界**不统计已分裂的父类和两个新子类，也不是原图线段改名条数的界**。不同侧类的边界线段数可能不同；最少改侧类未必最少改线段记录。

### 3.3 确定性、终止和复杂度

输入包含固定链方向、旧命名、分裂位置和两个新标识。比较两个整数后即确定交换段，平局选左；不存在试错、回溯或候选着色遍历。遍历一次输出链、替换所选段符号即终止。输入验证和输出构造各为 `O(n)`，输出存储为 `O(n)`。

因每步结果仍是同一图族，任意有限次**保持图族的**合法分裂都可归纳完成。若连续进行 `k` 次且每次复制完整状态，总成本为 `O(kn+k²)`；这不是一般地图的复杂度结论。

## 4. 与已知操作及一般问题的边界

双色连通分量交换的保合法性是已知的基本操作（通常称 Kempe change）。本结果把它放在一个更窄的结构上：暂不计新线约束时，链恰分成两个可确定选择的双色分量，所以能同时证明成功、终止和最少旧侧类改名数。这里没有提出双色交换的新颖性主张。

以下情况不由本定理处理：链上有弦或分支；某侧不邻接两个锚；额外邻接迫使两段在远处重新相连；允许移动锚符号；插线后不再属于 `H_(n+1)`。代码不应把一般图悄悄简化成条带链后宣布成功。

尤其要区分：

- “交换一个合适分量是安全的”；
- “任何插线后总有合适分量”；
- “有一个不枚举、能终止的规则找到它”。

本定理在规定图族内证明了三者；并未对任意平面地图证明后两者。

## 5. 可复现实现与独立测试

核心实现：`fourcolor/strip_chain.py`，仅 Python 标准库。冻结数据类 `SideClass`、`StripChain`、`StripSplit` 保持标识、符号和更新证据分开。

```python
from fourcolor.strip_chain import SideClass, StripChain, split_strip_chain

old = StripChain(
    outside=SideClass("outside", 0),
    anchor=SideClass("fixed-neighbor", 1),
    chain=(SideClass("s1", 2), SideClass("s2", 3), SideClass("s3", 2)),
)
result = split_strip_chain(old, 2)  # 一基索引；新类默认为 s2/L、s2/R。
assert tuple(side.symbol for side in result.after.chain) == (3, 2, 3, 2)
assert result.changed_old_ids == ("s1",)
assert old.chain[0].symbol == 2  # 旧状态没有被原地改写。
```

运行：

```sh
python -m unittest discover -s tests -p test_strip_chain.py -v
```

测试范围：`n=1..40` 的全部分裂位置、固定外侧 `0` 的其余三个符号全部 `6` 个排列，共 `4920` 个单步实例；另外拒绝外侧非零的 `18` 个全符号排列，并测试非法输入、标识冲突、输入不可变、输出不可变及连续 `40` 次分裂。

独立测试器显式生成全部侧邻接约束并检查异名；最小改动数则通过比较两种交替完成来核对。**两个候选的比较仅用于测试最优性，不是生产算法。** 有限测试支撑实现可靠性；一般 `n` 的数学保证来自上面的证明，而不是把测试数当成证明。
