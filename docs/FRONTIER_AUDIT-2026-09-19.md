# 选线压力与局部保留名审计（2026-09-19）

本审计区分三个层次：选线启发式、给定已命名侧后的必然推导、有限图上的运行结果。它不构成四色定理证明，也不把受阻解释为需要第五色。发起思路属于 Qinzi27。

可复现数据：[frontier-pressure-pilot-2026-09-19.json](../outputs/frontier-pressure-pilot-2026-09-19.json)。它保存旧报告及源码 SHA-256、规范化几何、完整目标轨迹、条件 Hall 推导和逐条共享边检查。这里不汇报正在进行的新全量实验。

## 1. 旧权重遗漏了什么

令 `S(I)` 为当前母线区间 `I` 两侧的不同侧身份，`D(s)` 为侧的当前候选名集。旧 `closed-support` 使用：

`q(I) = Σ [4 − |D(s)|]`，只累计 `|D(s)| > 1` 的侧。

两侧各有两个候选时权重为 4；其中一侧进一步确定后，权重反降为 2。这不是加法错误，而是“已建立的命名约束数量”的定义问题。它可能降低已锚定线路的优先级。另一个独立问题是，选定区间后仍选其几何顺序中的第一个未定侧，不一定是候选最少的一侧。

本轮只改变一处的对照策略 `anchored-pressure`：

`q_all(I) = Σ_{s ∈ S(I)} [4 − |D(s)|]`，包含单值侧。

完全命名的区间仍退出队列；优先级为 `(q_all, 已建立原始线网闭环支撑)`，闭环只打破同权重。母线身份、当前区间、同权重几何次序、区间内选侧以及最小可用名规则不变。不测试替代颜色，不回溯。在区间仍活跃、几何不变且候选只缩小时，`q_all` 不会下降；这不证明它的贪心决策可全局延伸。

这个自动结果与“保留旧 B=3、C=2”的条件结果不同；不能把两条轨迹拼成一条。

## 3. 保留旧前两步，也能用必然约束解开

以下推导的前提明确固定为：外部=1、A=2，以及旧决定 B=3、C=2。它不是 `tight-hall` 从头运行的轨迹。

首先核对真正的共享边。D、E、F 两两相邻，构成侧邻接图中的三团（clique）；D、F、G 也如此。只有点接触不算共享边。

| 侧对 | 共享边 | 长度 |
| --- | --- | ---: |
| D—E | `y=327, x=0..63` | 63 |
| D—F | `y=327, x=63..160` | 97 |
| E—F | `x=63, y=172..327` | 155 |
| D—G | `y=327, x=160..518` | 358 |
| F—G | `x=160, y=172..327` | 155 |

对于真实团 `K` 中的侧子集 `T`，令 `U=∪_{s∈T}D(s)`。因为这些侧必须两两不同：

- 若 `|U| < |T|`，当前给定决定没有合法延伸。
- 若 `|U| = |T|`，任何合法延伸都必须让 T 用尽 U，因此 `K\T` 可删去 U。

这就是本处的 Hall 保留名条件。它枚举至多四侧团中的约束子集，不枚举颜色赋值组合。

易读推导：D、E 的候选同为 `{3,4}` 且相邻，它们必须占满 3、4；同时邻接两者的 F 只能为 1。于是 G=4、D=3、E=4。全部共享边两侧不同，内部 F 使用 1 合法。

为使图中文字与程序顺序也可核对，实际传播器的完整 11 条事件如下。前 7 条是已有单值传播，后 4 条是新增固定点扫描：

| 事件 | 原因 / 操作 | 结果 |
| --- | --- | --- |
| 1 | 外部=1，D 删除 1 | D=`{2,3,4}` |
| 2 | 外部=1，E 删除 1 | E=`{2,3,4}` |
| 3 | A=2，E 删除 2 | E=`{3,4}` |
| 4 | A=2，F 删除 2 | F=`{1,3,4}` |
| 5 | A=2，G 删除 2 | G=`{1,3,4}` |
| 6 | B=3，G 删除 3 | G=`{1,4}` |
| 7 | C=2，D 删除 2 | D=`{3,4}` |
| 8 | 团 `{D,E,F}`，子集 `{D,E}` 保留 `{3,4}`，F 删除 3、4 | F=`{1}` |
| 9 | 团 `{D,F,G}`，子集 `{F,G}` 保留 `{1,4}`，D 删除 4 | D=`{3}` |
| 10 | D=3，E 删除 3 | E=`{4}` |
| 11 | F=1，G 删除 1 | G=`{4}` |

JSON 的 `conditional_hall_audit` 保存初始和追加决定的 dart 锚、这 11 步、每侧 bounds，以及所有 22 条原子共享边的端点、长度和最终不等式检查。两组三团还各有逐边证书。因此上述三团不是根据画面外观猜测的。

## 5. Hall 实现审查与边界

`frontier_restart.py` 的团基于实际正长度共享边的侧邻接，不是原始线网闭环；十字交点周围的对向侧不能据此假定不同名。每个删除步骤均为给定决定的必要条件；域只缩小，有限个候选保证一次传播终止。每次主动选择固定一个原本未定侧，所以整次运行也有限终止，但可能终止于冲突。

未发现该有限团过滤的数学安全性错误。不过，非空候选不等于全局可延伸；三/四团局部过滤不等于完整匹配传播，更不证明任意图的无回溯算法完备。`tight-*` 优先使用单侧候选紧迫度，与 MRV / DSATUR 思路相关，不能仅因输出保留母线名就声称完全不同的原则。

独立核验也须区分：旧 `independent_check` 重建的是单值传播，适用于本次两种非 Hall 优先级；它不能用“与单值闭包相等”验证 Hall 闭包。Hall 需要逐证书核对真实团、当时域与删除集合，并独立检查最终全部边；若报告冲突，必须核验冲突证书或可重放的传播链。

## 6. 最小复现

在仓库根目录，使用 Python 3.10+ 和 Node.js。以下只运行目标一张图；将种子改为 `20260916` 可复现上述回归。JSON 是输入快照，不含私有机器路径。

```python
import json
from pathlib import Path
from scripts.validate_global_restart import export_geometries
from fourcolor.global_restart import restart_line_names
from fourcolor.frontier_restart import restart_frontier_names, propagate_hall
from fourcolor.whole_lines import build_whole_lines

# Rebuild only geometry: no previous names are accepted as solver input.
pilot = json.loads(Path("outputs/frontier-pressure-pilot-2026-09-19.json")
                   .read_text(encoding="utf-8"))
case = next(r for r in pilot["records"]
            if {"seed": 20261027, "step": 6} in r["aliases"])
geometry = export_geometries([
    {"key": case["geometry_key"], "document": case["document"]}
])[0]["geometry"]
old = restart_line_names(geometry, "closed-support")
new = restart_frontier_names(geometry, "anchored-pressure")

# Separate conditional calculation, deliberately keeping the old first two choices.
anchors = dict(old["initial_anchors_by_dart"])
for event in old["trace"][:2]:
    anchors[event["dart"]] = [event["symbol"]]
conditional = propagate_hall(build_whole_lines(geometry), anchors)
print(old["status"], new["status"], conditional["status"])
# Expected for 20261027/6: conflict solved solved
```
