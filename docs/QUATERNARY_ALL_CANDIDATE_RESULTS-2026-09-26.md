# 全候选试排结果：推理提前，整体成本上升

本轮保持 Qinzi27 的四进制候选表示、母线调度及最低候选优先，新增独立的
`quaternary-low-color-all-candidate-v1`。结论是：**已知 S3 推理链能提前完成，
但 767 组配对中实际落名序列、最终配色、落名次数全部相同；全面扫描成本明显
增加。** 当前证据不支持把它作为默认提速版，也不构成一般可延拓性或完备性证明。

## 1. 本轮实际改变什么

旧奇环 EQ 版只试探当前准备落名的面之最低候选。新版在每次落名前，按输入面
顺序和数字升序检查所有未定面的所有候选；实际传播出矛盾才删除该色，删色后
重新扫描。完整一轮没有删色才使用原母线调度、提交最低候选，复用已保存 trial。

`非1` 仍是 `{2,3,4}`，不是预先确定为 2。临时试探不增加持久承诺；删色得到的
单例用推导状态记录，也不伪装成主动落名。已提交色不回退，精确 oracle 不给
算法提供选色、删色或救援。每个配对场景的两版生产均先结束，再作离线核查。

数学依据是可靠反证：若当前约束加 `v=c` 经可靠传播得到矛盾，则可删除 `c`，
保留当前约束的全部合法解。反向命题不成立：传播没有矛盾仍可能全局无解。
本轮仍实际观察到了这样的存活候选。

## 4. 真实 19 面案例中得到的改进

图 key：`8070783fd68de9a9dd22c6d4c8831a55c330290f4a30e2e9c8f6edb70af66132`。
原始 19 面、51 个不同真实 NEQ，此图未学习到共邻奇环 EQ。

单锚模式在主动提交 `S16=1` 后，当前实际锚点仍仅为 `S1=1,S16=1`：

| 新版操作 | S3 候选字 | S4 候选字 | S5 候选字 |
|---|---|---|---|
| 删色之前 | `1111` | `1111` | `1111` |
| 反证 S3=2 | `1011` | `1111` | `1111` |
| 反证 S3=3 | `1001` | `1111` | `1111` |
| 反证 S3=4，传播确定 S3=1 | `2000` | `0111` | `0111` |

三次拒绝为 event 75/83/91；持久 phase 从 57→76→85→94。对应原始精确
UNSAT 记录 75/76/77 各为 17 节点、2 个叶子。实际承诺没有增加 S3=1；它是
推导单例，所以字为 `2000`。S4/S5 的 `0111` 仍代表三个候选，不是固定为 2。

这条推导在主动提交 S10=2 **之前**完成。旧版需要先提交 S10=2，再通过传播
得到同样的 S3=1 和 S4/S5≠1。新版提前补上这个局部推理机会，却没有减少主动
落名：两版均为 `S16=1→S10=2→S15=3→S14=1→S11=3`，最终配色相同。
本例单锚试探 5→220、拒绝 0→3；双锚试探 10→322、拒绝仍为 1。

初始 S10=1 **仍未解决**：新版 event 34 / trial phase 35 仍报 inconclusive，
原始 oracle 记录 35 给出 88 节点、6 叶 UNSAT 证书。它没有被主动提交，随后
原母线先选 S16=1，真实共边排除了 S10=1。本例仍不能证明一般调度总会避开坏色。

旧双锚 S10=2 的拒绝仍存在：新版 event 23，原始 UNSAT 记录 24 为 29 节点、
2 叶。四次拒绝及一个未处理 probe 的五份证书均已独立重验。

紧凑事后证据包：`outputs/quaternary-all-candidate-known-gap-2026-09-26.json`。
它引用完整几何与轨迹的正式检查点，保存两版顺序/配色、四进制变化、实际锚点及
原始 UNSAT 证书；不是新一次生产或搜索，不能另计为实验样本。

## 7. 下一步取舍

本轮实现证明了：您的候选编码能够承载“先对其他面作可靠删色，再继续母线
低色取名”的机制。收益发生在推导时点上，即更早的承诺阶段，未扩展本批完成
集合；代价则显著上升。
旧默认流程保留，新版作为固定对照。

下一项优先研究应为**无需 oracle 的逻辑异名证书**：针对已保留的 S1≠S10
原始边证明，抽象出明确、可独立检查的证书规则，避免仅靠每一步重复全面扫描。
逻辑 NEQ 必须与真实物理共边分开记录；关系来源、颜色对称性归一化、当前承诺
及锚点作用范围均须明确。另立版本，与本版比较推理收益、退步和成本；不预设
它能解决一般延拓。选择性扫描可以另作成本优化对照，不与关系规则混成一次改动。

当前无需用户补图或修复环境；待解决的是如何以更小的可靠关系/接口表示覆盖
全局约束。没有提出新基本定理、文献原创性或通用四色证明的声明。
本轮代码、文档及结果仍在本地，未提交、推送或部署。
