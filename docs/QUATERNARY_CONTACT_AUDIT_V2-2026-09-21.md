# 四进制接触原型：独立核查补充协议 v2

本文件在 v2 正式运行前固定。原型求解源码、原例子、v1 核查源码、输入清单和
报告均保留原样；本版补强核查器，不修改传播算法，也不新增算法完成率主张。

## 修订原因

v1 已核对原始约束的全部合法赋值投影和独立集合实现的最终关系闭包，但对
编码元数据核对不足。篡改试验发现：保持候选集合不变而交换单例标记 2/3、
把多候选标记改为多个 3、篡改反向侧身份，或向关系掩码添加第 17 bit，均可能
被 v1 接受。这是核查器的覆盖缺口，尚未发现原型输出这些错误。

## 本版增加的独立核查

- 从原始输入读取显式锚定来源，区分 `states` 中的单例 3、`anchors` 声明及
  没有显式锚点的输入单例。来源记录不得遗漏、添加或变更。
- 独立重建初态与终态规范四位字：空域为 0000，多候选使用 0/1，无显式锚定
  的单例使用一个 2，有显式锚定的非空单例使用一个 3。终态为空时保留锚点
  来源记录，但其状态字是 0000，不能用 3 冒充仍有候选。
- 核对整数编码、四位候选 mask、候选列表、最小显示代表和 `anchored`。
  布尔量不得冒充整数；初态、终态及其冗余域字段必须一致。
- 核对初始与最终关系矩阵的维数及 16-bit 整数范围；初态关系逐项从原始
  候选域、真实共边、逻辑同名独立重建。保留 v1 的最终闭包与完整赋值核查。
- 反向线关系不仅核对组合转置，还核对左右侧身份交换；点接触和逻辑同名
  回显必须与输入一致。`status` 限于三种声明值，并与冲突/单例判定一致。
- 添加篡改单元测试，确认以上错误会被拒绝。保存原 v1 测试，避免只检验
  新增字段而丢失原有的合法解保留检查。

## 运行范围与限制

沿用原协议的全部 41,847 个有限模型及完整候选笛卡尔积，不做颜色对称归并，
不增加随机抽样。新增核查器、测试、本协议与原有来源共同写入新的 manifest，
冻结后正式重跑。新报告使用独立文件名，不覆盖 v1。

另设一个具名范围对照，不计入上述 41,847 个模型：四个侧身份构成全部六条
真实共边（抽象图 K4，可平面嵌入），每侧输入域均为 0111，即只允许 2、3、4。
独立枚举 3^4=81 个完整赋值，检验其无合法解但二元路径一致可能仍非空。
这里的失败来自额外限制所有侧均不能用 1；它不否定 K4 的正常四色可解性，
也不声称这个限制状态可由旧生产策略到达。该对照用于防止把未决误报有解。

本轮独立核查原始输入、初态、最终闭包、所有合法赋值的投影和输出编码。
传播 trace 保留供重放，但新增核查器不逐条独立认证 trace 中的每一个中间
删减；不得把本轮结果写成每条 trace 已获得独立证明。没有主动取色承诺，
因此本实验也不是旧贪心调度的逐步可延拓性测试。
