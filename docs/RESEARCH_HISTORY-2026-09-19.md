## 1. 怎样读这份记录

目前已得到可复现的表示、若干有证明的受限命题、多版确定性候选程序及其反例，**没有得到任意平面地图通用成功的新算法或四色定理新证明**。四名色盘是后期实验的输入条件，不能算作程序自行证明出的上界。局部规则或表示与已有文献有重合；本仓库不认证原创性。

下文日期是文档／报告检查点；同日有多条并行研究支线，不以章节次序伪造精确时间先后。尤其要区分：

| 记录单位或状态 | 含义 | 不能解释成 |
| --- | --- | --- |
| 单张去重几何 | 一份当前完整线网，可能是一条历史的中间前缀 | 一条完整历史、一个独立随机样本 |
| 历史全部前缀完成 | 初始状态及每次加线后的几何均完成 | 仅最终图完成 |
| 单步修复 | 从指定旧状态成功加入这一刀 | 后续所有刀都能成功 |
| 证书通过 | 对报告所声称的成功、冲突或拓扑事实验证通过 | 地图着色成功 |
| `underdetermined` | 可靠推导后仍有多候选，规则主动停止 | 矛盾或地图不可四色 |
| `conflict`／`blocked` | 该版本、该起点、已提交选择或限定修复动作受阻 | 原图必须第五色 |
| `outside_scope` | 输入超出适配器或实现门槛 | 一次实际选色失败 |
| 固定诊断集 | 已知困难图及预先选择的对照 | 未见留出集或普遍成功率估计 |

“最小数字”“最少颜色种类”“最少旧侧改动数”是三个不同目标。整体置换名字是对称规范化；构造中固定一个当前最小候选是可能改变可延伸性的决定。

## 3. 2026-09-06—07：先把对象、经典等价与未证部分分开

### 3.1 基础模型和受限精确算法

基础提交 `c74510e` 的日期为 2026-09-06；下述初始机器报告的检查点为 2026-09-07。两者分别记录代码建立与验证时间，不把它们误作同一次运行。

从“有向线的左右名字”建立组合地图：有向半边、旋转次序、真实侧／面身份、当前色名和分割历史分别记录。悬线延伸不增加面；桥左右是同一面，色差为零。`Extend` 与 `CloseSplit` 分别记录拓扑变化，括号历史本身不足以恢复全部嵌入。

基础文档给出群色差的路径无关／势函数重建、球面上流与面色的对应、完整边界关系粘合、堆叠三角剖分递归基准，以及圈、无桥仙人掌、theta 和**给定分解树的 TTSP** 最小改标记公式。它们有各自明确假设，不声称覆盖所有平面图；TTSP 四状态递推是标准有限状态动态规划思路，未作原创认定。

初始机器核验包括四面体的 256 份面赋值与 729 份非零边赋值；TTSP 核验为三角形 27、theta 27、固定种子随机网络 30 个初始标签实例。固定轮缘预着色实验中，84 种合法轮缘着色有 24 种不能向中心扩张，而整图仍有合法四色着色。这明确区分“旧承诺不能延伸”和“地图不能四色”。

## 4. 2026-09-08：锚定端点与构造缺口

新增线必须有可解释的端点锚定或闭合；连接不同边界分量也可能只生成桥、不分面。对一次真正分面，若保留一个子侧的旧名 `a`，另一个子侧可取的名字为 `K \ ({a} ∪ T)`，其中 `T` 是它**全部当前保留边界**的邻名，不仅是两个端口。这个直接扩张条件可验证，但候选并不保证一直非空。

固定 13 个图库例为 8 完成、2 受阻、2 草稿、1 非法输入。连续种子 20260908–20261147 的 240 条生成历史中，160 条 guillotine 全部在某一步受阻（累计提交 1094 步），40 条嵌套环／桥完成 720 步，40 条边界扇完成 480 步。2569 份初始／已提交状态证书通过不等于 2569 条历史完成。四线例同一终图按 `A→B→C→D` 受阻，而 `A→C→D→B` 成功，保留了构造顺序问题。

独立逆合并诊断检查 147 个带标号抽象图、478 份规范化合法配色：每图至少有一条所检查的抽象合并链，但有 1 份固定配色没有完整放松链。这使用研究性枚举／回溯，既没有给出一般几何可画性，也没有作为网页失败兜底。

证据：[构造规则](CONSTRUCTION_RULES-2026-09-08.md)、[阶段日志](WORKLOG-2026-09-08-CONSTRUCTION.md)；[construction.js](../web/construction.js)、[逆合并诊断](../scripts/search_construction_gap.py)；[构造机器结果](../outputs/construction-validation-2026-09-08.json)、[逆合并结果](../outputs/reverse-merge-search-2026-09-08.json)。

### 6.3 联合候选和二元搭配关系

## 15. 2026-09-20—21：保留旧色的修复与代价支线

本节问的是“已给定旧标色，加入一刀至少需要改动多少旧侧、怎样执行”。它与用户允许抛弃旧色、对当前整图重新命名的主线分开。此前[有效旧操作复核](PRIOR_OPERATIONS_RESULTS-2026-09-20.md)也分别保存 49 图八组合的 392 次运行、九个 v4 失败的精确求解及旧全库成绩，没有把精确搜索包装成用户的原方法。

### 15.1 单次 Kempe 操作的成本排序与多步修复

[分割成本实验](KEMPE_SPLIT_COST-2026-09-20.md)沿用 160 个固定首次受阻快照，按成本排列已有单次 C 操作的 195 个候选，仍为 95 成功、65 停止；没有新增覆盖。在共同成功例中，净改旧侧数总和从171降到105，全部改侧数266降到200，顺序记录数1058降到765。这些目标不能互换，160 个快照也不是160条完成历史。

[后续进展](KEMPE_PROGRESS-2026-09-20.md)将两件事分开：限定深度的完整双色连通分量 BFS 寻找操作序列；预算搜索另求最终合法标色的最小净改旧侧数。原单次 C 停止的65例中，64例最少需2次 Kempe 操作，1例需3次；全部160例的净改侧成本下界独立核验。65例的最小净成本分布为1侧41例、2侧20例、3侧2例、4侧2例，故“总能至多改3侧”在这些固定起点已被反驳。此前组合及有界搜索已覆盖160例，不能把此轮说成首次实现160/160。

证据：[成本正式报告 v2](../outputs/kempe-split-2026-09-20-v2.json)、[多步正式报告 v2](../outputs/kempe-progress-2026-09-20-v2.json)。初次无 `-v2` 报告仍作历史记录保留；验证器补强后的当前源码复现使用上述 v2，部分旧源码哈希不再匹配。有限搜索有明确预算，截断是未知；诊断和 oracle 不自动进入生产策略。

### 15.2 保守重标障碍、连续重放与旧父图刚性

[保守重标障碍](RECOLORING_OBSTRUCTIONS-2026-09-21.md)先建立16项子侧名对成本表，并在固定外侧相邻的三角链中分离结构类与字面名字成本。真实两行错位 guillotine 家族在最后一刀后有 `6m+3` 个内部侧，对 `6m+1` 个旧侧计费，构造的最小净改旧侧数为 **`2m`**，一次完整双色分量交换即可达到。操作次数为1并不表示只改1个侧；244个去重代价子问题也不全是真实几何。

[连续重放](TRIANGLE_CHAIN_REPLAY-2026-09-21.md)固定 `m=1..8`、8种几何变体、2种继承方向，每种 Python 策略128条历史。原 plain、strip、forest 各128条，加未改网页模块64条，共448条对照均在最后父图前停止；不能因此假设它们已自然到达上述下界起点。

随后独立定义 `forest_then_single_kempe_cost`：保留 forest 成功步，实际受阻时才恢复两个子侧继承态，按成本选择一次完整双色分量交换并提交到真实 `RectState`。同一128条历史全部完成，实际执行 **3712刀、1792次后备修复**，每次后备的净改旧侧成本均独立核验为该步最优；未使用 BFS 或最终目标搜索兜底。结果不证明累计改动最优，也不保证任意 `m` 或任意历史都完成。

[旧父图刚性](TRIANGLE_CHAIN_PARENT_RIGIDITY-2026-09-21.md)进一步证明：外侧名固定时，该家族旧父图恰有6个合法标色，均相差整体名字置换；对**任意合法旧父图标色**，最后一刀最小净成本都为 `2m`，6个目标的成本为 `2m, 2m, 5m+1, 5m+1, 5m+1, 5m+1`。因此更换旧标色不能规避这一下界，但它仍只约束此家族、此计费集合及保留旧色的任务，不是整图重启法的下界或一般四色算法复杂度下界。

证据：[障碍报告](../outputs/recoloring-obstructions-2026-09-21.json)、[对照重放 gzip](../outputs/triangle-chain-replay-2026-09-21.json.gz)、[连续修复 gzip](../outputs/kempe-history-continuation-2026-09-21.json.gz)、[父图刚性核验](../outputs/triangle-chain-parent-rigidity-2026-09-21.json)、[重放摘要](../outputs/replay-novelty-summary-2026-09-21.json)。该阶段检查点为786项 Python 与107项 Node 测试通过；网页模块重放不等于浏览器界面测试。
