# 四进制候选编码接入真实绘图：结果与边界

实验于2026-09-21冻结并运行，2026-09-22完成落盘证据复核与本说明。
发起思路属于 Qinzi27。本轮完成了真实几何到候选约束的接入；没有实现新的
主动选名策略，也没有证明一般四色完备性或确立原创性。

## 实际接入了什么

用户已澄清：图中2表示“非1”的最小显示代表，不是已经承诺使用颜色2。
四个位依次对应名字1–4，`0111`保留候选集合`{2,3,4}`，`0300`才是显式
锚定2。本轮让这个区别真正用于已有绘图输入：

- 从原始笔画和框线导出平面化原子边，保存每条边的方向、左右全局区域、
  输入笔画来源及所属完整母线。整条母线跨交点时左右区域可以变化。
- 真实共边产生异名约束；真实桥两侧同一个面，不错误要求其异名。仅点触
  不产生异名；孤岛虚拟连接不冒充物理接触。
- 同一区域的多个边界游走保持一个区域身份。候选字与两个区域之间允许的
  有向名字对分别编码，不能只靠单个四位数恢复所有接触关系。
- 默认不读输入旧色作为限制，也不把各区域的最小显示代表拼成合法配色。
  原型只传播候选与二元关系，没有主动选择、回溯或oracle救援。

新增实现为`quaternary_geometry_adapter.py`、`audit_quaternary_geometry.py`及
`validate_quaternary_geometry.py`；原有生产策略、网页和冻结数学核心未改。
适配器可直接接入原始绘图，批量入口按笔画集合规范化；单图输出另外保留原输入。

## 固定输入与实际结果

计算前协议：[QUATERNARY_GEOMETRY_PROTOCOL-2026-09-21.md](QUATERNARY_GEOMETRY_PROTOCOL-2026-09-21.md)。
清单在运行前固定全部几何、锚点、资源上限、106个来源哈希及4个输入归档哈希。

4,096个3×3内部单位格线段子集，加全部49个既有诊断/对照绘图，共4,144个不同
输入key（两族共享空框）。每图分别运行单锚、旧双锚；49图另作完整配色往返，
加2个旧错误承诺前后状态，共8,339场景。全局面数2–26；2,662图含真实桥，
147图用到孤岛虚拟连接。去重依据规范笔画集合，不是图同构。

| 模式 | 场景数 | 原型完成 / 未决 / 冲突 | 独立精确核查 |
| --- | ---: | --- | --- |
| 单个有界区域锚定1（主模式） | 4,144 | 0 / 4,144 / 0 | 全部SAT |
| 旧框线两侧显式锚定1、2 | 4,144 | 431 / 3,713 / 0 | 全部SAT |
| 输入已有完整配色，验证往返 | 49 | 49 / 0 / 0 | 全部SAT |
| 旧v2首次错误承诺之前 | 1 | 0 / 1 / 0 | SAT |
| 旧v2首次错误承诺之后 | 1 | 0 / 0 / 1 | UNSAT |

所有8,339场景的几何、元数据、传播和精确证据核查通过，oracle未知为0。
**通过核查不等于原型完成配色。** 双锚的431个完成场景全部只有2个面，输入
锚点已经覆盖全图；49个往返场景也已经输入所有颜色，均不能算新增选名能力。

主模式只固定名字1，名字2/3/4还可全局置换，可靠传播不能无依据指定其中一个。
因而保持未决符合本轮设计，但这些图有完整解的结论来自离线精确见证，不能
由“候选域非空”直接推出。主模式选择最小ID有界面只是稳定初始化，并没有
从任意图识别用户意义上的唯一最内圈。

## 一个真实失败位置给出的结论

旧v2的`guillotine-20261213`第17步图有19个区域、51对真实共边邻接。
输入来源与实际可达旧轨迹绑定在
`examples/quaternary-real-regressions-2026-09-21.json`。

1. 仅保留实际初始化`S0=1,S1=2`时，原型传播后`S10=0111`，显示代表2，
   候选仍为`{2,3,4}`。独立求解器37节点找到完整合法见证。
2. 外部再施加旧算法实际作出的`S10=2`承诺，输入变为`0300`。原型通过
   二元关系传播报告`conflict`；独立求解器29节点确认UNSAT，无解树含2叶，
   保存后再次独立验证。

这清楚区分了两件事：候选编码可以保留用户所说的“非1”，并且传播可以识别
这个已经施加的错误承诺；但承诺之前仍留下了不安全候选2。因此候选不等于
全局可延拓的颜色，四进制表示本身没有解决安全取名。

新原型没有主动提交这个错误颜色，也没有撤销它重新求解；本实验不能称为
新方法修复了旧失败，更不表示这张图本身不可四色。`conflict`可能由某个
二元关系变空触发，不要求每个区域的候选字都变为`0000`。

## 核查深度与成本

初始域笛卡尔积不超过262,144时逐一枚举字面赋值，覆盖全部格线网的两个
常规模式。8,258场景执行了全枚举，共检查5,564,708个赋值，保留61,069个
合法赋值的全部投影；这些是跨场景计数，不是不同平面图数。

另81场景超出全枚举上限，明确记为`not_run`，未宣称枚举其全部解。所有
场景仍经过独立集合实现的传播轨迹核查，合计84,960次删减；未冲突结果
另核查固定点。精确oracle单次上限200,000节点，总计8,338份SAT见证和
1份UNSAT证书，均有结论且与原始共边及显式承诺相容。

4,096条固定顺序格线历史的28,672个前缀引用全部覆盖。每个前缀从本轮
模式初始化重新运行，不继承上一步具体颜色；这不是验证所有添加顺序，也
不是验证新主动承诺的逐步可延拓性（本轮主动承诺数为0）。

报告记录4工作进程的运行阶段墙钟时间26.29秒，不含预先几何导出和最终
总报告序列化；分场景生产时间累计11.64秒、审计累计40.92秒。并行累计
时间不可直接相加作为墙钟时间，单轮数据不能证明普遍性能改善。

几何审计从坐标独立重建旋转序、面游走、外部面并检查原子边交叉/覆盖，
仍共享既有Node平面化输入与部分母线分组代码。坐标检查容差为`1e-5`像素，
沿用900×600框和现有引擎的数值范围；不能推广为任意精度几何正确性证明。
传播审计逐条验证关系合成，但调度修订次数只核对下界，不独立重演工作队列。

本输入含已知旧失败及相关历史前缀，是有限回归与穷举子族，未组成新盲测集。
原型只接入既有二元传播，没有包含旧生产版所有Hall和结构反证规则；因此
完成数不能直接与旧完整求解器的7,069图成绩比较。

## 下一步的具体问题

先固定本版作为表示和核查基线。下一阶段应研究如何在提交之前，通过有证书
的条件传播排除像`S10=2`这样的不安全候选，同时把未找到矛盾的情况继续记为
不确定；另一条路线是保留足够的联合边界状态后恢复一个完整解，并核算成本。
新规则需要另立版本、预声明新输入和逐步可延拓核查，不能把当前诊断结果当作
已完成的选名算法。当前不需要用户补文件或处理运行故障。
