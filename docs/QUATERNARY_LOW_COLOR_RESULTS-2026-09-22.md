# 低色优先后续试验：完成配色、修复范围与剩余障碍

本轮已完成。Qinzi27提出的“通常优先低色”被实现为当前候选按1→2→3→4
尝试；新增条件传播在实际落名前排除能证明矛盾的候选。四进制方案从仅保留
候选推进到实际完成配色，但没有由此获得一般安全选名或四色完备性证明。

## 最重要的对照结果

在相同输入、初始化、选侧与二元传播下比较：

- `plain`：直接提交当前最小候选，后续冲突即停止。
- `guarded`：先临时固定同一个最小候选并传播；确证冲突就排除，未发现
  冲突则提交。若试探还没有完整配色见证，明确标记`inconclusive`。

| 初始化与范围 | 直接低色完成 | 条件传播后低色完成 | 本轮意义 |
| --- | ---: | ---: | --- |
| 单有界面锚1，全部4,272图 | 4,272 | 4,272 | 两版均完成，没有额外修复收益 |
| 旧框线双锚1/2，全部4,272图 | 4,271 | 4,272 | 修复1个旧失败，无新增退步 |
| 此前未见的128输入key，单锚 | 128 | 128 | 两版均完成 |
| 此前未见的128输入key，双锚 | 128 | 128 | 两版均完成 |

后两行是前两行的子集，不相加。新输入没有触发候选排除，不能说新增样本
已经证明条件检查带来普遍优势。单锚从上一轮“全部未决”变为“全部完成”，
主要来自加入主动低色选择；普通低色对照也全部完成，不能全归功于条件检查。

常规两初始化共8,544个场景，新版完成全部场景，实际18,743次提交均经
离线精确求解器核查保留完整解；未知、错误提交和预算未完成均为0。
直接低色共18,735次提交，其中18,734次安全、1次SAT→UNSAT。
这些是同一有限版本与输入范围的结果，不是一般成功概率。

另外两个具名旧诊断各运行两版，总共17,092次正式运行：首错前诊断再次
复现同一修复，不能多算第二张修复图；首错后诊断本来已经UNSAT，两版
均在初始化报告冲突，不属于新方法主动选择失败。

## S10怎样从错误低色转向完成

旧19区域图实际初始化为`S0=1,S1=2`。初始传播保留：

```text
S10 = 0111 = {2,3,4}
先临时检查 S10=2 → 传播矛盾 → 排除2
S10 = 0011 = {3,4}
随后优先提交3 → 继续同样规则 → 完成全图
```

新版该例有10次条件试探、1次候选排除、9次实际提交，9次提交都可延拓。
直接低色版首个提交就是`S10=2`，由有解变为无解；保存提交前完整见证和
提交后完整无解树。这里是提交之前阻止错误，未撤回任何已提交颜色。

如果把错误的`S10=2`作为外部输入事先锁定，新版也报告冲突，不替用户
撤销外部承诺，不把换输入后的成功混成同一问题的成功。

## 成本与成功保持

4进程正式执行记录352.00秒，包含分片写入，不含最终总报告写入和事先
几何生成；同时运行了项目回归，不能当独占机器性能基准。所有场景生产时间
累计199.59秒、审计累计242.01秒，累计并行时间不能直接相加当墙钟时间。
尚未证明普遍加速、内存改善或最少颜色数改善。

本实现接受试探后复用其传播结果，所以在没有候选排除的成功路径上，两版
传播调用数都是`1+实际提交数`，不是每次试探必然多算一遍。被修复旧例
需要继续完成，而基线早已冲突停止，二者总用时也不是同一完成任务的速度比较。

在以下条件下可证明成功保持：相同输入和确定性调度、传播可靠、没有资源
截断。设plain的最终完整配色为C，则C满足它每个提交前缀。逐步归纳，两版
当前状态相同，选同一侧及同一低色；guarded的试探正是plain下一阶段输入，
C仍是见证，可靠传播不会报告矛盾，因此guarded不排除而提交同色，沿相同
路径完成。这不保证plain原先失败的图都被修复，也不证明每次试探存活安全。

本轮提交上限128、试探上限512；后者不小于前者，不会单独截断plain原本
能在提交预算内完成且没有排除的对应路径。时间和其他资源仍是另外的限制。

## 已保存的补充负结果：条件传播仍不完备

新增独立开发诊断`outputs/quaternary-low-color-domain-obstruction-2026-09-22.json`，
不混入正式17,092次运行，也没有据此修改本次冻结规则。

取三角形B,C,D，让A和E都邻接B,C,D，而A/E不相邻，即可平面嵌入的
三角双锥图`K5−AE`。额外给定`D(A)={1,2}`、`D(E)={2,3,4}`。
因为三角形使用三种不同色，A/E只能同用第四色，交集迫使`A=E=2`。
初态有6个完整合法赋值。

按抽象输入顺序先选A并优先试1后，B,C,D,E形成只剩三候选色的K4。
此时二元路径一致仍可未决，新版提交A=1，完整解由6降为0；之后报告冲突。
4个阶段各枚举全部`4^5=1024`个字面赋值，共4,096次检查；完整解集合、
35条独立核查轨迹和首次错误提交均保存。

这是**任意外部候选域＋抽象输入顺序**下的明确不完备例，未建立它由本轮
单锚/双锚初始化、真实绘图与母线调度可达。因而它不能改写正式真实图测试
的结果，却说明“没有发现条件矛盾”不能升级成通用安全证书。
