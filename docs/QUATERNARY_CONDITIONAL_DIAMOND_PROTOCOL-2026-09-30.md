# 共同三色域菱形同名规则：计算前协议（2026-09-30）

本轮在已冻结的三色域奇轮版本上增加有条件的同名推理，并保留低色优先、
母线调度和原有逻辑EQ/NEQ学习。开发动机来自上一轮仍未识别的8个联合试探
缺口；它们已知联合无解，但不代表生产算法曾同时提交这些假设。规则成立的
数学理由、实现的有限穷举、旧状态诊断及真实流程收益分别判断。

## 规则、条件范围与独立证书

在以地图面为顶点、真实共边为边的对偶邻接图中，取四个互异面a、b、u、v。
若a与b共边，且u、v分别都与a、b共边，并且四者的可靠候选域都排除同一
颜色q，则这四面只能使用其余至多三色。a、b因共边占用两个不同色，u、v
都只能取剩下的一色，因此u=v。这一结构常称为菱形K4减一边；实现允许
u、v之间也有真实边，此时推导同名将与该真实异名约束矛盾。

证书保存按输入顺序排列的目标面对、公共边两端、共同排除色，以及完整阶段
文档、候选域和关系矩阵的哈希。只对矩阵仍允许异色的目标对新增同名证书；
已只允许同色或空关系的面对无需重复添加。每个目标对保存一个确定顺序的
证书，不要求枚举全部证书，也不宣称找到全局最短证明。

结构边只接受原始separator真实共边，不把逻辑NEQ、点接触、桥或逻辑EQ改写
成物理边。候选域来自本次阶段文档、初始化锚点、实际承诺以及已独立核验的
传播轨迹；仅检查域值没有证明域的来源。域条件依赖当前承诺及假设，故所得
EQ只属于本次条件传播。不能去掉前提后写成原图的无条件同名关系，不能在
不同假设、前缀或运行之间沿用。

新增传播适配器先执行原有奇轮传播，对未决阶段寻找条件EQ，将证书支持的
EQ加入本次调用的局部副本文档，再重新传播；逐轮保存文档、域、关系矩阵、
证书和新增对。出现终态或没有新增EQ则停止。每轮必须新增至少一对，所有
可能无序面对有限；独立检查器重放每一轮、核查累积及终止条件，防止把漏跑
轮次、重复EQ或未证明域伪装成闭包。预算耗尽只能记未完成。

独立证书检查器不导入原检测器，采用物理公共边及共同邻居的独立枚举检查
证书及所声明模式的覆盖。未找到本规则证书仅表示没有该模式，不等于当前
图可延拓。该推论是基础图着色事实的实现，不声称为新定理或四色定理新证明。

## 冻结和执行顺序

保留前轮全部234项冻结来源的原始字节，新增19项模块、检查器、测试、输入
声明、协议和实验入口，合计253项。计算前manifest绑定逐文件SHA-256清单。
准备阶段仅构造输入、绑定上游报告及检查点身份和哈希、重放已有证据；不得
运行新的生产流程、新规则全量普查或新oracle搜索。小型单元校准只使用
预声明的少量构形，与正式研究分母分开。

代码和单元检查完成后冻结来源、上游输入、完整回归清单、新几何清单、规则
清单与资源限制，再实施正式规则普查、旧病例诊断和完整生产配对。新增输出
使用唯一文件名，不覆盖旧报告；不得根据运行结果临时更改种子、删减失败
输入或拼接版本的成功集合。保存复核不重新运行生产、检测器或精确搜索。

六份直接上游文件分别为奇轮版与原二元扫描的manifest、报告、成功检查结果。
旧奇轮诊断检查点另由manifest的gap_inventory.baseline_reference绑定其路径及字节
哈希。旧诊断覆盖须与原二元扫描的1,814项逐一对应，不能只取8项缺口。实际重放范围和
仅作哈希绑定的范围分别报告，不声称重复执行全部旧支持扫描。

## 第一层：规则可靠性的有限穷举

固定标号顶点a、b、u、v，枚举全部6条可能边的2^6=64个边掩码，即全部
四顶点标号简单图。对每图固定以下21种域模式，不作顶点或颜色对称性约简：

1. 所有顶点共同排除四色之一：4种。
2. 上述三色域中恰放宽一个顶点为完整四色：4个顶点×4个排除色，共16种。
3. 四个顶点均为完整四色：1种。

| 对象 | 预声明数量 |
| --- | ---: |
| 不同原始标号图 | 64 |
| 共同三色域主案例 | 256 |
| 单顶点放宽对照 | 1,024 |
| 完整四色域对照 | 64 |
| 总图／域案例 | 1,344 |
| 案例与全部4^4文字赋值配对引用 | 344,064 |
| 案例与域内笛卡尔积赋值配对引用 | 147,712 |

每例初始关系矩阵仅包含候选域笛卡尔积、精确身份对角线及真实共边NEQ；
不先执行路径一致性，不输入EQ或逻辑NEQ。逐例遍历全部256个文字赋值，先
检查真实边，再检查域；缓存同图的原始合法性只减少重复计算，不改变分母。
对每条报告的EQ检查其保留所有域内合法赋值，保存合法解数及零违例计数。

每个原始图保留四色完整见证。域内本来无解的案例单独标记；其证书的逻辑
保解检验可能为真空，不能计作具有有效解见证的推理改善。每个未报告EQ的
面对，如存在满足原边及域且两端不等的解，保留一个完整反例见证；若域内
有解但所有解都同名，另记为“本域蕴含同名而未报告”。不要求本规则发现
全部同名蕴含，也不把无证书当作有不等见证。

保存复核重新枚举文字赋值并调用独立证书及缺失检查器，不调用检测器、生产
传播或oracle。本层虽覆盖全部四点标号简单图，但只覆盖上述21种域模式及
规定初始矩阵，不是全部15^4非空域组合、一般派生关系矩阵、算法可达状态、
平面地图构造历史或算法完备性的穷举。

## 第二层：旧状态联合诊断

固定上轮全部1,814个无支持色对，沿用原阶段、初始化和实际承诺、两端假设。
基线为奇轮版本已识别1,806项、仍未识别8项；同时保留原二元版的1,803/11
分类，使前轮3项修复不会被重复算成本轮新增。对每项重放旧基础SAT、两端
各自SAT和联合UNSAT的原始证据，并比较旧奇轮与新条件EQ传播。

本部分不进行新oracle搜索，不把旧oracle答案放入生产规则，不修改旧二元
允许矩阵，也不重跑670,916项支持普查。分别记录新增修复、持续未识别、
旧已识别退步、证据错误及资源未完成，并保存完整局部EQ证明链。旧状态的
反事实试探不是新生产版本实际可达状态的全量候选检查，不能计作实际错误
提交被修复，更不能推出任意改选后的全路径安全。

## 第三层：完整流程配对及新几何输入

旧497条输入记录、895个准入初始化场景全部保留，按相同原始输入配对运行
基线奇轮版与新条件EQ版。49项旧几何排除（12导出、37审计）完整保留，不能
算配色成功或失败。是否重新生产基线、哪些旧保存证据复用须分别报告。
每个实际提交前后独立核验原始图可延拓性，分开报告初始化SAT、实际安全、
最终完整合法配色、终止、试探、承诺序列差异和运行成本。

新输入只使用两个既有几何生成家族：

- 断头切割guillotine：种子20263011、20263012，每条历史前5次切割。
- 完整左右弦：同种子，各5条弦；标准库random.Random先抽左端5个整数y，
  再独立抽右端5个整数y，范围20至580，按样本列表顺序一一配对。

固定4条历史、24个从空图到终末的前缀引用，按笔画集规范化去重得到预期21
张输入；实际键由manifest确认，并与全部旧497记录比较。预期只有空前缀
重叠，若实际不同必须按真实键报告，不能强行记为20张新增。新输入每前缀
分别使用两个标准初始化，不继承颜色、域或条件EQ；保留所有导出和审计失败。
若20张均准入，新增40场景，与895旧场景合计935配对；这是计算前预算而非
成功结果。新种子和相关前缀仍不是独立新图族或普遍成功概率。

本轮不增加同心多边形，不改前轮几何精度排除，也不穷举其他合法插入顺序。
每条历史的所有前缀必须逐一检查，终末成功不能替代中间前缀结果。

## 资源限制与结论边界

面数准入上限40，源笔画上限80，每运行实际决策上限128、试探上限8,192，
初始化文字赋值审计阈值262,144，每条原始精确查询节点上限200,000。局部
EQ闭包遵循单调新增面对的有限停止条件，轮次及新增对完整落盘并独立核对。
预算不足、未执行、证据错误和未知必须单列，不能计为UNSAT或通过。

oracle仅依赖原始真实邻接、初始化锚点及实际提交，离线检查而不提供生产
颜色、候选、下一步、目标解或失败救援。逻辑EQ/NEQ、传播域和条件EQ不得
偷渡进原始精确查询前提。共享解析、几何适配及旧传播重放的依赖范围明确
列出，独立检查不等于完全独立的软件栈。

最终分别报告规则保解、旧假设组合诊断、实际每步可延拓性、完整流程、
几何排除、未知和成本。若路径变化，旧缺口减少不证明新路径全部候选安全；
需要另立新路径普查。全部有限通过仍不能代替一般覆盖性、正确性、状态
衔接和终止论证，也不单凭实现或修复数量宣称原创性已证。
