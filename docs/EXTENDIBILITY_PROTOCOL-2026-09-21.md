# 当前结构重启版的逐步可延拓检验：计算前协议

本轮针对 Qinzi27 的原线侧重启主线：每次加线后按当前几何重新命名。
冻结 `mother-peer-structural-reuse-v1`；不输入上一张图的名字，不让精确求解器
参与取名或失败救援。以下范围在正式候选运行前固定。

## 输入、顺序与资源

1. **整数格矩形切分**：3×3 单元格，初始一个矩形，每刀选择现有矩形及其
   严格内部整数横/纵坐标，贯穿该矩形。穷举长度 0 至 5 的全部有序合法历史。
   每刀保留父矩形、两个子矩形和坐标证据。生成器先得 2,145 条历史、357 个
   按输入线段集合去重的几何、12,173 个历史前缀引用。
2. **单位格线段子集**：同一个 3×3 格的全部 12 条内部单位边，穷举 2^12=4,096
   个子集；每个子集只选固定线段编号递增加入的一条历史，**不穷举所有排列**。
   可含非矩形区域、悬线、桥和孤岛。所有中间子集仍在全清单内。
3. 画框固定 900×600，整数格坐标缩放为间距 300×200。两族可能重叠，不能
   把它们说成独立随机试验；也不能把这两族称为所有平面地图的穷举。
4. 几何去重仅按规范化无向输入线段集合，不做同构、旋转、反射或共线段合并。
   所有原历史和前缀别名保留。算法只读取当前规范几何，因此可按几何复用运行。
5. 历史/子集生成上限为 1,000,000；精确核查每次上限 1,000,000 搜索节点；
   全赋色枚举每图上限 65,536 个初始化后字面赋值。使用单进程。
   穷举族至多 7 / 10 个面（含外面），两个相邻初始化面固定后均在赋值上限内。
   任何资源截断为 `unknown` 或 `not_enumerated`，不得记为无解或穷举通过。
6. `prepare` 先独占写入 manifest，绑定源文件、实际完整输入、资源与策略；
   `run` 检查绑定后执行，结束再核对。原冻结源和历史报告保持原样。

## 三层核查

**推导可靠性**：既有独立集合实现重放所有结构证书、Hall 删减、二元路径传播
及选择顺序；新检查还枚举满足初始化的全部真实合法赋色，确认每个传播固定点
保留所有符合当时累计承诺的解，确认实际学到的异名关系没有删除合法解。
独立重放检查传播的单调删减，因此最终保留也意味着中间删减保留。

**逐次落名**：先完整运行候选，再以原真实邻接及显式承诺调用独立 MRV 精确
求解器。检查初始化，以及每次主动承诺前后的解存在性。结构推导产生的域、
异名关系及最终目标色均不传入 oracle。SAT 保存完整配色；UNSAT 保存覆盖所有
可用字面颜色的搜索树，另一验证器逐边、逐锚点、逐分支与冲突叶复核。
没有颜色轨道压缩；两个相邻初始化名字 1/2 只利用全局颜色重命名的对称性，
其余名字仍逐字面枚举。

**完整流程**：逐图记录完整配色/冲突、实际承诺数、源/轨迹哈希、每步见证与
历史全部前缀结果。出现第一次 SAT→UNSAT 时保存原几何、全运行轨迹、候选域、
选择依据、此前承诺、SAT 见证和完整 UNSAT 证书，再做保持输入范围的缩减。
没有找到实际失败时不制造缩减结果。

## 独立性和解释边界

- oracle 与 UNSAT 复核器不导入生产着色或传播代码，只共享输入验证/规范化。
- 几何仍来自现有 Node 引擎；Python 重建旋转系统与面轨道交叉检查。双方共有
  输入线段，生产/审计也共享既有 `PlaneMap` 表示，不能声称整个软件栈完全独立。
- 已知旧版的真实失败作为核查器阳性对照；修复版在同图的路径作对照。
  这些开发材料不混入新穷举成绩。
- 任意预着色的条件障碍与当前算法实际可达失败分开。数学上说明检查不充分，
  不等于当前版本在这些输入上已经失败。
- 本轮不修改策略，不宣布一般安全性、复杂度改进、原创性或四色定理新证明。
  633 构形尚未接入。

结果将另写 `EXTENDIBILITY_RESULTS-2026-09-21.md`，保留本协议的计算前状态。
