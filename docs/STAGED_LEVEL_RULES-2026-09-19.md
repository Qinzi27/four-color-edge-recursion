# 初始化—分级统一规则 v3：运行前规格

日期：2026-09-19。发起思路：Qinzi27。
策略标识：`stage-anchored-level-sides-v3`。
核心入口：`fourcolor/staged_levels.py::restart_staged_level_names`。

本稿在完整重跑之前固定规则；不根据运行成败逐图选择首侧或更换策略。
v1/v2、旧实验、原始手稿和网站保留。结果另写独立报告，不回填本稿的预期为事实。

## 1. 本次只统一一个缺口

用户的初始外框 `(1,2)` 表示外侧 1 与尚未细分的内部 2，
不表示最终图左上角的一小侧必须永远为 2。
旧 v2 一开始就预绑定最终框内首侧 2，可能与后来选择的首母线保留侧叠加成额外预着色。

v3 取消这个预绑定，先只固定外侧 1，再由首个合格母线的实际当前侧选择一个 2 锚。
等级、整母线、当前分段侧名、当前边界来源、Hall 和二元关系过滤全部保留。
不是通过失败后试另一个颜色，亦不接收旧图解作为输入。

## 2. 预先固定的规则

1. 从当前完整几何恢复外框、完整直母线、接点区间和侧身份。T/X 中途接点不终止母线。
2. 仅固定外侧为 1，进行既有 Hall/二元关系过滤，保存这一独立阶段证书。
3. 首母线候选同时满足：
   - 母线两个真正端点均接外框；
   - 存在非桥当前区间，且该区间至少一个未定侧沿**真实外框边**共边。
   只有端点接触不够；记录实际外框边 ID。
4. 在合格母线中按原等级/数值几何端点顺序选首条；
   在其区间内，仅从上述真实外框邻侧出现位置中选择。
   沿用原优先级 `(4−|D|, 未定不同邻侧数, q, 既有闭合支撑平局项)`。
   `q` 仍计该区间全部未定侧的 `4−|D|`，不只计初始化候选。
   区间内同分保留原 occurrence 次序；跨区间同分按 `t0, dart`。
5. 所选侧的外侧单锚候选为 `{2,3,4}`，取最小名 2。只固定这一个当前侧，不同时固定最终左上内侧。
6. 若几何中没有任何上述合格贯通母线，预先规定采用外框首段内侧为 2。
   模式记为 `frame-interior-no-eligible-through-mother`。
   它用于空框、只有桥、孤立内环、折线等无合格贯通母线情况；不是运行失败后的兜底。
7. 此后完全沿用 v2 的整母线调度、当前边界过滤和 `min(D)`。未知等级保留 `None` 并继续排序，不要求同组具有相同母线结构。
8. 每次加入线后均从当前完整几何重新运行，不继承上一次的最终色承诺。每张图只试一次；冲突就记录冲突。

新增证书 `initialization` 保存模式、候选母线、所选母线/侧/dart、真实 frame 边、初始域和外侧锚。
`initial_anchors_by_dart` 只有外侧 1；首个 2 作为 `trace[0]` 的 `initial-retained-name`，有独立传播阶段。
所以本版“主动选择数”包含一次初始化选择，不能未经换算和以前的主动选择数直接比较。

## 3. 首个 2 的安全性：有条件的规范化引理

设当前地图已有某个合法四色着色，且通过全局颜色置换使外侧为 1。
若侧 `F` 沿真实外框边共边，则 `c(F)≠1`，故 `c(F)∈{2,3,4}`。
取一个保持 1、把 `c(F)` 映射到 2 的全局置换，所有共边异色仍成立。
因此，仅增加 `F=2` 不会消灭所有原有合法解。

这个论证不依赖 `F` 位于左、右、上或下，也不需要试算三种颜色。
但它不允许同时随意固定第二个内部侧为 2，也不证明之后每次贪心选择都安全。
它以“已有合法四色着色”为前提，不是单独证明四色存在性。

首条完整分割在粗图上可以解释为 `(2,3)`。
其最终当前剖面可能有很多不同区间，因此不把“另一整侧均为 3”写成最终图的硬约束。
`historical_frame_pair` 和 `coarse_split_pair_unordered` 是语义说明，不参与过滤。

## 4. 分级与算法的边界

等级仍由真正端点支撑派生；框为 1，未知保持 `None`。它只控制处理顺序，不产生永久禁色。
内部能够复用 1 与否，依赖当前真实邻侧及已核验的关系约束，而不依赖祖先曾用过的数字。

该版本仍是“在当前完整图上调度母线分段剖面”，不是唯一历史的粗到细重演。
最大直母线的端点 ID 也不是跨延长/合并操作的持久历史 ID。
无贯通母线模式应单列，不宣称所有地图均已获得同一种母线构造历史。

既有闭合支撑项只作平局辅助，本轮未增加找闭环分组的新算法。
二元关系过滤涉及全体侧对，不能称作严格只看两个端点的算法。
四色仍是输入色盘；本轮检验的是明确规则的有限表现，不是一般完备性证明。
