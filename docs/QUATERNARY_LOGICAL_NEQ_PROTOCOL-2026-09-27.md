# 四进制逻辑异名接入：计算前协议

本轮在发布提交 `06e0084a89b6efaed6ed42d06617427bfd1cf326` 已推送后实施。
发起思路属于 Qinzi27。本实验检验已有原始图反证证书接入四进制流程的效果，
不将既有反证规则、S1≠S10 关系或四进制编码称为新定理。

## 1. 唯一主要改动与数学依据

保留旧奇环 EQ、母线选侧、最低候选优先和仅试探准备落名候选的规则；
新增独立 `quaternary-low-color-logical-neq-v1`，将有原始图证书的异名对
放入 `different_names`。该数组与真实 `lines` 分开，不增加物理共边、
不合并面身份、不改变桥或点触的语义。与上轮全候选扫描不混合。

对输入面顺序中的每个非物理邻接无序对 `(u,v)`，调用既有
`fourcolor.structural_name_relations.refute_same_name`。仅输入原始简单
NEQ 图、面数及该对，不传入锚点、候选状态、EQ、其他学习 NEQ 或旧配色。
假设 u=v 后，若两类都是一个真实约束三角形的共同邻类，则四色下必同名，
可作逻辑类合并。每条商图边都有原始边见证；同类内部存在原始边，或出现
五个两两相邻的类，均反证最初假设。每次合并减少类数，故单查询终止；
没有矛盾只记 `inconclusive`，不推出同名可延拓。

这些是已知初等四名推理及仓库已有实现。旧19面图的该关系已有结构反证
单测；此前保存的13步颜色规范化证明另作解释材料，本轮无需改写实际锚点。
学习结果绑定完整原始输入哈希，但证明前提只含原始真实 NEQ。
所有对的阳性/未决证书均保存，不把已学关系反馈给下一对的证明器。

独立检查器重建原始边，核对全部非边对覆盖，并用既有独立集合证书重放
逐份核查。新增关系进入二元传播初始矩阵，整个试探/提交/删色流程保留。
单例仍是推导状态，只有初始化及真实主动提交成为锚点。

## 2. 开发样例与新输入边界

19面已知缺口、六点正例及既有抽象错误顺序均可用于开发单测，属于已知校准，
不计为未见输入上的发现。开发测试在正式来源冻结前完成并注明。
新几何只由预声明参数生成，不依据算法结果筛选：

- 旧全候选清单的403记录全部作为回归；保持19项几何排除及其原因。
- 随机种子20262701、20262702，各生成5步矩形切分及5条完整弦。
- 双环5/6/7边形，各采用31°角偏置，保留所有真实线段添加前缀。
- 合计声明7条新历史、81次前缀引用；按完整绘图key去重并报告与旧库重合。
  每个前缀重新标准初始化，不继承上一个图的颜色。

每个准入几何分别运行单有界面锚与旧外框双锚模式；旧抽象诊断保留原模式。
这些是同族新种子和角度，不是独立图族或独立随机成功概率样本。
不得把重复前缀/共享空图加作严格新增图。

冻结前仅作坐标/几何准入检查已发现：75张新声明图中45张通过，28张几何
审计错误、2张导出错误，均未运行配色或oracle。保留31°及所有前缀，不按
准入结果更换角度或删除记录；加上旧19项排除后预期共49项。预计477记录、
428条准入记录（含1抽象）、855配对场景，以冻结清单为准。受排除影响的
新历史须标为准入未完成，不能算全部前缀配色成功；精度修复另立试验。

## 3. 固定比较和资源

比较原奇环 EQ 与新逻辑 NEQ；不重跑昂贵的全候选版来混淆单项改变。
每个场景两生产器先完成，随后才运行离线审计。旧767场景的旧策略完整
envelope 必须与上一轮归档逐字段一致；两版均使用8192试探上限。

固定上限：40面、128次实际落名、8192次候选试探；每次原始精确查询
200000搜索节点。初始化字面赋值数不超过262144时，全枚举原始合法解并
核对每个兼容阶段仍保留；超限明确记未全枚举。证明器按全部非边对执行，
单查询强制合并最多 n−2 次，没有外部精确求解或递归颜色分支。
这不是关于整个实现的低复杂度或墙钟时间保证。

来源/原始归档哈希、全部输入、顺序及上述预算在正式运行前写入唯一新
manifest；之后不改规则或筛选样本。超限、异常、证据核验未完成分别保留，
不得计作无解或通过。checkpoint 用唯一新路径，不覆盖旧轮结果。

## 4. 三层核查

**规则可靠性。** 原始六点图为 K4(u,a,b,c)，另加 v-a/v-b/v-c 和
w-u/w-b/w-c，共12条边。穷举其4096个有标号边子图及每图全部4096个
字面四名赋值，共16777216图-赋值对，不作颜色对称商。逐图核对全部学到
NEQ在每个原始合法赋值成立，保留阳性数量及阴性同名见证。
完整母图有24个合法赋值，v=u、w=a，因此非邻接 v≠w 是非真空正例。
该有限家族只核查实现，不证明关系学习完备，也不声称穷举全部六点图。
单元测试另覆盖缺边、伪造证据、桥/点触、覆盖缺失及预算截断。

**每步可延拓性。** oracle 只读原始真实邻接、原始锚点及累计真实提交。
单个试探核查再加该假设；绝不注入学习 EQ/NEQ、传播后的候选域或推导
单例。先查初始SAT，再对每次提交前后核查，分别记录safe、unsafe、unknown
和preexisting-unsat。发现首错保留此前完整见证与之后独立UNSAT证据。
学习关系和每条传播删减另经证书及字面集合轨迹重放核查。

**完整流程。** 报告各版完成、冲突、未完成；逐对分为共同成功、修复、
退步、持续失败、未知；检查所有声明历史前缀。分别统计学习关系数、
初始候选削减、实际承诺/试探/轨迹次数、承诺序列与最终颜色是否变化。
严格新key子集另列；学习查询、证书检查和oracle成本分别记录。
有限全部完成不能推出一般延拓保证，最低候选优先也不是最小色数算法。

## 5. 落盘复核、独立性和报告

保存全部学习查询、完整传播阶段、真实决策、原始SAT/UNSAT证据及资源
记录。结束后只读检查器重新核对完整覆盖、来源和checkpoint哈希、关系
证书、字面传播、实际承诺及精确证据树；不得重新生产或搜索来补缺失证据。
明确共享几何解析、原有证明器/检查器和二元关系核心的范围，不声称所有
组件完全独立。规则有限枚举可以独立重算，重算不参与生产选色。

最后运行完整Python单元测试和 `scripts/validate.py`，输出使用本轮唯一
文件名。结果报告须区分：已知S10缺口是否补上、是否真的改变实际落名、
是否新增完成收益、成本与新的未决边界。即使S10提前删色，也不能声称
修复了一次实际错误提交，因为旧调度从未提交该坏候选。
