# 逻辑异名版二元联合支持扫描：计算前协议（2026-09-29）

本轮固定 `quaternary-low-color-logical-neq-v1`，检查已经到达的持久状态中，
二元关系矩阵仍允许的两个未决面取色组合，是否能同时扩展为原始图的完整
合法四色赋值。上一轮单候选普查不能替代这项合取检查：分别存在支持
`u=a` 与 `v=b` 的完整解，不保证存在同时支持两者的同一个完整解。

本轮是离线反事实诊断，不是新的生产算法版本或新图盲测。低色优先、母线
调度、关系学习、条件试探和实际承诺均不改变；精确求解器（oracle）与诊断
结果不反馈给生产端。发现无支持色对也不直接修改二元矩阵或冻结运行历史。

本轮使用 9 月 29 日单候选扫描的 manifest、正式报告及成功保存证据复核，

476 条几何记录和 1 条抽象记录；428 条准入记录包含 427 张几何输入的两种

`odd-cycle-eq` 对照不扫描，不把前序两版的 1,710 次运行当成本轮分母。

49 条几何排除原样保留：12 条导出错误、37 条独立几何审计错误。它们不
产生本轮配色状态或查询，不能隐藏、计作着色失败，或经修复后混入同一
冻结实验。31° 几何精度问题另行处理。

先保持旧 208 项冻结研究来源的原始字节，新增本轮扫描核心、独立检查器、
运行入口、三份对应测试及本协议，共冻结 215 项来源。准确文件清单与
SHA-256 写入新 manifest。本协议在新查询之前冻结，此后结果另写报告，
不向协议追加事后发现。所有旧来源、正式报告和检查点均保留。

prepare 必须严格绑定上轮 manifest、报告、check 及每个检查点的字节哈希、
记录身份、场景覆盖、原始输入和生产 envelope；核对上轮复核的证据有效、
准入执行完整与精确查询有结论标记。对选中的 855 条运行，逐项重放上轮
单候选扫描的保存证据，核对全部目标覆盖和精确见证，不重新搜索。上游
生产证书和规则证据沿已通过的 prepare/check 记录绑定，本轮不声称重新
执行生产端证书全审计、规则穷举、关系学习或完整着色生产。

## 持久状态与二元目标

持久状态为初始 phase 0 及每个实际事件的 `after_phase`。实际提交后的
trial 是持久状态，被拒绝的 trial 不是；不得仅按 `phase.kind == main`
筛选。按事件顺序重建初始化锚和实际累计 commit，reject 只保留已经记录
的删域，不增加实际承诺。阶段衔接、最终阶段及完整状态覆盖由旧记录和
本轮清单重建严格核对。

对当前状态的面次序取 `i < j`，仅在两端候选域大小都大于 1 时检查。
在这两个当前域的笛卡尔积中，只保留最终二元矩阵 `R[i][j]` 明确允许的
有向颜色对 `(a,b)`；反向矩阵应为转置，不另计反向目标。同一无序面对
可以有多个颜色对目标，按固定面序、颜色序排列。

矩阵已排除的 75,090 个色对不提交 oracle，避免重复发现已知邻接或传播
冲突。这个排除是目标定义，不是额外证明这些色对的逻辑可靠性；其传播
可靠性仍依据冻结上游审计。逻辑 NEQ 与物理共边分开，两个面不必物理
相邻。面身份不合并，桥或点触不自动形成真实 separator NEQ。

任何单例端点都不纳入二元目标，包括推导单例和显式锚点；本轮也不重复
单候选普查。因此结论只覆盖“双方均未决且矩阵允许的色对”，不得扩写成
所有面之间、所有四名组合或任意更高元组合的支持检查。全部 4,518 个
状态仍各有基础查询，包括 1,500 个无待查色对的状态。

## 原始精确查询与支持分类

设 G 为冻结原始图，S 仅含初始化锚和此前实际提交。每个状态检查
`E_G(S)`；每个色对检查 `E_G(S ∪ {u=a, v=b})`。精确输入只含原始真实
separator 邻接、S 和该次字面假设。已学习 EQ/NEQ、传播域、推导单例、
二元矩阵和拒绝删域均不能作为 oracle 前提。矩阵只定义待查列表，不为
求解器增加约束；不得把旧完整配色、目标解或别的查询答案当成选择依据。

每次精确搜索最多 200,000 个节点，保存完整 SAT 见证、UNSAT 树或 UNKNOWN。
仅在同一运行中按相同原始图和准确字面承诺集缓存，不跨运行或不同图混用。
每个基础、二元目标和新增单端点引用必须指向与自身原始问题完全匹配的
已保存证据，不因缓存省略某项查询义务。

- 基础 SAT、二元目标 SAT：`supported`。
- 基础 SAT、二元目标 UNSAT：`unsupported`。
- 基础或二元目标 UNKNOWN：`unknown`；超时、预算耗尽不能记为无解或通过。
- 基础 UNSAT：`preexisting_unsat`，不能归因于新假设的色对。

基础状态及目标状态分别统计，不以二元目标的 SAT 见证代替缺失的
基础记录。保存证据验证成功和搜索有结论是两个不同判定。

## 无支持色对的额外诊断

仅当基础 SAT、二元目标 UNSAT 时，额外分别检查
`E_G(S ∪ {u=a})` 与 `E_G(S ∪ {v=b})`，仍使用原始真实邻接和相同资源
上限，保存或准确引用完整证据。这两次查询用于确认是否是“单独均有
支持、合起来无支持”的二元障碍，不能由上一轮总计或两份不同完整解
直接推得合取支持。端点 UNKNOWN 单独保留，不称两端均可行。若端点
UNSAT 与已绑定的前轮支持证据矛盾，保留不一致并使验证失败。

随后复制该冻结持久阶段的 document，一次添加两个字面假设 `u=a` 和
`v=b`，调用冻结逻辑 NEQ 条件传播器作离线诊断。保留该阶段原有 EQ、
`different_names` 和可靠拒绝状态；不以 outcome 域重新制造输入，不再运行
关系学习或整个着色器。这些关系只用于检查现有条件传播能力，仍不进入
oracle 前提，也不更新真实运行的实际承诺。

完整条件传播轨迹由独立检查器重放。矛盾标为 `conditional_refuted`，
未决标为 `conditional_inconclusive`；条件 solved 与原始二元 UNSAT 冲突
必须记录并使验证失败。发现二元障碍、条件传播缺口和真实策略错误是
三种不同事实：本轮两个假设不是生产器曾经同时提交的事件，也未测试
任意改选后继续执行的全新路径，不能把无支持色对计作实际错误提交。

## 汇总、历史与解释边界

分别报告几何／抽象、初始化、回归输入组／前轮新增 key 组、基础状态、
面对与色对分母、支持分类、端点支持结果、条件诊断，以及查询／证据
复核成本。计数单位是“运行 × 持久状态 × 无序面对 × 有序色对”，有
同图、初始化和历史前缀相关性；不能当作独立图数、独立图族或普遍
成功概率。前轮新增 key 本轮已是已知输入，不称新盲测。

每条运行的最早无支持目标按实际状态序、面序和颜色序确定，保留原始
输入、当前承诺、两端候选域、二元关系和全部证据。最早发现不表示
包含极小或全局最小反例；如后续缩减，另列实验并保留合法几何／构造
历史条件及原始实例。

沿用 62 条原始历史、680 个前缀引用。一种策略的两模式投影共 124 条
历史记录、1,360 个引用；其中 118 条历史记录完整，6 条受几何排除而
不完整，对应 1,300 个可扫描与 60 个被排除的前缀引用。三条多边形
历史未覆盖全部前缀的限制持续保留。重复前缀不是不同图，各前缀原先
分别初始化，不代表配色在历史中连续继承。

即使所有目标均有支持，也只确认这批冻结实际状态中所声明二元投影
的延拓事实，不保证多个色对可同时相容、三个及以上面的联合选择、
任意新状态或任意合法历史的安全，也不证明一般完备性或新的四色定理。
若发现无支持色对，它首先说明当前二元闭包尚未表示相应全局限制；
是否需要改动生产策略、增加有证书的条件推理，须依据诊断与成本另立
版本验证，不能把 oracle 当作本方法的一部分来宣称算法已改善。

## 复核、资源与完成判定

复现入口为 `scripts/validate_quaternary_logical_neq_pair_scan.py`，按
prepare → run → check 执行，准确参数以该冻结版本帮助为准。每个原始
记录保存一个唯一检查点，含完整场景覆盖、逐目标扫描证据或明确错误；
只可在同一个冻结 manifest 下接续，不覆盖既有证据。输出文件使用本轮
pair-scan 标识和日期／唯一后缀，与同日单候选文件严格分开。

最终 check 重新从冻结生产来源构建完整 inventory 和实际承诺，逐项
检查所有目标、原始精确证据及条件轨迹，重算分类、分母和总计；不调用
生产器、学习器、传播器或精确搜索。215 来源及所有输入哈希在 prepare、
run、check 中一致。只核对总数、哈希外观或结果状态而不检查完整证据
不能记为成功。

分别报告证据复核成功、准入扫描完整、精确查询有结论及全部声明色对
受支持等状态。存在 UNKNOWN、处理错误或未完成时原样保留，不拼接
不同版本成功集合，不将未完成伪装为无解或通过。执行全部
`python -X utf8 -m unittest discover -s tests -v`，以及
`python -X utf8 scripts/validate.py --output <唯一新验证报告路径>`。
速度比较优先报告确定性的节点、调用及轨迹量；未控制并行、缓存及
机器负载时，墙钟耗时不构成总体提速证据。
