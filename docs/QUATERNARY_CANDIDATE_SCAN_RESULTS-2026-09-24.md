## 检查的问题

当前候选域 D(v) 保留 c，不等于在原图 G、已有真实承诺 S 下存在一个
满足 v=c 的完整四色解。本轮查询的是 `E_G(S ∪ {v=c})` 是否为空。
若为空，说明当前域保留了一个无全局支持的候选；若它没有被实际提交，
还不能称为本策略错误提交。再对这个候选单独运行原有条件传播，区分它
能否在提交前被现有规则拒绝。

图顶点为面、边为真实共边 NEQ，即对偶约束图。逻辑同名不增加几何边，
推导出的单例不增加 oracle 承诺。单例面不重复逐色查询，其状态仍有基础
SAT 核查及上轮规则/传播审计。

## 两类可直接解释的结构原因

第一类是原图蕴含的远端逻辑异名：**S1≠S10，但两面不直接共边。**
这是对保存证据的事后数学分析，不是新增生产规则。
假设 S1=S10，先将共同颜色命名为 1。S1、S0、S12 是原始真实邻接三角形，
可对剩余颜色统一重命名为 S0=2、S12=3。这是在证明原图关系，不是允许实际
运行随意改写已经承诺的颜色。原始边随后逐个唯一强制：

```text
S11=4 → S14=2 → S15=4 → S13=2 → S16=3 → S9=4 → S8=1
      → S7=4 → S18=1 → S6=3 → S5=4 → S3=3 → S17=4
```

最后 S2 的真实邻面 S1=1、S0=2、S3=3、S17=4 占齐四色，矛盾。每一步的
三个已色阻挡邻面与最终四个邻面均已直接核验原始边，完整明细保存在案例包。
由此可证这个原图蕴含逻辑 NEQ(S1,S10)；它不能被冒充物理共边写回几何。
扩大共同奇环长度本身不会自动实现这一不同的推导机制。

第二类是没有对未选面充分试排：phase 1 的 S3 仍为 `{1,2,3,4}`，但其
2、3、4 各自已有被独立核验的条件矛盾轨迹，因此可以安全删除并推出 S3=1，
再由原始共边排除 S4=1、S5=1。现有策略只试探当时调度选中的面，尚未执行
这轮全域试排。此论证说明两处缺口有共同修复入口，不代表已经实现或测得收益，
也不能声称它同时解决 phase 0 的 S10=1。
