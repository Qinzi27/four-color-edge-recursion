## 1. 对象与命名：线在前，侧空间由连接导出

有向线段 e 的名字为 N(e)=(a,b)：左侧符号 a，右侧符号 b。
反向名字为 (b,a)。物理线段 ID、名字、侧空间身份、构造历史是不同对象；
多条线可以同名，多个不相邻的侧空间可以复用同一符号。

同一侧沿接点继续行走时，符号必须一致。程序先从已提交线名读取一致的侧轨道，
再判断新连接影响哪一个旧侧。填色只把这些已确定的符号显示出来，不调用旧的面贪心算法。

代码内部使用 0,1,2,3，页面显示 1,2,3,4。初始画框外侧为内部编码 0，内侧为 1。
这是实验的初值与候选集合，**不是从命名一致性推导出的四色上界**。

## 2. 什么操作才算完成

网络有限，所有交点显式作为顶点。一次操作只允许：

1. 一条简单折线路径：两个不同端点在旧真实网络上，内部不接触旧网络，不自交或重叠；
2. 一个与旧网络完全不相交的简单闭环，可从空白开始。

自由端保留为草稿；途中遇到旧线须先结束这一笔，再另起一笔。闭环接触旧网络的
更广泛操作暂未实现，不能把所有闭合走法都称为本程序支持的独立闭环。

**拓扑命题。** 记 F 为包含外部的侧空间数，C 为真实网络连通分量数。
Euler 公式 V−E+F=1+C 给出：

    ΔF = ΔE − ΔV + ΔC.

锚定路径若有 k 条新段，则新增内部顶点 k−1；拆分旧边加入端点时，E 与 V 同增，
不改变 E−V。因此 ΔF=1+ΔC：

- 两端原来在同一连通分量：ΔC=0，故 ΔF=1；
- 两端原来分属不同分量：ΔC=−1，故 ΔF=0，是桥，不分割；
- 独立简单闭环：ΔE=ΔV、ΔC=1，故 ΔF=1。

这些是既有平面拓扑原理的直接应用，不是新定理。隐形辅助桥只方便侧轨道遍历，
不能作为真实锚点，也不计入这里的真实连通分量。

## 3. 单步直接选标定理

前提：旧线名一致，真正分隔不同侧的旧线两边异标；所有旧符号在 K={0,1,2,3} 中。
一次合法操作把符号为 a 的旧侧分成两个新侧。选择其中一个新侧 S，另一侧继承 a。
T(S) 是沿 S 的旧真实边界看到的、**原父侧之外**的对侧符号集合。

如果 |T(S)|≤2，则取

    c = min(K \ ({a} ∪ T(S)))

必有定义。将 S 的全部线侧记录统一更新为 c，另一子侧保留 a，其他旧侧不变，
就得到合法的四符号线名。

**证明。** 至多排除 a 和 T 的两种符号，四元素集合至少剩一个 c。
逐类检查所有边界：

1. 未涉及 S 的旧边，其两侧名字不变；
2. S 与原父侧外部的旧边，其对侧符号属于 T，故不等于 c；
3. 新分割线，以及原本同属父侧但现在两岸分开的旧桥，其两边是 c 与 a，二者不同；
4. 每个子侧的全部边界侧统一使用一个符号，所以接点转角的一致性仍成立。

四类覆盖所有线。故新的命名合法。□

这一步允许改变被选子侧所对应的旧线的某一项，并不是“所有旧线的两个项都冻结”。
例如旧线 (a,b) 的一部分可能变为 (a,c)；另一侧 a 及其他侧空间不变。
保留递归历史和反向语义，才能准确描述这件事。

## 4. 固定旧标记时，什么时候一定停住

旧命名合法意味着 T 不含 a。于是，在四符号约束下，存在上述继承式延拓，
当且仅当两个新侧中至少一个的 T 不含其余三种符号中的某一种，即至少一侧 |T|≤2。

若两个 T 都含 K\{a}，每个新侧在冻结外部后只能使用 a；两侧相邻，不能都取 a。
所以不仅本次最低符号选择失败，**任意保持外部旧符号的该次分割赋标都不可能**。
这仍不是原地图不可四色标记，也不是否定可能存在其他构造历史或先改外部标记。

## 5. 对当前策略的四步反例：同一目标图，不同历史

坐标画框为 900×600。定义四条路径：

```text
A = [[300,0], [300,600]]
B = [[300,400], [900,400]]
C = [[150,0], [150,600]]
D = [[150,200], [300,200]]
```

程序的确定性约定：合格子侧优先选 T 最小者，再按本轮几何侧序号打破平局，
最后选最低可用符号。平局约定是本次实现提案，不声称由提出者原始记号唯一决定。

| 输入历史 | 各步结果 | 意义 |
|---|---|---|
| A→B→C→D | split, split, split, blocked | 当前策略不能处理任意合法输入顺序 |
| A→C→D→B | split, split, split, split | 同一个最终目标线集有成功历史 |

第一条历史中，D 所在父侧内部编码 a=2。两个子侧的 T 都为 {0,1,3}，
所以两侧候选都为空。D 不提交，原线名保留；屏幕用虚线显示这次受阻请求。

这个例子比“给一个任意预标地图再让它失败”更直接：受阻前的所有标记都由本程序
从空画框正常生成。但它仍然不能证伪“存在某个成功顺序”。

高级图库另保留六边形预标阻塞例，明确标成显式预标输入，不冒充当前选择规则生成。

## 6. 缺口的精确表述

需要证明的不是局部判据本身，而是类似以下带量词的命题：

> 对每一个指定范围内的有限平面线网，存在一个由允许的锚定路径、连接桥和独立闭环
> 组成的构造顺序，使得每次真正分割至少有一个子侧满足 |T|≤2。

还必须区分两个版本：允许任意合格符号/子侧选择，或强制本程序的最低符号和平局约定。
前者即使为真，也不能自动证明后者；存在顺序也不自动给出一个不用搜索的找顺序算法。

已知四色定理可以保证最终地图存在合法颜色，但不能直接保证这个更受限的中间历史。
用最终四色解反过来指定顺序，再宣称该顺序独立证明四色，属于循环论证。

一种独立研究工具是逆合并。面邻接图中把 v 合并进邻接的 u，保留 c(u)，冻结其他颜色，
合法当且仅当 N(v)\{u} 中没有颜色为 c(u) 的顶点。它反向对应一个 T 至多两色的分割。
但简单邻接图可能合并多段共享边界；仍须核查几何上是否是一条允许的路径。
这个研究 oracle 与生产命名算法分开，不用它给画板偷偷求解。

固定配色的四环 (0,1,0,1) 没有安全逆合并边；改为 (0,1,0,2) 可解除。
八面体三色状态也可能没有安全合并，第四符号可改变该状态。固定配色反例不能交换量词
变成“所有配色和顺序都失败”。

## 7. 程序、案例与独立证据

核心：[web/construction.js](../web/construction.js)。网页没有调用 selectMarkers、
Python 枚举器或回溯后备。几何识别和证书检查仍会遍历线/侧记录；“不遍历”在这里
准确指**不枚举着色组合、不回溯试色**，不意味着程序连输入都不用读取。

13 个可逐步重放的图库案例包含：四符号必要例、同图双历史、边界接线、折线、
独立环、嵌套环、桥、自由端、虚拟锚点、穿越拒绝、斜线锚定、预标阻塞。

生成器不读取颜色来筛选有利地图。连续 seeds=20260908..20261147，LCG 参数
1664525、1013904223，模 2^32。前三类范围与运行结果如下：

| 图族 | 地图数 | 计划上限 | 已提交操作 | 最终结果 |
|---|---:|---:|---:|---|
| 递归矩形分割 guillotine | 160 | 每图 24 次 | 1,094 | 160 个历史受阻 |
| 六层嵌套环与左右连接 | 40 | 每图 18 次 | 720 | 40 个完成 |
| 画框顶点出发的扇形 | 40 | 每图 12 次 | 480 | 40 个完成 |
| 固定教学图库 | 13 | 各例显式指定 | 22 | 完成8，阻塞2，草稿2，非法1 |

每个生成历史首次受阻即停止并保留触发路径与证书，不换种子重来。递归矩形实验
说明这个规则对该输入分布很容易停住；不得把全部“检查通过”误读成全部地图完成。

Python 独立核心重新从旋转系统求侧轨道、从线名读符号，核验相邻异标、真实 Euler
计数、原图顶点 XOR 守恒和**对偶图**闭路积分。总计 2,569 份初始/已提交状态证书通过。
阻塞语义由 Node 判据检查、显式反例与上述证明支持；没有假称 Python 独立重建几何
浮点交点或重新求解每个阻塞图。

## 8. 如何复现与使用

Node.js 20+、Python 3.10+，均只用标准库；没有新增第三方依赖。

```sh
npm test
python -m unittest discover -s tests -v
python scripts/validate.py --output outputs/validation-my-run.json
python scripts/validate_construction.py --output outputs/construction-my-run.json
python scripts/search_construction_gap.py --output outputs/reverse-merge-my-run.json
npm run build
npm run dev
```

打开服务器打印地址下的 `/rules.html`。选择图库后点击“案例下一步”，或自行输入坐标。
接线模式可依次点击起点、折点和终点；闭环模式点击起点闭合。先检查真实锚定，
再提交新线名。查线模式红箭头给出 (左,右) 的读取方向。

JSON 保存初始线名、每一步路径、全部线名证书、谱系和未提交草稿；导入重新计算
已提交操作并比对证书。未提交路径仍为草稿，点击“提交草稿”可重现其阻塞或非法结果。
导入不是信任外部给的 `verified=true`。SVG 用于呈现，不能替代 JSON 计算证据。
生成实验报告中每项 `records[i].replay` 也可单独保存为 JSON 导入网页；其 `pending`
保留首次受阻的请求，点击“提交草稿”即可复现停止原因。

有限精度限制：输入坐标不先粗舍入，顶点键在几何细分时以 10^-6 规范化；极近、
极细或退化输入可能被拒绝，不是符号数的反例。斜线精确锚定舍入缺陷已加入回归测试。
每次提交仍全量重建几何及核验线名，不声称更新复杂度只与新增线有关。

本轮验证范围为命令行算法测试、跨语言证书、构建和 HTTP 资源检查；未做真实浏览器
点击、触控、视觉布局或下载交互测试。需要这些测试时应另行明确验证，不冒报已完成。
