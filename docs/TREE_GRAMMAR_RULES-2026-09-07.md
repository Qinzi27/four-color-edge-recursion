# 二叉树色标文法的操作规则与母线记号对照

核对日期：2026-09-07。本文核对相关原文、给出独立推导并保存有限计算证据；不主张新定理或穷尽查新。

## 结论与阅读入口

Cooper–Rowland–Zeilberger（2012，下称 CRZ）研究的不是任意画线后直接给新面选色，而是有序二叉树的三符号解析，以及两棵树的共同解析词。局部规则可以与三面交界处的群色差严格对应，因此相似性超过括号外观；但面身份、分割历史和实际地图的接口次序并不会自动包含在一棵解析树中。

本次最重要的区分是：叶子标记固定后，向上合并至多有一个结果；父标记固定后，向下分裂有两个有序候选。两棵树必须共同约束这些候选。论文中的局部扩展需要规定的成对结构，不能直接外推为任意母线分面都可继续。

主来源：[CRZ 作者全文](https://sites.math.rutgers.edu/~zeilberg/mamarim/mamarimPDF/4ct.pdf)，[arXiv:1006.1324](https://arxiv.org/abs/1006.1324)，期刊 DOI [10.1016/j.aam.2011.11.002](https://doi.org/10.1016/j.aam.2011.11.002)。页码采用作者 PDF 页码 1–18。

## 1. 先固定对象，避免数字混用

| 对象 | 在本文中的含义 |
|---|---|
| 有序满二叉树 T | 每个节点有零个或两个孩子，左右不可随意交换；根有两个孩子，内部非根节点对应三个关联方向 |
| 叶子位置 x1,…,xn | 按顺序排列的变量位置，不是颜色，不是永久面 ID |
| 解析词 w | 这些叶子上实际放置的符号序列，字母表为 {0,1,2} |
| 节点标记 | 解析树上的三符号状态；转换到三价图时可读成关联边的非零色差 |
| 面颜色 | 四个群元素 {00,01,10,11}；与三符号状态分属不同集合 |

原文短摘录一（§2，第2页）：

> “each vertex has either 0 or 2 children”

译：每个节点要么没有孩子，要么有两个孩子。它界定的是树结构，不表示每个地图节点只有两条边。

因此 `((x1,x2),(x3,x4))` 是合法的四叶树形；不能因此认定 `(1,2,3,4)` 也是这篇论文允许的叶子色标。数字在表达式里扮演什么角色必须先声明。

## 2. 基本规则：分裂有两个候选，合并最多一个结果

原文 §1，第1页的六条产生式可整理为：

| 父标记 | 左右孩子允许的有序标记 |
|---|---|
| 0 | (1,2) 或 (2,1) |
| 1 | (0,2) 或 (2,0) |
| 2 | (0,1) 或 (1,0) |

等价地，每次分叉处父、左孩子、右孩子三个标记两两不同。反向读取规则：两个孩子不同，父标记就是剩余的那个符号；孩子相同则失败。

独立代数核对：取编码 γ(0)=01、γ(1)=10、γ(2)=11。合法合并满足

    γ(parent) = γ(left) XOR γ(right) != 00.

特别注意，文法符号 0 对应非零群元素 01；两个同标记相消得到的群元素 00 是失败状态，不能把它当作合法的文法符号 0。

对一棵已给定的树，逐层查六规则即可确定是否接受某个词。等价的独立检查是：每个子树覆盖的叶子区间，其群元素总 XOR 都非零。只检查整棵树总 XOR 非零不够。

## 3. 两棵树如何连接约束

设 W(T) 是树 T 接受的全部具体词，则树对的目标为：

    找到 w ∈ W(T1) ∩ W(T2).

两棵树使用同一份有序叶子变量。一边任意成功不能保证另一边成功。若两边都成功，根的群值都是全部叶子的 XOR，所以根标记必定一致。

CRZ §1–2 将“每对同叶数二叉树都有共同解析词”与四色定理联系起来。Kauffman（2005）§7，第171页说明了将两棵树的根和对应末梢连接成平面图的构造，绘制两边时有镜像/次序约定，不能任意把两个分割历史接起来。

独立算例：令 T1=((x1,x2),x3)，T2=(x1,(x2,x3))。

| 叶子词 | T1 | T2 |
|---|---|---|
| 011 | (0,1)→2，再 (2,1)→0，成功 | (1,1) 不能合并，失败 |
| 010 | (0,1)→2，再 (2,0)→1，成功 | (1,0)→2，再 (0,2)→1，成功 |

011 的总群 XOR 是 01，仍然在 T2 的内部子树失败。该例反驳“局部任意选出一个合法词即可用于所有树形”，不反驳这篇论文，也不是尚未完整定义的母线法的反例。

## 4. 论文里的三种具体扩展

### A. 两边同位置一起分叉：Proposition 10，第8–9页

已知两棵树的共同词，在双方同一叶位都把叶子替换成一个二叶分叉。原标记为 a，则把该位置同步替换为另外两符号 b,c，顺序可选 bc 或 cb。外部标记及两个根都保持。

例：双方原来共同使用叶标记 0，同步换成 (1,2) 或 (2,1)。这要求“两边同一位置一起改”，不是任意给某一侧单独加线。

具体词数乘2。按整体字母置换取等价类时，下面的计数核验限定原树至少2叶；单叶的稳定子不同，其等价类数不能套用同一个乘2结论。

### B. 一边分叉，另一边复制叶位：Proposition 11，第9页

这里“复制”首先指结构，不是把相同颜色复制两遍：

    左叶的结构：(x,S) → (x,(x,S))
    右叶的结构：(S,x) → ((S,x),x)

S 是原来的兄弟子树。设原叶标记 a、父标记 p、S 的根标记 s，三个标记不同。为保留父和 S：

    左叶情况，新叶词必须把 a 换成 s p。
    右叶情况，新叶词必须把 a 换成 p s。

例如原叶0、父1、兄弟子树根2：左叶替换为21，右叶替换为12。另一棵树在对应位置作普通二叶分叉，接受这一指定顺序。每个原共同词对应一个新共同词。

独立演算左叶情况：原 (a,s)→p；新内层 (p,s)→a，外层 (s,a)→p。S 和外部上下文均不必改变，但新叶不沿用旧叶0。

原文短摘录二（Proposition 11 证明，第9页）：

> “preserves the labels of all other vertices”

译：保持其他所有节点的标记。这里限定在该树变换的指定局部之外，不能翻译成“任何分面操作都保证所有旧面颜色不变”。本次已渲染并核看第9页左右两幅替换图。

### C. 两边同位置增成三叶链：Theorem 18，第16页

双方在同一叶位插入两层同朝向结构，例如 (x,S)→(x,(x,(x,S)))，把共同词中的 a 替换为 aaa。右叶使用镜像结构。这次三个新叶确实可以同标记；它们不是同一父节点的兄弟。

独立演算：a 与 S 的根 s 不同，沿三层链自下而上得到 p、s、p，其中 p 为第三标记。所有合并合法，顶端仍是原父标记 p。定理给出一个有效扩展映射，不声称枚举了扩展后所有词。

论文接着把“两边各复制一次时，是否总存在指定相等叶标记的词”列为 Conjecture 19，并提醒新词未必是某个旧词的简单扩展。本笔记只描述该版本的证明状态，未检索此猜想的后续进展。

## 5. 合并与改括号都有限制

CRZ §6.1，第14–15页：当两棵树的子树覆盖同一组对应叶位，可先处理内部树对，再把该部分压缩为共同根接口，处理外部树对；重新接入时必须对齐根标记。字母整体置换可帮助对齐，但不能把两边独立改名后的编号直接粘合。

CRZ §3 的去重是三字母全局置换 S3，不是消除所有回溯或所有不同树形；也不能直接等同于四种面颜色的 S4。

独立推导一个最小的“改括号”判据：假定 A、B、C 都是合法子树，根标记为 a,b,c，且 ((A,B),C) 已合法。令对应非零群值仍记 a,b,c。

    左式合法：a != b，且 a XOR b XOR c != 0。
    右式 A,(B,C) 还需要：b != c。

三个非零群值中，左式合法迫使 c 为 a 或 b；右式合法恰好排除 c=b。因此在保持三个子树标记不变时，这次旋转可行当且仅当 a=c。011 与010分别是失败、成功例子。

这不是一个新的结合律：该部分运算没有全局结合律。Kauffman §7 还讨论带正负号的受限重结合；本次没有实现完整的带符号变换系统，不把旋转小检查视为它的完整复现。

## 6. 与原母线/面分割法的真实对应

### 能严格对上的局部关系

取三个两两不同的面颜色 u,v,w，三条交界边的差分别为：

    d_uv = u XOR v
    d_uw = u XOR w
    d_wv = w XOR v
    d_uv = d_uw XOR d_wv.

三个差都非零，因而恰是三种不同的文法标记。举例把显示面颜色1、2、3分别编码为00、01、10：

| 真实两侧面颜色 | 群差 | 文法标记 |
|---|---|---|
| (1,2) | 01 | 0 |
| (1,3) | 10 | 1 |
| (2,3) | 11 | 2 |

所以项目的局部分割图出现 (1,2)、(1,3)、(2,3) 三种实际边侧标签时，它们的群差确实满足文法 0→(1,2)。这证明一个局部代数对应，不证明“整个分割历史树就是论文解析树”。

### `((1,2),(3,4))` 不能直接当成同一种乘法

若1、2、3、4指四种不同的面颜色，编码为00、01、10、11，则：

    d_12 = 01，d_34 = 01，d_12 XOR d_34 = 00。

这只说明：把这两组色差当成两个孩子，并强制合成一个非零父边的三价文法节点，会失败。原母线可能表示不同边段、两个区域集合或四价局部结构，并未必要求这种合并。因此这不是原方法的反例，而是对“直接把括号改成文法合并”的反例。

### 目前仍缺的整体对应

| 要比较的内容 | 已确认 | 尚未确认 |
|---|---|---|
| 局部标记 | 三面交界的色差满足三符号规则 | 母线每个位置是否都对应一个三价约束 |
| 树节点 | CRZ 的父标记由孩子求得 | 用户的父括号究竟存历史、当前边，还是边界关系 |
| 递归接口 | CRZ 对齐有序叶子词和根标记 | 母线各分支如何对应同一地图里的永久面/边身份 |
| 构造选择 | 成对扩展有明确条件 | 原方法如何决定方向、继承色和多候选选择 |
| 跨分支闭合 | 需要共同词和接口一致性 | 原方法遇到新相邻关系时允许哪些确定调整 |

可以把这些作为待定义的接口，而不是要求提出者先证明整个四色定理。最有用的下一份输入，是一个实际分面步骤的“旧状态、选中位置、合法操作、新状态”完整记录。

## 7. 本地核验与复现

新增独立脚本 `scripts/inspect_tree_grammar.py`，核心解析器使用六条产生式；独立 oracle 使用每个子树叶区间的前缀 XOR，没有调用产生式表。脚本明确是文献规则研究工具，未接入网页选色，不是提出者的算法实现。

主报告：[tree-grammar-rules-2026-09-07-02.json](../outputs/tree-grammar-rules-2026-09-07-02.json)。前一报告保留为阶段记录，仅核验前两种扩展。

| 验证范围 | 结果 |
|---|---|
| 1–7叶全部有序满二叉树 | 合计197棵；7叶132棵 |
| 每棵树×全部三符号叶词 | 合计323,175次，解析器与独立 oracle 一致 |

| 2–5叶全部有序树对×叶位置 | 1,094种情形，核验三种扩展 |

| 三叶链扩展 | 对每个旧共同词核验指定新词与根标记；不枚举全部新词 |

无随机抽样，因此随机种子为 null。树对有限成功不是任意平面地图实验，更不是新的四色证明；脚本没有实现一般地图到树对的分解。

从仓库根目录运行（Python 3.10+，标准库）：

```sh
python scripts/inspect_tree_grammar.py --max-leaves 7 --extension-max 5
python -m unittest discover -s tests -v
python scripts/validate.py --output outputs/validation-tree-grammar-new-run.json
```

首条命令默认生成带时间戳的新报告；指定 `--output` 时拒绝覆盖已有文件。最后一条使用新文件名保留原验证报告。
