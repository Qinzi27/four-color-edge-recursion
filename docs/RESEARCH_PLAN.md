# 研究计划 / Research plan

本项目的出发点是 Qinzi27 提出的左右颜色对与递归分割括号。第一阶段成果是对这一想法的严格表示和可运行研究基线。可能的原创贡献需要进一步文献核对、明确新命题以及可检查证明；仓库上线、测试通过或新的术语都不能替代这些工作。

## 已建立的起点

[FOUNDATIONS.md](FOUNDATIONS.md) 给出地图表示、对偶闭路验证、边界关系粘合、堆叠三角剖分基准和小图类最小改标记公式。它们使每项后续主张有明确输入与输出。

第一批计算应回答“实现是否与已证明定义一致”，然后才探索“能否提出更强的新命题”。对同一个测试同时记录原图、对偶图、面身份、颜色值和边差，防止转换过程悄悄改变对象。

## 路线 A：边界状态究竟保留多少信息

研究对象为带有有序接口的平面着色约束图，真值采用精确关系 $\mathcal R(G,B)$。用它检查候选压缩表示是否充分，例如只保存相邻接口颜色差、相等模式、分割历史或某个闭路基。

可检验问题 A1：是否存在两个带相同接口的小图，其候选压缩状态相同，但精确扩张关系不同？只要找到一对，就否定该压缩的充分性。保存这对图及一份只在其中一侧可扩张的边界预着色，作为可复现反例。

可检验问题 A2：对某个明确限制的图类，能否证明候选状态与精确关系等价，并给出状态数关于接口大小的上界？有限测试只用于提出猜想；全图类的正确性需要结构归纳或其他证明。

首批图类采用外平面图、给定 TTSP 分解的网络、堆叠三角剖分对应的区域邻接图。通用树分解或球面切割动态规划已有大量研究，潜在贡献应具体到新的充分统计量、压缩界或更易检查的证书，见 [文献比较](RELATED_WORK.md)。

## 路线 B：闭路缺陷与最小修复

先完成可核对的任务 B1：枚举小圈、仙人掌和 theta 图的标签，比较第7节公式与全枚举最优值。对含桥输入明确返回不可行，不能偷偷允许目标边差为0。

任务 B2：对规模受控的 TTSP 表达式，以独立穷举检验第8节动态规划的最优值和回溯证据。当前接口样本应包含不同串并联顺序、平行边以及无可行处处非零流的网络。数学定义允许初始零标签，但当前修复接口只接收 `1,2,3`；未来若扩展到0，应同时新增零标签测试。给定表达式的正确性与“任意图自动获得分解”的正确性分开验证。

任务 B3：区分三个尚不能互换的优化量：最少修改边数、修改的地理/图距离半径、最小不一致闭路或约束核。当前 Hamming 最优流解只解决第一个；当前生成树失败见证不保证后两个最优。

候选未来命题必须写成带量词和图类的形式，例如：“对图类 $\mathcal C$ 的每个带标签输入，某明确递归能返回最优修复及可验证证书，且资源上界为 $f(n,k)$。”不能以未定义的“局部调整总能解决”代替命题。

## 路线 C：历史、重写与构造顺序

先定义操作字母表 `Extend`、`CloseSplit`、`Subdivide`、`Recolor`，每个事件包含地图身份、选定面角以及受影响面/边 ID。拓扑变化与颜色选择分开记账；重着色事件必须显式保存。

待研究问题 C1：两份历史何时重建同一个带嵌入地图？等价应允许明确指定的 ID 重命名，保留旋转次序，并说明是否允许镜像。

待研究问题 C2：某些相邻独立操作可否交换而不改变最终精确边界关系？对完全相同的最终约束图，关系相同由定义保证；有研究内容的是局部规则是否足以识别这种等价，以及证明终止性、合流性所需的条件。

若未来声称一个局部重写系统对任意平面图都产生合法四色结果，必须证明输入覆盖、每步保持语义、终止与输出非空。已知四色定理的存在性不能被隐藏在某条未证明的“总能修复”规则中。

## 可重复计算的最低记录

每次实验保存：生成器和图类、随机种子、输入规模上限、实际样本数、原始边 ID、旋转系统或明确标记“仅抽象图”、标签、预着色、算法版本、输出证书、独立检查结果、耗时测量条件。

小输入独立 oracle 可以枚举所有 $4^{|V|}$ 个顶点颜色或 $3^{|E|}$ 个非零边标签。它不应调用被检验算法的同一递推再把结果比较一次。规模较大后可使用不同建模的 SAT/ILP 求解器，但必须记录版本及模型；安装或引入新依赖属于未来工程决策。

反例应保留发现时的完整输入；缩减副本再尝试删除边、压缩二价点或减小标签集合。只有在明确定义的缩减偏序或代价函数下穷尽检查后，才称为“最小反例”。通常的贪心删除只能称为“缩减反例”或“删除极小反例”。

## 发布与科研表述

公开版本可使用标题 “Recursive edge-side states for planar map coloring: foundations and exact repair baselines”。描述应包含 `four-color theorem`、`planar graphs`、`graph coloring`、`nowhere-zero flows`、`recursive decomposition`、`四色问题`，但不使用“已解决四色定理的新证明”等超出成果的说法。

建议每个后续命题或实验以 issue 记录定义、相关文献、基准、反例和证明状态。只有在代码与文档固定为可引用版本后，才为该版本制作 release；GitHub 搜索或外部搜索引擎是否收录、何时出现以及排序均不能保证。

署名使用用户确认的身份；当前使用 GitHub 账号 Qinzi27，不推断真实姓名或机构。已有文献使用独立引用记录，AI 辅助整理和实现情况应在仓库贡献说明中透明披露。无需为了“与他人不同”提前给基础事实冠以新定理名。

## 第一份论文或技术报告的骨架

1. 问题与动机：两侧颜色对、面身份和递归历史之间的关系。
2. 正式模型：输入、嵌入、桥、自环、对偶与边界接口。
3. 基础结果：已知等价和本仓库自包含推导，明确其非原创基准性质。
4. 一个经查新的新增结果：如某受限图类的充分状态压缩或最小证书定理；若尚未取得，保留为研究问题。
5. 可重复实验：独立 oracle、负例、规模限制和完整运行记录。
6. 局限与推广：与既有语法、流和动态规划方法逐条比较。

在新增结果尚未建立时，最合适的产物是可审阅的研究笔记及软件仓库，而不是将探索性草稿包装成已完成的一般理论。
