# 2026-09-20 联合边界过滤工作记录

## 问题与预声明范围

接续相邻内部双面 U、D 共同邻接 k 个接口的结果，检查“接口至多两色”是否能强化原 v4。固定旧归档9个失败图及40个既有诊断图，两模式各运行一次；同状态首错候选覆盖与新完整轨迹分开统计。这个范围不是未知测试集。

## 实现和推导

1. 保留原实现，新增真实共边证书与 `domains`/`joint` 两模式。证明一元消融对现有路径闭包冗余。
2. 联合模式对每个相邻双面局部组检查至多12个内部颜色对，保留当前全部局部二元关系，闭包后取并并回传。逐条推导可靠，且因条件分支域大小至多2，局部一元/二元投影精确。
3. 沿用 v4 初始化与选择规则；新增信息不转成临时承诺，不回退旧承诺，不读取旧颜色，不调用完整着色求解器。
4. 添加独立集合版条件闭包、Hall/关系删除证书重放、真实边证据及选择核验。检查器修正了模式误标和统计/初始化元数据未核对的漏洞，并增加篡改测试。
5. 新单图命令要求显式模式，保存独立核验的完整证书，拒绝覆盖旧输出。

- 两模式49图均40完成、9冲突；修复0、退步0，首错候选排除0/9。
