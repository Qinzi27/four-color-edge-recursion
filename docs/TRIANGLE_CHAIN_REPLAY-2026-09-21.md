# 连续贯穿切割重放、单次 Kempe 修复与真实可达成本

日期：2026-09-21。研究想法属于 Qinzi27。本轮从单矩形开始实际执行切割，不向策略植入上一轮手工写出的困难初色。所有旧报告保留；本轮新策略单独命名，不改变旧网页、v3/v4 冻结成绩或此前算法定义。

**已核验的进步：在预声明的 128 条配对历史上，旧 forest 策略全部提前停止；新增 forest 后接单次择优 Kempe 修复的实验策略全部完成。全部 1,792 次后备修复都达到该步的最少净旧侧改色成本。此结论不包含一般完备性或整段历史累计成本最优。**

## 1. 实验设计及成本口径

沿用 [上一轮真实矩形构造](RECOLORING_OBSTRUCTIONS-2026-09-21.md) 的参数 `m=1,…,8`，最终内部面数 `6m+3`。每个参数有 8 条几何历史：先切下排/上排、从左/右依次分离矩形、全部线段端点正向/反向，共 `2×2×2` 种。最后均保留同一个父矩形 `[-1,3]×[1,2]`，最后沿 `x=1` 分成两个子面。

Python 策略另分别指定 `inherit=left/right`；网页策略使用原模块自己的选择。不存在随机抽样，全部历史和参数逐项保存。两行先后与线段方向是独立对照参数，但不代表已经穷尽所有贯穿历史。

成本统计未拆旧侧的字面颜色变化，两个新子侧及外侧权重为 0。一个侧在不同步骤重复变化会重复计入**历史累计成本**；最后一步的**最少净旧侧改色**只比较该步真实初态与合法终点。未构造线记录映射时，记录成本保持未测量，不写成 0。

## 2. 原有规则的真实重放：448 条均提前停止

| 原有策略 | 历史数 | 完成整个历史 | 到达最后父矩形 | 停点最小旧侧成本为 0 / 1 的数量 |
|---|---:|---:|---:|---:|
| plain，左右继承各一组 | 128 | 0 | 0 | 96 / 32 |
| strip，左右继承各一组 | 128 | 0 | 0 | 32 / 96 |
| forest，左右继承各一组 | 128 | 0 | 0 | 32 / 96 |
| 原网页自动规则 | 64 | 0 | 0 | 0 / 64 |
| 合计 | 448 | 0 | 0 | 160 / 288 |

这批历史共尝试 6,240 刀，实际提交 5,792 刀，每条在首次阻塞处停止。全部 448 个实际停点都有一次完整 Kempe 分量交换可修复，事后最少成本为 0 或 1；这些诊断没有反馈给旧策略。因此，不能把最后 `2m` 的成本归到这些旧策略的实际输出，也不能将早停解释为地图不存在四色着色。

网页对照由 Node 直接加载未改动的 `web/construction.js` 执行，坐标从原矩形仿射转换到其画布并转换回来。这里验证了模块行为，没有进行鼠标、触控等浏览器 UI 测试。

## 3. 明确定义新策略并连续运行

新策略 `forest_then_single_kempe_cost` 位于 `fourcolor/kempe_history_policy.py`：

1. 原样执行已有 forest 规则；它成功时保留其状态与决定。
2. 仅在它实际阻塞时，使用真实待切几何和真实父色构造放松图 `H`。两个子侧继承同一父色，仅删除它们的新互邻约束。诊断用的第五个名字不进入输入。
3. 检验两个子侧起点、各三个颜色对的 6 次尝试，寻找不动外侧、只含一个子侧的完整双色连通分量，选择净旧侧成本最小的候选。
4. 将一次实际交换的目标写入真实 `RectState`，保留旧侧身份、切割历史并重建线记录。没有候选则停止；没有多步 BFS 或终点求解器后备。

对同样的 8 个参数、8 条几何历史、2 种继承方向，共运行 128 条新策略历史。独立审计逐条比较旧 forest 成功前缀，并重建每一步几何邻接，确认原有成功决定没有被替换。

## 4. 新的结构澄清：困难成本不依赖精挑初色

[最后父地图的独立证明](TRIANGLE_CHAIN_PARENT_RIGIDITY-2026-09-21.md) 给出更强的量词：对任意 `m≥1`，最后切割前的真正旧父图，其内部为以父侧和 `v1` 为根边的 2-tree。固定外侧后只有三种内部颜色；根边有 `3×2=6` 种配色，每个新三角形强制第三色，所以整个旧父图恰有六种合法配色，全为上一轮初态的整体置换。

因此，一旦到达这个父地图，**任何合法配色**在指定最后切割后都必须净改至少 `2m` 个未拆旧侧；一次 Kempe 交换能达到。提前选另一份合法父图配色，无法降低这最后一刀的成本。一般命题依靠 2-tree 构造证明；独立原顶点枚举对 `m=1,…,8` 核对全部 48 份父图配色。

需要分开保留两个结论：

- 父图任意合法着色的 `2m` 结论：对所有 `m≥1` 有直接证明。
- 本次新连续策略能从单矩形到达并完成历史：目前正式核验范围是这 128 条，不等于证明任意 `m` 或任意贯穿历史均能完成。

2-tree 的唯一三色性是已知性质；几何对应及成本推论是本项目明确写出并验证的结果，文献原创性见 [阶段查新](NOVELTY_ASSESSMENT-2026-09-21.md)。
