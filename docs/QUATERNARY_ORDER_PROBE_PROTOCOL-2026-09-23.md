# 母线顺序与障碍可达性：计算前协议（2026-09-23）

本轮保持 `quaternary-low-color-conditional-propagation-v1`、真实母线调度、低色优先和条件传播不变。目标是检查改变接框区域或增加母线外框支撑后，内部 K4 是否能在 E 固定之前落名，以及是否出现从 SAT 到 UNSAT 的实际提交。独立精确求解器仅在被测运行完成后核查，不提供选择或救援。

## 输入与几何预检查修订

1. 反演主组：保留原提升构造的24条显式线段，去掉原隐式外框；分别以 Z(40,40)、P(430,345)、Q(430,365)、X(390,350)、Y(470,350)、A(420,280)、E(150,100) 为中心，将每段等分4或8份后作平面反演。固定0/90度方位，等比缩放到900×600、留50边距，坐标保留8位。共28个终图，全部保留。它们是有限折线近似，不能预设拓扑保持；逐图核对11面、19真实邻接及带指定接框面标记的完整图同构，保留全部对称映射。A、E和K4集合必须不受映射选择影响。只检查终图，不宣称检查96/192条折线的全部插入前缀。
2. 支撑辅组：从原完整24段图开始，预先指定左延伸(0,355)–(410,355)、右延伸(450,355)–(900,355)、斜线上段(95,0)–(430,335)、斜线下段(450,355)–(695,600)。六个终态为原图、左、右、左右贯通、上下斜线贯通、先左再右再斜上再斜下。检查每条短历史的全部前缀。两种方位共12终态、32前缀引用、16个按线段集去重的输入。新增切割会改变拓扑，不继承旧面身份；原障碍被切开时只作调度对照。

在任何新配色运行之前，几何预检查发现旧导出器最多80条原始线段，因此上述96/192段均被接口拒绝；旧适配和独立几何审计又固定900×600。为使输入可核查，本协议冻结以下预运行修订：主组另建隔离的几何导出入口，仅把旧引擎的线段资源上限80提高到256，原文件不变且原源码哈希绑定；辅组将原拟0/90度改为0/180度真等距旋转，仍900×600。未依据颜色、候选域或oracle结果调整输入。90度矩形画布适配不在本版本范围。主组折线近似参数不再自适应调整；失败也保留。

## 冻结与范围

- 新 manifest 绑定旧129个来源、旧 manifest、全部新代码/测试、本协议及全部实际几何、锚点、输入生成元数据。正式运行前重新生成几何与源码核对。唯一文件名，不覆盖旧证据。
- 两组分别统计，不把同构或相关前缀当独立样本。最多44个输入、88次运行；终态40个/80个模式引用与短历史32个/64个模式前缀引用独立报告。
- 每图采用已有 `one-bounded-anchor` 与 `legacy-frame-anchors` 标准初始化，不人为指定旧Z或某个颜色序列。改变接框面同时可能改变锚点，因此不把主组效果归因为纯调度变化。尤其 R≠Z 时原抽象障碍的Z=1前提未必存在。
- 几何非法、拓扑不符、超过40面都在清单中记为未运行及明确原因，不能记作配色失败或通过。几何合法但未保持目标拓扑的主组不进入目标策略比较，保留几何及错误理由。辅组无需保持旧拓扑。
- 每次运行资源：最多128提交、512候选试探、每次精确oracle最多200000节点。初始化字面赋值乘积≤262144时全枚举；超过即标未枚举，仍作逐步精确核查。预算耗尽/异常/UNKNOWN不计安全或无解。

## 核查与判据

1. 规则可靠性：独立重放全部传播删减轨迹；达到枚举阈值的实例保留全部满足原始真实邻接及当前承诺的赋值。保留共享解析/几何和调度辅助代码这一独立性边界。
2. 每步可延拓性：初始化及每次实际提交前后仅以原始真实NEQ和累计承诺构建精确问题，保存SAT完整见证或可验证UNSAT树。定位首个SAT→UNSAT；后续冲突不冒充首错。拒绝候选单独记录。
3. 完整流程：记录终态、全部声明短前缀、终止/资源状态与成本。不向生产者反馈oracle。各几何两模式先完成生产，再事后审计；持久阶段只含初始及事件after阶段，不把被拒trial当可达状态。
4. 结构诊断：从原始真实NEQ枚举全部诱导K5减边，记录两顶点候选域及交集；统计严格{b,t}/{其余三色}型、非包含交叉域、被选危险最小色和未决后提交。结构匹配不等于精确首错。可唯一解释的A/E记录首次单例阶段；P/Q/X/Y的对称性保留，以整个K4集合判断是否先于E。
5. 落盘后重新核对输入覆盖、来源哈希、原始接触、全部传播轨迹、精确证据和诊断汇总，不再运行生产者。发生真实错误时先保留原始实例，再另作符合声明范围的缩减，不改本轮冻结规则。

本轮成功仅代表声明有限输入的证据。没有首错也不能证明一般可延拓性、最少颜色、复杂度改进或原创定理。已知共同三角形迫使两端同色的EQ接入另立版本。
