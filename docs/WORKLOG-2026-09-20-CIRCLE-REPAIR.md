## 理论进展

1. 定义 `q(A)` 为 A 的奇分量数，包含孤立顶点；候选偶边集 C 通过对称差保持 A 偶度。严格下降每步至少减 2，只得到已接受步数界，并不保证下一步存在。
2. 奇数棱柱（两个圈与奇数条径向路径，允许度 2 细分）初始两圈可由任一环带面翻转修复；在非负可加边权下，最便宜单面恰为所有可补全第一层中的最小修复。证明使用经典匹配交替圈结构，不宣称新普遍定理或文献首创。
3. 统一细分 L 段时最低净改动 4L，否定不区分边段/拓扑路径的常数局部界。
4. 八轮缘轮图给出严格单简单圈下降反例。全部 57 圈 q' 分布为 2:33、4:20、6:4；有不靠枚举的解析解释。两三角面给 `2→2→0` 平台路径，或组合成一次动作，最低净改动为 6。共享边双面不能解决该例。

理论由独立检查复核，并将关联矩阵、奇点集合、细分后圈长、补全性和一般终止性保持区分。报告有英文摘要和主源引用，亦记录 Scientific Agent Skills 的工作流来源。
