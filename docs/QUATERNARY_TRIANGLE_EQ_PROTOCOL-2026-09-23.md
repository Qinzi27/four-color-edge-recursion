# 共同三角形EQ接入：计算前协议（2026-09-23）

本轮另立 `quaternary-low-color-triangle-eq-v1`，保留冻结旧guarded策略作逐图配对对照。研究问题为：原始邻接可证明的同名关系能否在低色提交前排除已知危险候选，同时不丢失合法解、不引入新的错误提交；测量传播及运行成本。规则是已知初等事实，不作为原创定理。

## 规则和实现边界

在固定四名集合{1,2,3,4}中，原始真实NEQ含三角形BCD以及A、E各自到BCD的六条边，则BCD占三种不同名字，A、E都只能使用剩余同一名字，因此A=E。规则不要求三角形在几何上是一个面，但所有九条关系必须是真实共边，而非点触、桥、自环、候选排除或之前学习的EQ。

本版只对原始不相邻、不同身份的A/E枚举共同三角形；每对按原始sides下标顺序选择字典序第一个三角形证书。一次性学习，不用EQ迭代产生新的邻接或合并物理面。原始非空states/equal_names不支持，避免把外部限制混作新推论；允许普通锚点。证书验证器独立构建原始邻接矩阵并核对九条边、身份、顺序和完整覆盖，不调用学习器来验证自己。

新入口只在原始文档上加入已认证equal_names，再调用旧低色guarded核心；原始文档、学习记录、增强文档和全部内部运行均保存。相应二元EQ闭包会同步两个候选域的交集，仍保持低色选择；不把交集中的最小显示值直接当作已承诺颜色。无证书时增强文档与原始文档完全相同，底层轨迹应与旧策略一致。
