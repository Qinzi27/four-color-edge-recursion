# 这项研究的意义、用途与已有工作

定位日期：2026-09-19。发起思路：Qinzi27。
本文解释现有工作的价值并补充具体先例对照；旧规则、失败记录和冻结实验保持原样。

## 1. 最值得研究的是什么

**沿整条分割线追踪两侧名字时，哪些边界信息足以保证当前选择在后续仍可完成？**

这是从最初的左右命名直觉中提炼出来、可以严格检验的问题。随着地图细分，一条母线会邻接多个当前区域；
历史上继承过同一个名字的区域，也可能需要重新区分。记录线的身份、分段位置、当前侧名和历史，
使我们能追问：一次选择依赖哪些信息，遗漏了什么关系，以及应在什么时候提交名字。

这项工作目前的价值体现在三个可以直接使用的产物上：

| 产物 | 可以用来做什么 | 目前的边界 |
| --- | --- | --- |
| 明确的线侧对象、规则与逐步证书 | 把手绘直觉转成可重放操作，检查每个决定的依据 | 正确表示地图，不等于每次取名都可延拓 |
| 固定输入、旧合法见证及失败档案 | 公平比较候选规则，定位第一次使后续无解的决定 | 指定样本的成绩不代表随机地图上的成功概率 |
| 局部条件的证明与识别程序 | 在实际地图中排除有证明的错误候选，缩小下一步研究对象 | 已有机制的项目应用，不自动构成新定理 |

因此，别人可以用这个仓库复查构造策略、研究具体反例、比较约束传播规则，或进行教学演示。
目前没有证据支持更快的通用四色求解、较小的充分状态空间或实际业务性能收益。

## 2. 失败为什么有信息量

最新冻结规则 `peer-batch-ready-sides-v4` 在既有 **7069** 张去重输入中完成 **7060** 张、冲突 **9** 张。
它修复了 v3 的四个失败，却产生九个新退步。这个库包含相关历史的中间图，且已用于多轮研究；
不能把每张图当作独立随机抽样，也不能把多个版本的成功集合拼成一个统一算法。

一个具体失败是：侧 `s1` 已命名为 `2`，侧 `s4` 的过滤后候选为 `{2,3,4}`，最低名规则选择 `2` 后不可延拓。
旧合法见证表明，图本身仍能四色标注。进一步检查发现，两侧虽然不共边，却由内部结构被迫异名。
这说明候选过滤尚未推出全部必要关系；几何侧已经形成、候选集合非空，都不足以证明当前最小名字安全。

这类结果能否定**一条已经固定的规则或一个具体决定**，并给出要补充的条件。
它不否定尚未完整形式化的所有母线方法，也不是四色定理的反例。
具体边表、首次致命决定及见证见 [v4 结果](PEER_BATCH_RESULTS-2026-09-19.md)与[九侧引理](IMPLICIT_INEQUALITY-2026-09-19.md)。

九侧引理能排除九个新失败中三例的当次错误候选；它尚未接入 v4，三张图也没有因此被重跑并判为成功。
先保留这一区别，才能判断下一版究竟增加了什么能力。

## 3. 有哪些直接先例

**有紧密相关研究，部分基础思想与本项目直接重合。** 以下比较关注数学对象和操作，而不只看术语。

| 已有方向与原始来源 | 与项目重合的部分 | 尚需另行比较的部分 |
| --- | --- | --- |
| Kauffman (2005), [Reformulating the map color theorem](https://homepages.math.uic.edu/~kauffman/MapReform.pdf) | 色差、三价图三边着色、树与局部转换的已有联系 | 整母线跨多个分段后的状态及合法操作；无桥适用范围必须保留 |
| Cooper–Rowland–Zeilberger (2012), [二叉树文法全文](https://sites.math.rutgers.edu/~zeilberg/mamarim/mamarimPDF/4ct.pdf) | 三符号文法、两棵树的共同解析词与四色的关系 | 单棵分割历史不自动等于两棵树共同词问题；必须给出映射 |
| Cori–Dulucq (1986)，[CRZ 作者补记中的前驱说明](https://sites.math.rutgers.edu/~zeilberg/mamarim/mamarimhtml/4ct.html) | 图着色与形式语言联系的更早来源 | 本次没有重读其扫描正文，不能断言具体规则等价 |
| Dvořák–Lidický，[Coloring count cones of planar graphs](https://arxiv.org/html/1907.04066v2) | 外边界配色能否扩张、扩张数与接口信息 | 母线记录是否确实压缩了充分信息，需要状态量和正确性证明 |
| Inoue 等 (2026)，[近线性四色算法预印本](https://arxiv.org/abs/2603.24880)及[递归接口 §13.2](https://arxiv.org/html/2603.24880v2#S13.SS2) | 递归中保留边界着色情形再拼接 | 作者报告的 `O(n log n)` 不能转移成本项目的复杂度保证；本次未复现其计算检查 |

全局置换颜色并取一个规范代表，与构造途中不可逆地选择最小候选名，也必须区分。
前者不改变有无合法着色；后者会约束剩余问题，不能由“颜色只是名字”推出其安全性。
固定目标同步改名中的依赖图也有直接先例，详见[原有逐项对照](TARGET_RENAMING_THEORY-2026-09-18.md)。

因此，把颜色写成有序对、括号、树或 Klein 四元群，本身不能作为原创性依据。
对于完整母线框架，当前既没有逐项等价证明可以宣布整套方法完全重复，也没有查新结果足以认证原创。

## 4. 更具体的对照：九侧引理与 Moser spindle

本次从项目十九条真实邻接要求出发，核到了一个精确结构对应。
标准的 **Moser spindle（莫泽纺锤图）** 是一个七顶点、十一边、需要四色的图。
[SageMath 官方文档](https://doc.sagemath.org/html/en/reference/graphs/sage/graphs/generators/smallgraphs.html#sage.graphs.generators.smallgraphs.MoserSpindle)
给出该性质，[官方生成器](https://raw.githubusercontent.com/sagemath/sage/refs/heads/develop/src/sage/graphs/generators/smallgraphs.py)给出精确边表。

项目九侧模板的顶点是实际侧身份 `O,A,B,p,q,r,s,t,u`，不是颜色。其十九条边为：

```text
O-A  O-B  O-p  A-p  O-q  B-q  p-q
r-p  r-q  r-A
s-r  s-A  t-O  t-B  t-s
u-B  u-r  u-s  u-t
```

反设 `A,B` 同名，把这两个变量识别为 `a` 并合并重复约束。所得商图有八顶点、十八边，
其中 `a` 邻接其余全部七点。删除 `a` 后留下：

```text
O-p  O-q  p-q  p-r  q-r
r-s  O-t  s-t  r-u  s-u  t-u
```

令 `O→0, p→4, q→6, r→3, s→2, t→1, u→5`，这十一边正好映射为 SageMath 的
`01,04,06,12,15,23,25,34,35,36,46`，逐边相等。于是商图为联图

\[
Q=K_1\vee M,\qquad M=\text{Moser spindle}.
\]

这里的联图表示加一个与 `M` 所有顶点都相邻的顶点，所以它需要 `χ(M)+1=5` 种颜色。
也可以不借助软件，直接检查 `M` 为什么需要四色：

1. 若只有三色，三角形 `O,p,q` 用尽三色，邻接 `p,q` 的 `r` 必须与 `O` 同色。
2. 三角形 `r,s,u` 同样用尽三色，邻接 `s,u` 的 `t` 必须与 `r` 同色。
3. 但 `O,t` 有边，同色矛盾。
4. `O=r=1, p=s=2, q=u=3, t=4` 给出合法四色见证。

故 `A=B` 的假设与只准使用四色矛盾，推出 `A≠B`。如果实际图还有额外边，这个子图障碍仍然有效。

**这是已知 Moser spindle 障碍的一次具体应用，不能把该固定障碍或上述推论作为新的四色理论。**
本项目在这里完成的是：从真实受阻地图识别这个结构，并输出与真实共边对应、可独立检查的证书。
这比笼统说“某处可能有隐含关系”更具体，但仍须与现有图案识别和约束传播方法比较效率。

注意：识别同名变量是反证中的约束商图操作，不是把地图上某条实际边收缩；它不必保持平面性。
五色需求属于这个假设产生的商图，绝不表示原平面地图需要第五色。

复现本次对应检查：

```text
python scripts/verify_spindle_correspondence.py --output outputs/my-spindle-check.json
```

脚本使用标准库，不安装或调用 SageMath；独立核对边集对应及固定小图赋值，并拒绝覆盖已有输出。
本次结果：[spindle-correspondence-2026-09-19.json](../outputs/spindle-correspondence-2026-09-19.json)。
它不修改冻结规则，也不构成一次新算法全库重跑。

## 5. 什么结果会让继续研究更有价值

最有希望的目标应当小到能够证明，并能和已有方法作明确比较：

| 可争取的结果 | 需要交付的证据 |
| --- | --- |
| 某类地图的母线接口可以更小 | 明确输入类、接口定义、充分性证明及状态量上界；与保留完整边界的方法比较 |
| 某种顺序下可以安全选择名字 | 固定初始化与调度，证明每次承诺都保留至少一个完整解；不能只证明候选非空 |
| 局部隐含关系有效且可控 | 证明关系可靠、说明识别成本，冻结新版本，在旧库和预声明新输入上同时记录收益与退步 |
| 同步改名有更好的范围界 | 明确哪些侧允许改变、是否需要已知目标、原子同步语义和可证明的成本上界 |

如果只得到已有完整边界状态的另一套记号，成果应主要定位为解释性表示和可复现工具。
如果能证明更小的充分接口、新的安全条件或修复界，就形成了可与文献比较的数学结果；
其新颖性仍要针对那个具体结果查证。

**现阶段最合理的定位：线侧递归命名的可复现研究框架，以及局部构造规则适用范围的实验研究。**
