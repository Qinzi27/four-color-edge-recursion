## Reading the counts

A distinct geometry, a construction history, a prefix reference, a single-step repair and a verified certificate are different units. `underdetermined` means the rules did not choose a remaining alternative; `outside_scope` is an implementation restriction; a strategy conflict does not imply that the map needs a fifth color. Choosing the smallest available number is not the same as minimizing the total number of colors.

The current common corpus contains **7069 distinct geometries**: 6113 earlier inputs plus 961 later-seed inputs, with 5 overlaps. It represents **363 histories, 7678 prefix references and 302 static references**. The later-seed cohort has now been used for development and is no longer an unseen holdout.

## Fixed-old-color repair is a separate research question

The Kempe studies start from an already colored parent and charge for changing old sides. Their 160 first-stall snapshots are not 160 completed histories. Cost ranking improves the existing single-C repairs without increasing their 95/160 coverage. Bounded search later finds sequences for all 160, but earlier composition and search already achieved that coverage. Minimum operation count, net changed-side count and ordered records are separate objectives; three minimum-length paths were not minimum-net-cost endpoints. Current-source reproduction uses the two **v2** reports; their earlier v1 reports remain historical records, with some source hashes superseded by audit-strengthening changes.

For the staggered guillotine family, the final map has `6m+3` internal sides and the cost counts `6m+1` old sides. A direct argument gives minimum net cost `2m`; one complete two-color component exchange attains it. Parent rigidity strengthens this to **every legal coloring of that old parent**, with fixed outer color: its six possible colorings are globally equivalent, and the six legal targets have costs `2m, 2m, 5m+1, 5m+1, 5m+1, 5m+1`. This is neither a lower bound on whole-map restart nor on general four-coloring complexity or symbolic update cost.

Reaching such a parent is another question. For `m=1..8`, eight geometry variants and two inheritance directions give 128 histories per Python policy. Plain, strip and forest controls contribute 128 each, and the unchanged web module another 64: all 448 stop before the final parent. The separately specified `forest_then_single_kempe_cost` policy preserves successful forest steps and, only after an actual stall, restores the inherited child state and attempts one cost-ranked whole-component exchange. It completes all 128 histories and 3712 cuts; all 1792 fallback repairs are independently optimal for that step's net old-side cost. No BFS or endpoint-search fallback is used. Neither cumulative-cost optimality nor completion for arbitrary `m` or histories is proved.

The [control replay gzip](../outputs/triangle-chain-replay-2026-09-21.json.gz), [continuation gzip](../outputs/kempe-history-continuation-2026-09-21.json.gz) and [summary](../outputs/replay-novelty-summary-2026-09-21.json) preserve those distinctions. This checkpoint passed 786 Python and 107 Node tests; module-level web replay is not browser UI testing.

## Latest main line: structural refutation before a reuse commitment

`mother-peer-structural-reuse-v1` retains v2's restart from the whole current geometry, mother-line/point-to-point structure, auxiliary levels and minimum-name convention. Before proposing the same name for a side and a currently singleton side, it assumes they are equal and reasons using only original adjacency edges. In a four-name quotient graph, common neighbors of a triangle must share the fourth name. Repeated forced merging may produce an internal original edge or a K5, refuting the initial equality. A proved inequality is a logical constraint, not a new geometric edge. The structural module receives no archived coloring and does not enumerate full color assignments.

This repairs v2's old `20261213/17` failure by proving S1≠S10 before the first fatal S10=2 commitment. On the full old corpus, all 7069 geometries, all prefixes of all 363 histories, all 363 final maps and all 302 static references complete. Every run has a full independent audit.

Before inspecting new results, 20 seeds `20262101..20262120` were fixed, each with 24 cuts plus its initial state: 500 prefix references, 481 distinct geometries, comprising 479 unseen and two overlapping the old corpus. Both policies run fresh on every geometry: v2 solves 480/481, the candidate 481/481; on the unseen subset the comparison is 478/479 versus 479/479. All-prefix histories improve from 19/20 to 20/20; both solve 20/20 final maps. The new failure `20262117/12` is repaired by proving S0≠S9, ruling out that particular reuse of outer name 1 without banning internal use of 1. These are new seeds from the same guillotine generator, **not an independent graph family**. See the [paired report](../outputs/structural-restart-new-seeds-2026-09-21.json.gz) and [summary](../outputs/structural-restart-new-seeds-summary-2026-09-21.json).

Under the stated contracts—identical initialization and no-learning pipeline, cumulative commitments, sound propagation/refutation, checking only the currently proposed reuse, and normal finite execution—the [preservation proposition](STRUCTURAL_RESTART_SUCCESS_PRESERVATION-2026-09-21.md) gives `Success(v2) ⊆ Success(structural-reuse-v1)`. A successful old final coloring witnesses every proposed equality along its path, so sound refutation cannot create a first divergence. All 7068 old-corpus v2 successes and 480 new-seed v2 successes empirically retain identical active traces and literal final names, with zero learned relations. This does not extend to arbitrary early sound filtering, which can alter a greedy schedule, or guarantee the same resource cost.

The old-corpus and new-seed candidate runs make 86451 and 5989 structural queries respectively, learning one relation each. Zero learning still incurs queries. The latest checkpoint passes **831 Python tests and the comprehensive validator**, with 31 and 35 input/source hashes unchanged across the two runs. The existing Node geometry engine is invoked; JavaScript is unchanged and the complete web test suite was not rerun in this structural round. Paired new-seed timings are retained as uncontrolled single-run observations, not evidence of a speed advantage.

An inconclusive refutation remains unknown; it does not certify that the proposed reuse extends. The complete inside-out closed-loop idea is not yet formalized, and universal success is unproved. Shared-triangle reasoning and quotient-graph refutation have a direct antecedent in Hébrard and Katsirelos (2020), *Constraint and Satisfiability Reasoning for Graph Coloring*, §3 and §6.3, Lemma 2; see the [authors' full text](https://gkatsi.github.io/papers/hk-jair20.pdf). The [novelty assessment](NOVELTY_ASSESSMENT-2026-09-21.md) also compares ColorFixing, MinHOM, unique coloring, 2-trees, Kempe reconfiguration and dynamic recourse. The original arXiv:2603.24880 studies a different general-algorithm objective; this project has not reproduced its configuration library or universal guarantee. Priority of the overall combination remains unestablished.
