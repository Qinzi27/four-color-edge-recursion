# 三色三角邻接饱和规则：计算前协议（2026-10-01）

本轮在已冻结的条件菱形同名版本上增加三色三角邻接饱和（triangle color
saturation）删色，保留四进制状态表示、低色优先、母线调度及原有逻辑EQ/NEQ
学习。开发动机是上一轮仍未识别的2项联合假设诊断；这些假设曾被离线证明
联合无解，不代表生产算法曾同时提交它们。规则的数学理由、实现保解性、旧
假设诊断和真实流程收益分别核验。本轮不混入缓存或增量更新等成本优化。

## 规则、物理见证及条件范围

以面为顶点、真实共边为边的对偶邻接图中，三个两两异名的面类A、B、C，若
可靠候选域均排除同一颜色q，则只能使用其余三色。三者两两相邻使颜色互异，
因此恰好占满这三色。与A、B、C都相邻的另一面类T只能使用q；可删去T域内
所有非q候选。若q原本已不在T域中，推理得到空域，表示当前假设矛盾。

面类只由已审计的显式同名关系（EQ）构成，包括本次条件菱形传播得到的EQ。
它不合并物理面身份、不改变原始线段。商图的AB、AC、BC、TA、TB、TC六条
所需邻接各保存一条原始separator物理边作为见证；可以来自同名类的不同
成员。逻辑NEQ、点接触、桥或oracle答案不能替代这六条物理共边。独立规则
入口要求同一EQ类所有成员候选域完全相同，并拒绝类内物理自环。生产先完成
旧传播，仅对非终态调用本规则；已得到冲突的阶段不绕过旧冲突处理。

证书保存目标类代表、三角类代表、共同排除色、实际删去色和六条字面物理边，
并绑定完整阶段文档、候选域及EQ列表哈希。所有类及其成员按输入索引固定
顺序；每个可删色目标类保存一条确定顺序证书，不声称枚举全部证明或获得
最短证明。独立检查器不导入检测器，另行构建EQ类、枚举三角及目标，检查
证书内容和规则所声明结构的完整覆盖。没有证书只表示没有这个模式。

这些删色依赖本次调用的当前承诺、试探及此前可靠推导。外层传播先运行原
条件菱形闭包；若饱和证书产生新删色，则在本次调用的局部文档副本中更新
目标代表的四进制状态，再执行原闭包。原始线段、锚点和显式EQ/NEQ保持
不变；每轮内部得到的条件EQ重新推导，不向下一轮根前提偷渡。域单例仍为
推理状态，不伪装成人为锚点或实际落名。每轮文档、完整内层轨迹、EQ来源、
证书和删色均保存；顶层最终轨迹不能替代全嵌套轮次的成本统计。

每个继续轮次必须删去至少一个此前未删候选，最多4n个字面面／颜色对，故
局部闭包有有限停止条件。独立重放检查精确下一轮状态及停止条件，不接受
漏轮、未证明删色或跨试探复用。该规则是基础图着色推论的工程接入，不把它
称为新定理、一般完备性或四色定理新证明。

## 第一层：规则可靠性的有限穷举

第一部分枚举a、b、c、t四个标号顶点的全部6条可能边，即2^6=64个简单图。
对每图固定21种候选域，不作颜色或顶点对称性约简：

1. a、b、c共同排除q，t保留四色，q逐一取1至4：4种。
2. 从上一模式分别将a、b、c之一放宽到四色：3×4=12种。
3. 四顶点全为四色域：1种。
4. 四顶点均排除同一q：4种，包含K4三色无解的真空保解对照。

第二部分固定五个字面顶点a、b、c、t0、t1及显式EQ t0=t1。a、b、c构成
物理三角，三条由a、b、c指向目标类的物理边，分别独立选择t0或t1作端点，
共2^3=8个固定标号原始图。每图使用同样21种域模式，t0、t1的域保持一致。
这覆盖目标类物理见证分布在不同成员的情形，仅是规定的8种边端点选择，
不代表所有EQ分区、任意数量成员或所有商图提升。

| 预声明对象 | 四顶点部分 | 五顶点EQ部分 | 合计 |
| --- | ---: | ---: | ---: |
| 不同原始标号物理图 | 64 | 8 | 72 |
| 三角三色／目标四色主案例 | 256 | 32 | 288 |
| 单点放宽、全四色和全三色对照 | 1,088 | 136 | 1,224 |
| 图／域案例 | 1,344 | 168 | 1,512 |
| 全部4^n字面赋值与案例配对引用 | 344,064 | 172,032 | 516,096 |
| 域内笛卡尔积与案例配对引用 | 175,360 | 85,088 | 260,448 |

每例遍历全部4^4=256或4^5=1,024个字面颜色赋值，直接依次核对原始物理
边、显式EQ及候选域。五顶点部分也遍历t0与t1不相等的赋值并拒绝它们，
不能直接枚举四个商类后宣称遍历了4^5。缓存同图原始约束合法性只减少重复
计算，不改变每个案例的分母；不使用路径一致性、生产传播或oracle。

每个原始物理图加显式EQ均保存四色完整见证。每条证书对目标EQ类每个成员
删去的每一颜色分别核查：不得删除任何满足原边、显式EQ及域的完整赋值。
域内原本无解的案例及其真空删色单独统计，不计作有解情况下的有效推理。
每个未删去的域内字面候选若有完整支持解则保存见证；若域内有解但此候选
无支持，记为“未报告的无支持候选”。无域内解、无证书和无支持见证分别
记录，不能互相替代。原始图的四色见证不证明受限域有解。

保存检查独立重枚举原字面赋值并核验证书及缺失覆盖，不重新调用检测器。
本层不是全部非空域组合、一般EQ商图、平面嵌入、合法构造历史或算法可达
状态的穷举，不要求这条局部规则发现全部不可用颜色。
