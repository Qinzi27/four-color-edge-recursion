# 从闭合结构的接口约束到可执行传播

本轮接续“从内部结构向外传递什么信息”的问题：内部完成后，外部不能只得到一个色数或各面独立的候选域，还需要得到哪些接口颜色组合可以同时出现。发起想法来自 Qinzi27；这里新增的是本仓库中的可验证局部传播实验，基本方法属于已有约束一致性框架。

## 规则与真正增加的信息

对于一条真实面邻接边 U—D，取同时邻接两面的接口集合 T。U、D 必须异色，所以四种颜色中，T 合计至多使用另外两种颜色。识别程序记录 U—D、U—t、D—t 对应的全部原图共边编号，忽略桥边；辅助兼容关系不冒充真实共边。

这里的“内部”指局部接口问题中被条件化的 U、D，不保证它们位于地图几何上的最内层。本轮研究的是内部约束怎样向接口传递，尚未实现任意嵌套圈识别，也没有改变 v4 的遍历规则。

新增两种显式模式，沿用旧 v4 的初始化、选面顺序规则和 `min(D)`，仅改变承诺前的传播：

|模式|执行内容|与旧传播的关系|
|---|---|---|
|`domains`|枚举六种两色调色板，只检查 T 各单面域能否得到支持|已证明在旧非空路径一致固定点之后不会再删单个候选色，作为消融对照|
|`joint`|在局部 `{U,D}∪T` 中检查至多12种内部有序异色对，保留全部二元关系，汇总各条件分支支持后再传播|可以删除旧闭包留下的不合法颜色对；明确包含局部条件检查|

关键小例子就是原图 `K₂ ∨ 3K₁`。固定第三接口 z=3 后，旧闭包仍保留另两接口 x、y 的全部16种颜色对。新规则保留10种，删除 `{1,2,4}` 内两个不同颜色构成的六种配对；否则 x、y、z 已用掉三色，U、D 只能同取剩下一色。独立1024种完整赋值检查确认24个合法解全部保留。x、y 各自的一元域仍是四种颜色，所以只比较域大小会漏掉这一进步。

理论文件 [JOINT_BOUNDARY_THEORY-2026-09-20.md](JOINT_BOUNDARY_THEORY-2026-09-20.md) 给出一元冗余证明、可靠性证明及局部投影精确性证明。精确性只针对当前局部二元网络，不保证这些局部解可以延拓到整图，也不保证后续不可逆取最小色安全。

## 预先确定的比较范围

输入固定为旧 v4 归档的9个失败图和40个既有诊断对照图，共49图，两种模式分别从几何重新运行，共98次完整命名。旧颜色只由独立核验器读取来证明真解仍存活，不传给新生产算法。9个失败图分别比较两种对象：

1. 在原来第一次错误决定之前的相同状态，新规则能否排除那个候选色。
2. 从头采用新传播后，整个新贪心轨迹能否完成，并检查40个对照是否退步。

这是已看过的诊断集，不是未知留出集，也不是重新跑完7069张地图。相邻历史前缀不能视为独立随机样本。一次调用的时间用于记录成本，不作为算法加速证据。

## 正式实验结果

**结论：信息更强，但本轮没有提高原策略的完成数；不能称为已验证的算法优化。**

|规则|49图完成|49图冲突|修复旧失败|新增退步|阻止原首错候选|
|---|---:|---:|---:|---:|---:|
|冻结 v4（归档基线）|40|9|—|—|—|
|一元消融 `domains`|40|9|0|0|0/9|
|局部联合 `joint`|40|9|0|0|0/9|

`domains` 在全部49图上的每次主动选择、最终域、关系矩阵、颜色及初始化均与冻结 v4 完全一致。`joint` 的49条主动取色轨迹也没有改变。40个对照全部完成，9个旧失败仍失败，不能把这个结果写成修复了任何旧失败。

仍然观察到了新信息：9个原首错状态中，有6个在一次联合扫描中新增二元删减；全新完整轨迹中，有39/49图出现额外二元删减，共删除3192个有向矩阵位。这个数累计了不同传播调用及两个方向，**不是3192条不同的数学结论**。联合过滤直接删除的一元值为0；额外配对限制没有改变本轮主动取色。

验证分为三层：

- 全部98次完整运行逐项复核几何共边、就绪阶段、主动选择、Hall 删除、全局关系删除及局部分支汇总；成功着色检查全部真实邻接和承诺。
- 独立集合实现重算9893次局部条件闭包，并复核16336个 Hall 事件、27214个全局二元删除事件。生产程序使用位掩码与工作队列，核验器使用集合与重复扫描。
- 9个首错状态中的39个局部结构，独立穷举其当前域笛卡尔积共4681次分配，39/39所得精确投影与生产过滤一致；这不是整图赋色搜索。全部已知合法见证在新过滤后存活。

## 实现与复现

- `fourcolor/joint_boundary.py`：几何证书、一元消融与联合条件过滤。
- `fourcolor/joint_boundary_restart.py`：独立实验策略，保留原 v4 源码。
- `scripts/validate_joint_boundary.py`：固定诊断集，独立集合运算核验全局删除与局部分支，保存全部运行。
- `scripts/name_joint_boundary_map.py`：单图入口，模式必须显式选择；输出已存在时拒绝覆盖。

下列 `python` 指配置好的 Python 3.10+ 解释器。单图几何导出还需要 Node；核心传播使用 Python 标准库。每次复现应换一个输出文件名，保留旧证据。

```shell
python scripts/name_joint_boundary_map.py examples/peer-batch-five-lines.json --mode joint --output outputs/joint-boundary-example-rerun.json
python scripts/validate_joint_boundary.py --output outputs/joint-boundary-pilot-rerun.json.gz --summary outputs/joint-boundary-pilot-rerun-summary.json
python -m unittest discover -s tests -v
python scripts/validate.py --output outputs/validation-joint-boundary-rerun.json
```

## 这一步的意义与下一道关口

已得到一个可检查的区分：仅增加色数上界会重复已有的一元推理；保留该约束引出的联合配对，才可能带来增量。局部关系可以由真实共边产生，并以独立核验证书传给原命名程序。这比只讨论“由内到外可能更好”更明确，但没有由此宣称新四色证明、首创条件一致性或一般速度优势。

目前的障碍已经收窄：分别计算一个局部组的精确二元投影，仍不足以阻止这些错误决定。下一步优先检查最小失败图中**重叠局部组之间的共同接口条件**，比较“先保留联合条件再合并”与“分别投影成二元关系再传播”丢失了什么。先给出有限范围的可靠推导，再决定是否写入下一实验策略；不直接扩大试色范围来追求通过率。

只有新策略在明确靶点上展示了实质作用，才值得冻结规则并完整重跑7069图、统计新增退步，再加预声明未知图集。不能把旧版本的成功数与后来的局部修复数相加冒充新版本全库结果。本轮保留为本地研究结果，未改网页、未上传 GitHub。
