# 按需结构反证为何保持旧 v2 的成功轨迹

2026-09-21。对当前冻结规则的独立数学审查。本文件在规则冻结后补充证明说明，不修改正在运行的规则、源码或源哈希清单，也不是新的算法分支。

**在下面明确的前提下，任何旧 v2 能完成的合法四名实例，新规则都会沿用完全相同的主动选择序列完成，并且不会学习任何新异名关系。** 这是一条成功保持命题；它不依赖某个有限测试集合，也不说明旧 v2 失败的实例都会被修复。

## 1. 定义与必要前提

固定当前线网及其侧轨道约束图 `G`，名字集合为 `{1,2,3,4}`。桥的两侧属于同一轨道，不产生异名约束。令 `A` 表示旧 v2，`B` 表示 `mother-peer-structural-reuse-v1`。

需要以下契约：

1. **同一问题。** 两者使用同一几何、侧身份、真实边约束及四名集合；初始外框规范化相同。
2. **相同的无学习主流程。** 当已学习关系集合为空时，两者在每个有合法延伸的共同前缀上得到相同候选域、二元关系和下一主动提议。选择只依赖这些状态及相同的确定性几何元数据，不依赖查询遥测、运行耗时或缓存命中数。
3. **旧路径承诺累积，传播保留解。** 已作出的名字承诺不被另一名字覆写。给定当前承诺 `P`，每个满足 `G` 和 `P` 的完整合法赋名 `f` 都满足 `f(v) ∈ D_P(v)`；二元过滤同样保留 `f` 的所有投影。特别地，若 `D_P(b)={c}`，任一当前合法延伸都令 `f(b)=c`。
4. **只检查将被实际采用的同名提议。** `B` 的额外检查针对当前准备提交的 `a=c`，以及当前域恰为 `{c}` 的另一个侧 `b`；只有检查成功反驳 `a=b` 才改变主流程。未找到反证时，查询仅增加记录，原提议照常提交。
5. **异名证明可靠。** 每个 `proved_different(a,b)` 都保证 `G` 的任何合法四名赋值满足 `f(a)≠f(b)`。当前实现只依据真实原边推理，因此结论是对当前图的无条件关系。若将来允许依据承诺推理，也必须在证书中明确条件，且旧最终见证满足这些条件。
6. **正常执行并有限终止。** 不将超时、内存耗尽、外部中断或实现异常算入本数学命题。额外结构查询有限结束；没有在查询预算耗尽时改用另一选择器等隐藏行为。

前提 4 的“按需”限制很重要：本命题不适用于任意预先加入全部可靠约束的策略。即使新约束全部正确，提前缩小别处的候选域也可能改变按域大小排序的贪心顺序。当前规则只会在准备做出的具体承诺被可靠反证时分叉。

## 2. 成功保持命题

**命题。** 若 `A` 在 `G` 上有限步输出完整合法赋名 `f*`，且上述前提成立，则 `B` 具有：

- 相同的主动提交序列，包括侧身份、dart 位置及具体数字名；
- 相同的最终赋名 `f*`，不仅是全局名字置换意义下相同；
- 学习关系集合始终为空。

**证明。** 两者初始承诺与无学习传播状态相同。假设在已经提交相同的前 `k` 步后，尚无学习关系。设下一共同提议为 `a=c`。

因为旧策略最终成功，`f*` 延伸旧路径的所有承诺，尤其延伸当前承诺和即将提交的 `a=c`，所以

```text
f*(a) = c。
```

`B` 只可能查询另一满足 `D_P(b)={c}` 的侧 `b`。由传播的保留解性质，旧最终见证仍在当前全部候选域中，因而

```text
f*(b) ∈ D_P(b) = {c}，即 f*(b) = c。
```

于是 `f*` 是一个同时满足 `G` 与 `a=b` 的完整合法见证。可靠的结构证明不可能声称所有合法赋名均令 `a≠b`。因此这一步的所有查询都不可能返回 `proved_different`，包括缓存结果；`B` 不学习关系，提交与旧策略相同的 `a=c`。

无学习的主流程再得到相同后继状态，归纳条件延续。旧策略有限步完成，`B` 遂在相同提交序列后得到相同完整结果。若旧策略在初始传播后已经完成，结论直接成立。证毕。

等价地，假定有“第一次学习或主动选择分叉”，上述旧最终见证会在该处直接反驳所声称的异名证明，所以不存在第一次分叉。

### 单例是否可能在下一轮重建时消失

证明并不要求所有派生单例都永久写入 `anchors`，也不依赖某种特定内存表示的逐轮单调性。唯一需要的是：在检查发生的这一刻，完整旧见证 `f*` 属于当前域。若当前域是 `{c}`，则 `f*(b)=c` 已经成立；后续是否重新计算域不影响这一步推理。

当前旧程序的永久承诺是累积的；派生单例是这些承诺和原图约束的可靠后果。因此同一最终见证确实适用于整个旧成功路径。若将来允许覆写承诺、撤回假设或使用不保留解的启发式剪枝，需要重新验证这一契约。

## 4. 可以推出和不能推出的内容

在正常数学执行范围内，旧成功集合包含于新成功集合：

```text
Success(v2) ⊆ Success(structural-reuse-v1)。
```

这给出了“已成功案例不会因这种按需可靠反证而退步”的原理性理由。有限回归仍然有必要，用来检查实现是否满足契约、具体修复范围和额外计算开销，而不是用统计结果替代命题的前提。

该命题不保证：

- 任意旧失败实例都能找到足够的异名证明；
- 一次学习后，新的后续贪心路径一定成功；
- 所有必要信息都可用二元异名关系表示；
- 新策略更快、满足同一资源预算，或具有某个更优复杂度；
- 新规则或上述成功保持论证具有已确立的原创性；
- 用户的全部闭环递归方案已经实现，或获得新的四色定理证明。

此外，“旧成功时零学习”不意味着“零结构计算”：这些路径仍可能执行许多结果为 `inconclusive` 的查询。图数、学习关系数、查询数和运行时间必须分别报告。
