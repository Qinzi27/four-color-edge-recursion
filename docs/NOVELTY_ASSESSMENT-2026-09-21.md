# 递归侧命名与低成本修复：原创性阶段评估

评估日期：2026-09-21。起始研究想法属于 Qinzi27。本报告综合本轮动态着色与结构压缩两条定向检索，并参考项目此前已核对的固定目标依赖图及 Inoue 等工作。检索不包含穷尽引文追踪，不是学术优先权认证。

**阶段结论：方法组成已有明确先例。本项目可以保留的候选贡献，是特定几何模型下的精确构造、可核验成本证书、策略适配及可重复实验整合；尚不能确认文献首创，也不能称作新的通用四色算法。**

这不否定独立推导、实现与实验的价值，但需要分别回答三件事：我们是否做出了正确结果；结果相对旧实现是否有用；同一思想或等价命题是否已在文献出现。测试与直接证明主要回答第一件事，受控比较回答第二件事，查新才回答第三件事。

## 2. 特定 `2m` 命题应怎样表述

上一轮 [构造与证明](RECOLORING_OBSTRUCTIONS-2026-09-21.md) 给出指定合法父态的 `2m` 命题。本轮 [旧父图刚性证明](TRIANGLE_CHAIN_PARENT_RIGIDITY-2026-09-21.md) 将量词加强为：对每个整数 `m≥1`，存在这种真实贯穿矩形切割，使最后切割前的**任意合法父图配色**，在外侧固定为 0、两个新子侧不计入旧侧成本的条件下，分割后的最少净旧侧改色数都严格等于 `2m`；一次完整 Kempe 分量交换即可达到。

这里至少要同时保留六项条件：

1. 顶点代表面对应的侧一致性类，几何角点接触不算面邻接。
2. 输入有真实矩形与完整贯穿切割历史。
3. 旧父图是 2-tree 加固定通邻外侧，恰六种合法配色，全为同一初态的整体置换；下界对六种均成立。某个给定策略是否从起点到达该父图，仍需单独证明或测试。
4. 外侧固定，内部最终约束图为路径平方，实际可用内部色为三种。
5. 成本只统计终点相对初态的净旧侧改色，排除两个子侧；不是累计操作数或记录写入数。
6. Kempe 交换在待边尚未提交的旧约束图上合法，最终才提交新增子侧异色约束。

这比“一次插边可能需要很多改色”具体，但它又利用了已知的唯一三色性和双色分量交换。完整表述不同，未必意味着其证明机制或数学实质具有足够新颖性；还需排除图同构、已有定理的直接推论及不同术语下的等价构造。

因此，建议使用“我们构造并验证了这一受限实例族”，暂不使用“首次发现”“原创最优四色算法”或“突破四色理论”。

## 3. 与 Inoue 等近线性四色工作的关系

Inoue、Kawarabayashi、Miyashita、Mohar、Thomassen、Thorup 的预印本 [The Four Color Theorem with Linearly Many Reducible Configurations and Near-Linear Time Coloring](https://arxiv.org/abs/2603.24880)，项目此前核对版本为 [v2](https://arxiv.org/html/2603.24880v2)，报告 `O(n log n)` 的平面图四色算法。此前已读范围、版本与复现边界见 [相关工作更新](RELATED_WORK_UPDATE-2026-09-19.md)。本报告沿用该版本对照，没有重新审查全部证明或运行其计算检查。

| 比较问题 | Inoue 等 v2 | 本项目当前研究 |
|---|---|---|
| 主要输出 | 输入平面图的一种合法四色着色 | 对给定旧状态和局部新增约束，寻找成本低的修复及证书 |
| 主要性能目标 | 整体着色算法时间 | 旧侧净改色、操作路径、触及范围及有界求解开销 |
| Kempe 的角色 | 与可约构型、全局递归等机制结合 | 当前受限候选生成、路径操作及成本比较 |
| 可否直接移植保证 | 本项目未复现其整体机制 | 不能从论文的时间界推出本项目的改色成本界或完备性 |

二者有共同工具，目标函数不同。全局快速找到某种合法着色，不自动意味着保持旧状态所需改动少；本项目在特定实例上找到较低改色成本，也不构成比 `O(n log n)` 更好的整体四色算法。可能的连接是更严谨的边界状态与可延拓性设计，仍需独立证明与验证。

## 4. 下一步测试与创新判断的边界

本轮 [连续历史正式实验](TRIANGLE_CHAIN_REPLAY-2026-09-21.md) 已完成独立审计：原有规则的 448 条历史均在最后父图之前停止。单独命名的 forest 后接单次择优 Kempe 策略完成 128/128 条配对历史，1,792 次实际后备修复均达到该步的精确最少旧侧改色；全部最后待切状态均属于此前困难配色的整体置换。输入来自实际轨迹，终点 oracle 仅在整条历史结束后审计。这证明有限范围的功能改善，不证明任意规模完备或累计历史成本最优。

父图刚性也已给出对任意 `m≥1` 的证明，并对 `m=1,…,8` 的全部 48 个旧着色独立枚举核验。其根本机制直接属于已有 2-tree 唯一三色性，不能把这一理论本身称为原创。新增明确内容是此真实几何编辑的量词、成本和可执行见证；仍需排除既有同构构造或直接推论。

较有研究价值的候选方向是：

- 将本轮有限连续轨迹推进为明确策略和历史族上任意参数的到达性及完成性证明。
- 找到可维持的不变量或明确的前瞻条件，并证明修复代价或摊还代价界；同时计入预防阶段的改色成本。该父图全部合法配色的最后成本相同，单纯提前换色无法改善这一特定编辑，需明确研究其他几何或图类。
- 用已知 Color-Fixing、diamond reduction 或结构 DP 作公平基线，确认新增适配在哪类输入上减少运行开销或改色成本。
- 将几何重放、下界证书、独立 oracle 和冻结数据形成可复用的研究工具。工程价值可以成立，但应与算法理论新颖性分开表述。
