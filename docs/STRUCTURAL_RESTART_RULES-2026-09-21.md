# 结构关系先于落名：冻结规则与对照设计

日期：2026-09-21。规则版本：`mother-peer-structural-reuse-v1`。
本文在7069图正式运行前冻结；实验结果另存，不回写规则。

## 1. 与原始方法的关系

Qinzi27的起点是有序线侧名、母线与接点关系，以及加线后按照当前线网重新求名。本实现从当前线段与平面嵌入构造线侧轨道，整图重新命名，不输入旧配色。它沿用历史最强v2的母线优先选择及最小候选名约定，新增落名前的结构关系检查。这是原路线的一个可检验实现候选，不把实现中的编号、优先级和取最小约定视为用户已经证明的公理，也尚未完整实现任意闭环的由内向外展开理论。

对偶邻接在这里只表示两个线侧轨道是否共享真实原边。桥两侧属于同一轨道，不产生异名边。学习出的逻辑异名关系另存，不添加实际几何边，不混同母线、面、颜色或生成历史。

## 2. 可证明的规则

在最多四名的合法赋名中，三个两两相邻的类必须占三个不同名字；同时邻接三者的所有类只能取剩下的第四名。因此这些共同邻类必须同名。

查询两个轨道a、b能否同名时，暂时合并它们，只用原始真实邻接建立商图。确定性枚举三角形，将其非相邻的两个共同邻类合并；重复到固定点。如果出现同类内原边，或五个两两邻接的类（K5），假设与四名条件矛盾，从而得到a≠b。若没有矛盾，结果仅为`inconclusive`，不代表同名可延拓。

每次强制合并减少类数，所以单次查询有限终止；这不主张线性时间。假设合并后的商图可以非平面，K5证书是反证中的约束冲突，不是实际地图出现K5。

核心只接收顶点数、真实邻接边和待查二元组，不接收配色、预先求出的完整解、旧颜色或隐藏目标。输出逐步整类合并、原边见证及终端矛盾，供独立审计。

## 3. 唯一策略及停止条件

1. 从当前几何重建全部线侧、母线层级和约束，按v2外框锚定外侧1及相邻内侧2；无法确定的层级保留未知。
2. 完成既有Hall与二元路径一致传播，并加入此前已证明的异名关系。
3. 按v2选择下一个线侧和最小候选名。按轨道编号递增，检查所有已固定为同一候选名的其他轨道；每个无序二元组至多新查询一次，包含无结论结果的缓存。
4. 遇到第一条异名证明就保存该关系，重新传播并选择，不提交刚才被反证的名字。全部查询都无反证时，提交v2的最小候选名一次。
5. 最终完成或发生冲突即停止。不回退已提交选择，不换用Kempe、完整着色搜索或另一策略。显式存在“假设同名后推导矛盾”的条件检查，不能描述为完全无试探算法。

关闭结构检查的消融必须与冻结v2的轨迹、域、二元关系、锚点和结果一致。未被排除的贪心选择仍无一般可延拓保证。

## 4. 独立核验

审计器从原始嵌入复算线侧与真实共边，核验每条证书的完整当前类、三角边、六条连接边、合并和终端矛盾，不调用证书生产器。对无结论证书检查商图已经饱和。另用集合运算核验传播删减、锚点、选择顺序、全部应有查询及缓存、先学习后提交的事件序列，以及完整配色的每条真实边。

`triangles_examined`是生产程序遥测，只核验类型和下界，不声称独立复数验证该计数。证书正确性及合并次数、分区、查询覆盖另有实际检查。

主要回归：使用冻结v2归档`outputs/level-sides-peer-full-2026-09-19.json.gz`，SHA-256为`5085627be22653ea9b6ea13de5ff851c452a8c702996ee6eda0672d2d72eca07`。该归档有7069个去重几何、363条历史的7678个前缀引用及302个静态引用，基线7068完成、1冲突。每图仅运行本新策略一次，保留全部失败和学习关系图的完整证据，不合并不同策略的成功集合。对照记录逐图改善、新退步、持续失败，历史全部前缀完成率与终图完成率分开。

独立新种子检查：固定生成器`generatedPaths('guillotine', seed)`及20个种子20262101至20262120，每条24次加线及空图共25个前缀。先生成所有几何，再分别从头运行v2和本规则，不按结果筛选。不把该同族新种子集称为独立图族或一般随机平面图；按去重几何报告与旧7069图的重叠。新种子结果不用于修改本冻结规则。

输出独占创建并记录输入、核心、审计器、规则及运行器哈希。正式报告同时保存成功与失败，完整轨迹可以用冻结源码重放。计时含独立检查与证据写入，不据此声称速度优于v2或经典着色算法。

## 6. 原创性边界

“假设同名→合并→约束传播→矛盾后推出异名”属于既有图着色推理框架。Hébrard与Katsirelos（2020），*Constraint and Satisfiability Reasoning for Graph Coloring*，JAIR 69:33–65，§3讨论Zykov同名合并/异名加边，§6.3（印刷页53）的Lemma 2给出了包含共享三角形规则的团剪枝：取H=K4，两个三角形共同邻点若再要求异名就形成K5，故四名时必须同名。[作者全文](https://gkatsi.github.io/papers/hk-jair20.pdf)。

因此本轮可检验贡献是把有证明的结构关系检查接入用户的线侧重启方法，给出失败原因、可重放证书和公平回归结果；不主张发现新的该条引理。整体策略的优先权、一般完备性、复杂度改进和对既有求解器的优势均未建立，有限通过不能当作四色定理新证明。
