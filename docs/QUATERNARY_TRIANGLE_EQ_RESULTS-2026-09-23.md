## 规则与四进制语义

设原始真实NEQ中，BCD两两相邻，A和E各自与BCD三点相邻，共九条边。在四名集合中：

1. B、C、D必须占三个不同名字。
2. A、E均不能使用这三个名字。
3. 两者都只能使用第四个名字，所以每个合法解都满足A=E。

这是已知初等推论。本次贡献是将它作为有证书、可独立核查的传播规则接入当前程序，未宣称新的数学定理或原创性证明。逻辑EQ不合并面身份，不改变真实邻接；桥、虚拟连接和点接触不充当NEQ。

本版按原始面顺序，对每对不相邻的A/E选择第一个共同三角形，一次性学习，不用新EQ循环构造额外邻接。原始非空候选states和外部equal_names不在本入口范围。锚点可以影响后续候选域，但不参与寻找证书。

加入EQ后，原有二元关系传播会同步两端候选交集。例如A=`1100`（{1,2}），E=`0111`（{2,3,4}），可以同时收缩为`0200`（传播确定名字2），不会把`0111`的显示代表2误当作已指定颜色。`0300`才表示显式锚定2。

## 已知障碍如何被修复

开发诊断保留原始10个身份、18条NEQ、单锚Z=1和输入顺序Z,P,Q,X,A,B,C,D,E,Y。新版仅学习：

```json
{"apices":["A","E"],"rim":["B","C","D"]}
```

| 阶段与实际承诺 | 旧版A / E候选 | 新版A / E候选 |
|---|---|---|
| 初始化，仅Z=1 | {1,2,3,4} / {2,3,4} | {2,3,4} / {2,3,4} |
| 提交P=1 | 同上 | 同上 |
| 再提交Q=2 | {1,2} / {2,3,4} | **{2} / {2}** |
| 再提交X=3 | 仍为危险交叉域，随后试探并提交A=1 | A/E已确定为2，继续处理其余区域 |

旧版顺序为P1→Q2→X3→A1。A1是第一次SAT→UNSAT：此前有6个完整解，之后为0；保存的UNSAT证据为17节点、6叶。后来拒绝B2并出现冲突只是较晚暴露错误。

新版在阶段2、X/Y都还为{3,4}时，就传播确定A=E=2。它没有主动提交A或E；该阶段独立oracle的锚点严格只有Z1/P1/Q2，没有A2、E2或学习EQ。新版主动顺序为P1→Q2→X3→B1→C3，得到合法配色：

`Z1 P1 Q2 X3 A2 B1 C3 D4 E2 Y4`。

两版分别枚举初始化后的4^9=262,144个赋值，原始合法解都为216个；新版EQ初始传播保留全部216个，后续保留与当前实际承诺相容的原始解。跨阶段重复计数的273次解保留不是273个不同解。阶段7→6、主动提交4→5的差别也不能解释成性能优势，因为旧版中途失败。

可重放证据：[抽象诊断检查点](../outputs/quaternary-triangle-eq-2026-09-23-checkpoints/174-bcbb8b274017.json.gz)。该输入已知且参与规则开发，不计入新输入泛化收益，也不是生产母线调度的真实失败实例。

## 已定位的下一处覆盖缺口

以下是对预声明样本的**事后结构观察**，没有增加输入或修改本轮规则。双环正五边形终图 `eq-holdout-concentric-polygons-n5-rings2-angle0` 中，原始真实邻接有：

- 两端S1、S5不相邻；
- 共同邻居形成奇环 `S2→S3→S6→S7→S4→S2`；
- 五条环边及两端各到五个环点的十条边，均直接存在于原始separator NEQ中。

如果S1与S5异名，共同邻居只剩两种名字；五边奇环不能二染色，故S1=S5。当前三角形EQ版本却没有证书：单锚初始化S1={1}、S5={1,2,3,4}，旧双锚S1={2}、S5仍为全域；两版初始域相同，虽然最后都能完成。这直接显示本版尚未覆盖所有原始图蕴含的同名关系，不是新的运行失败。

证据：[五边形检查点](../outputs/quaternary-triangle-eq-2026-09-23-checkpoints/143-1dfab5c0e499.json.gz)，key `1dfab5c0e49989159cf890c7b88c8af70eb6af993c817998c3769cb76ce049e2`，SHA256 `8a058d60f8d3b57a38090db6d1915a35ee1ee6c66451a9ce8d3ee1e048518a9c`。30度表示也核对到同样覆盖缺口，不作为独立新图族。

因此下一步可另立**共同奇环EQ证书**版本，把本版三角形看作长度3特例。只接受原始共邻图中可重放的奇环证据，维持面身份、低色策略及原始NEQ oracle，再分别检查修复、退步和成本。这个奇环推论也有直接初等论证，不能仅因加入程序就宣称原创。寻找真实母线可达首错和一般完成保证仍是独立未解决问题。
