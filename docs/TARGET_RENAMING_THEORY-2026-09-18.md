# 固定目标同步改名：闭包、原子批量与可研究的目标选择

日期：2026-09-18。出发问题来自 Qinzi27 的线侧递归命名及插线后同步更新旧线名。

**定位：本文件完善项目中的数学模型，并给出自包含证明。依赖图已有直接文献先例；下述结论按初等刻画与项目适配处理，不主张独立原创，也不构成一般四色构造。**

## 1. 本次推进与先例

原 [困难例文档 §7](HARD_CASE-2026-09-18.md) 给出：已知目标名、全部阻塞依赖无环时，可以按依赖先后逐侧执行。本次把它推进为完整的固定目标刻画：哪些部分更新合法；有环时哪些侧必须同批；指定一侧立即改名时必须扩张到哪里；如何区分侧数与实际线名记录数。

直接先例是 Cambie、Cames van Batenburg、Cranston 的 *Optimally Reconfiguring List and Correspondence Colourings*，EJC 115, 103798 (2024)，[arXiv 正文](https://arxiv.org/html/2204.07928v3)。其 §2 Definition 4 定义 **colour-shift digraph** 的箭头恰为 `u→v iff uv∈E and target(u)=old(v)`；§6 Lemma 19 使用没有跨割依赖时的混合着色。因此，依赖图和关键切割机制均不是本项目新发现。

另需区分：Dvořák–Feghali 的 [A Thomassen-type method for planar graph recoloring](https://arxiv.org/pdf/2006.09269) §3 研究 once-only 轨迹；Bonamy 等的 [Distributed Recoloring](https://jukkasuomela.fi/doc/distributed-recoloring.pdf) 要求每批变更点是独立集。本文件允许相邻点**原子同步**交换，只要求批次之前/之后合法，故不能将它称为相同的分布式改色模型。

查新为 2026-09-18 定点核对，关键词为 once-only recoloring、colour-shift digraph、atomic recoloring、strongly connected components、dynamic graph coloring recourse。arXiv API 的 `id_list=2204.07928,2006.09269,1708.09080,1802.06742` 连接失败，已用 arXiv/作者正文及出版社页面代替；未完成完整引文追踪，不以未找到完全同名定理作为创新证据。

## 2. 对象与操作语义

令 H=(V,E) 为有限简单的**侧邻接约束图**：顶点是从有向线和端点旋转次序导出的侧一致类，边是异名约束。它不是原图几何线网，也不是改名依赖图。桥两侧属于同一类，不产生这里的自环约束。

给定 H 上两个合法命名 c、t，符号表有限（实现用 0..3）。c 为当前名，t 为指定目标名，S={v:c(v)≠t(v)}。外侧及其他固定类要求 c=t。每个 S 中的点直接且恰好一次改成 t(v)；没有暂借符号、反复改名或中途改变目标。

一个原子批次同时提交一组点的新名。只要求批次边界的命名合法，不假装批内有合法的逐点顺序。若系统只允许逐点可见更新，下面的同步结论不能直接应用。

**插线适配。** 分裂后两个子侧可以先在未提交状态中继承父名。令 H 为新侧邻接图去掉待新增的子侧间约束，令 G=H+待提交约束。c 必须在 H 合法，t 必须在 G 合法。规划在 H 上进行，新增约束只在最终整体事务提交时生效；不能把 c 当成 G 的合法状态。固定目标不会由本文件自动求出。

定义 D 的顶点为 S，依赖箭头为

\[
u\longrightarrow v\iff uv\in E,\quad t(u)=c(v),\quad u,v\in S.
\]

箭头读作“u 想取得的目标名当前被邻侧 v 占用”，因此执行方向与箭头相反。原文包含全部 V；本文件删除不变顶点。合法 c,t 保证不变顶点没有相关阻塞箭头，故该限制不丢信息。

## 3. 混合状态与调度的充要条件

对 X⊆S，令 m_X 在 X 中使用目标 t，其余位置使用旧名 c。

**定理 1（出闭包刻画）。**

\[
m_X\text{ 在 H 合法}\iff
\forall(u\to v)\in D,\ u\in X\Rightarrow v\in X.
\]

证明：逐条考虑 H 的邻边。两端均已改，由 t 合法；两端均未改，由 c 合法。若仅 u 已改，唯一冲突条件是 t(u)=c(v)。若 v 不在 S，则 c(v)=t(v)，与 t 合法矛盾；否则该冲突恰对应一条从 X 指向 S\X 的依赖箭头。以上穷尽邻边类型，故必要且充分。证毕。

**推论 1（所有合法批次调度）。** 将 S 分成有序非空批次，令 τ(v) 为执行批号。全过程合法当且仅当每条依赖满足 τ(v)≤τ(u)。每一批可以把有直接依赖的两点一起改；不必是独立集。

**推论 2（逐点规则的精确边界）。** 存在每点恰改一次的合法逐点顺序，当且仅当 D 无有向环。充分性是依赖先执行的拓扑序；必要性来自环上严格先后关系不可能成立。这把旧文档的充分证书补成了在明确操作模型下的充要判据。允许临时符号后，不再能由“有环”断言不可逐点改色。

## 4. 不可拆同步块、立即请求与实际记录成本

**定理 2（最小峰值原子批量）。** D 的每个强连通分量（SCC）必须在同一批完成；每个 SCC 一批、按依赖先行顺序执行总可行。因此

\[
\min_{\mathcal B}\max_{B\in\mathcal B}|B|
=\max_{C\in\operatorname{SCC}(D)}|C|.
\]

证明：同一 SCC 中任意两点相互可达，推论 1 沿路径分别给出两方向的批号不等式，故批号相等。每个 SCC 必须包含于某批，给出下界。凝聚图无环，按依赖先行的逆拓扑序逐 SCC 提交，满足推论 1 并达到下界。S 为空时两边约定为 0。证毕。

例：边 uv 上旧名为 (1,2)，目标为 (2,1)。两点互相阻塞，不能只把其中一点先改到目标，但一次原子交换两点合法。三角形从 (1,2,3) 轮换到 (2,3,1) 则出现三点 SCC。

**定理 3（指定请求的最小立即批次）。** 已完成集合 X 的混合命名合法。若 A⊆S\X 中的点必须在下一批立即更新，则最小合法新增批次为

\[
B=\operatorname{Reach}_{D[S\setminus X]}(A).
\]

证明：任何包含 A 的合法新增批必须连同所有尚未完成的阻塞者一起改；反复沿依赖推出必须包含可达闭包。反向，可达闭包与已经出闭的 X 合并后仍出闭，由定理 1 合法。故它不只是大小最小，而是按集合包含关系的唯一最小集合。证毕。

SCC 与立即请求不同。例如 u→v→w 可按 w、v、u 三次单点执行；若要求 u 下一批就改，必须把三点一起改。不能把 SCC 大小误称为任意指定首步的修复范围。

**定理 4（任意单调集合成本）。** 若批代价 F 满足 F(∅)=0 且 A⊆B⇒F(A)≤F(B)，则

\[
\min_{\mathcal B}\max_{B\in\mathcal B}F(B)=\max_C F(C).
\]

证明：每个 SCC C 包含在某批 B 内，所以 F(B)≥F(C)；逐 SCC 执行达到上界。不需要可加性。证毕。

两种实际解释：

- F(B)=Σ_{v∈B}w(v)，w≥0。可将新子侧权重设 0，只统计未分裂旧侧；实现提供这一版本。
- 每个侧类 v 关联固定线名记录 ID 集 R(v)，取 F(B)=|∪_{v∈B}R(v)|。每条原图边的一对有序左右名作为一条记录；同批改它两侧只计一次。这才是每批线名记录写入数，而不是把侧数直接等同线段数。

后一种解释限定**固定几何与 ID 映射**；若用分裂后的候选几何，则报告明确以该候选快照的记录计费。新增/删除记录、父边细分、历史谱系更新的成本另计。此处优化单批峰值，不优化总写入次数或实际运行时间。

**轮次边界。** 不限制批量时，全体 S 一批就是合法最终目标，非空情形最少批次恒为 1。不能把凝聚图最长路径叫作本模型的一般最少轮次。引入容量 b 后，存在峰值不超过 b 的调度当且仅当每个 SCC 成本≤b；在此限制下进一步最小化批次数，是另外一个问题。

## 5. 条带链衔接与双锚结构的边界

固定双锚条带链的分裂后继承状态，在 H=G 去掉新子侧间约束上合法。所选双色交换段内部每条邻边都有双向依赖，整段恰是一个 SCC。于是既有公式

\[
m=\min(i-1,n-i)
\]

不仅给出未分裂旧侧的最少改名数；对该指定目标，最小峰值同步侧数为 m+1（包含一个新子侧），旧侧加权峰值为 m。居中分裂长度 2k+1 的链，旧侧加权峰值达到 k；没有与链长无关的恒定旧侧批量上界。这不是几何半径下界。

**命题 5（全局双锚的平面范围）。** 对有限简单图 F，K₂∨F 可平面嵌入，当且仅当 F 是线性森林，即路径和孤立点的不交并。

证明：若 F 中有度至少 3 的顶点 v，两个锚与 v 对其三个邻点构成 K₃,₃ 子图，非平面。故最大度≤2。若存在长度 k≥3 的环，K₂∨C_k 子图有 k+2 个点、3k+1 条边，超过简单平面图上界 3(k+2)-6=3k。故每个分量都是路径或孤立点。反向，把路径分量端点依次连接成 P_N；K₂∨P_N 可从含两个锚的三角面逐次堆叠新点构造平面嵌入，删除连接分量的边即得 K₂∨F。空 F 为 K₂，亦成立。证毕。

这是一个初等结构限制，不作原创声明；只证明存在平面嵌入，不保证任意给定旋转系统合法。它解释了为什么不能在保留“相邻双锚连接所有侧”的同时，把条带随意推广为分叉树。单纯增加色数也不能移除非平面障碍；若要在平面范围超出线性森林，必须改变全局双锚的邻接结构。

## 6. 实现与独立核验

新增 `fourcolor/target_renaming.py`：输入 H 的邻边、当前名、给定目标、固定侧及待新增约束；验证端点合法性，迭代求 SCC，生成批次并给出可达闭包。没有着色搜索；侧 ID、符号、邻接与原图记录 ID 保持不同类型含义。

`tests/test_target_renaming.py` 检查输入、原子与逐点差异、数值权重、固定侧、请求闭包及已有模型的适配。`scripts/validate_target_renaming.py` 另用**直接枚举混合命名、全部子集转移动态规划**检验最小峰值，不调用 SCC 来构造 oracle。

运行（核心标准库、Python 3.10+）：

```sh
python -m unittest discover -s tests -v
python scripts/validate_target_renaming.py
python scripts/validate.py --output outputs/validation-target-fresh.json
```

新实验脚本拒绝覆盖已有结果，默认使用 UTC 时间戳。有限核验检查实现与命题一致，不代替一般证明。结果范围和数量见同日工作日志及机器报告。

## 7. 现在可以发展的研究问题

本轮把“执行已知目标”刻画清楚。**真正的选择问题仍是：插线后，怎样得到一个合适的合法目标 t？** SCC 分解不会替代这一步。

可操作的下一目标是：对明确的插线图族、固定外侧与允许的原子语义，在全部合法 t 中研究

\[
\bigl(r(t),b(t)\bigr)=
\left(\#\{\text{改名的未分裂旧侧}\},
\max_{C\in\mathrm{SCC}(D_{c,t})}|C|\right).
\]

研究 r 最小是否迫使较大 b，或能否通过适当增加总改名数来降低峰值同步范围。也可将 b 替换为固定几何上的记录并集代价。它们是不同优化目标，不能统称“局部性”。本轮穷举小图仅生成精确基准；它不是不搜索的目标选择器。

优先级与停止标准：

1. **先找明确的结构差异。** 用现有首次阻塞状态中按规模事先确定的全部小实例，求合法目标的完整代价集合与 Pareto 前沿；保留无权衡的结果，不能只挑漂亮案例。
2. **再选超出条带的平面图族。** 全局双锚条件需要放松，例如只有部分侧邻接某锚；必须先给出完整邻接/插线定义，而不是称为“更一般地图”。
3. **证明目标选择规则。** 希望从结构直接构造达到某个代价界的 t，并证明终止；先与精确小图基准对照。若规则只是在给定 t 后求 SCC，不算解决目标选择。
4. **与重着色及动态改色文献比较。** Barba 等 [Dynamic Graph Coloring](https://arxiv.org/pdf/1708.09080) 的边增删模型与本项目固定嵌入插线不同；已有动态下界不能直接迁移，但提示应严格限定更新类型与资源指标。

只有新的图族覆盖、严格更强的界、非平凡反例或可证明的选择算法，才可能构成独立新增结果。若进一步实验始终只是复现已知换色机制，就记录边界并停止该分支，不因已有实现而继续扩大投入。
